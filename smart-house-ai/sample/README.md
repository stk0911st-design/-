# sample/ — テスト用サンプルデータ

**ここにあるデータはすべて架空です。実在の物件・取引・担当者とは一切関係ありません。**

システムが正しく動くかを確認するためだけに使います。

## 使い方

```bash
# サンプルデータで社長ダッシュボードをテスト実行
./scripts/run_01_morning_ceo_dashboard.sh --input sample/input --tag SAMPLE --force
```

- `--input sample/input` : 本番の `input/` ではなくサンプルを読む
- `--tag SAMPLE`         : 出力ファイル名に `_SAMPLE` が付き、本番レポートと混ざらない
- `--force`              : 休日でも実行する（テスト用）

出力は `output/daily/YYYY-MM-DD_ceo_dashboard_SAMPLE.md` に保存されます。

## 入っているファイル

| ファイル | 内容 |
| --- | --- |
| `input/01_売上実績_2026-09.csv` | 売上・原価・粗利の実績 |
| `input/02_在庫一覧.csv` | 保有物件（保有日数が短いものから長いものまで） |
| `input/03_営業日報KPI_2026-09.csv` | 営業担当者別のKPI（週累計） |
| `input/04_新規案件_2026-09-01.csv` | 新規の持込案件（データ欠損ありのものを含む） |
| `input/05_借入_資金繰り.md` | 借入残高・金利・資金繰り予定 |
| `input/06_予定_判断待ち.md` | 予定表・社長判断待ち事項・今月の目標 |

### わざと欠けているデータ

AIが数字を捏造しないかを確認するため、以下を意図的に欠けさせています。

- `N-9002`（サンプル案件β）の **想定売却価格が空欄** → 粗利が計算できないはず
- `Z-105`（サンプル5号）の **リフォーム費が空欄**
- 前年同月・前月のデータが無い → 前年同月比は「比較不可」になるはず

レポートにこれらの数字が**具体的な金額として書かれていたら、それは捏造**です。
その場合はプロンプトの見直しが必要なので、報告してください。
