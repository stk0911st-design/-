# input_format_test/ — ファイル形式の検証用サンプル

**すべて架空のデータです。実在の物件・取引・担当者とは一切関係ありません。**

Excel（.xlsx）と Shift_JIS の CSV が正しく読めるかを確認するためのサンプルです。

## 入っているファイル

| ファイル | 形式 | 確認したいこと |
| --- | --- | --- |
| `在庫一覧_エクセル版.xlsx` | Excel（シート名「在庫一覧」） | シートがCSVに展開され、値が正しく読めるか |
| `売上実績_SJIS版.csv` | Shift_JIS の CSV | 日本語（案件名・担当者名）が文字化けせずに読めるか |

## 使い方

```bash
./scripts/run_01_morning_ceo_dashboard.sh --input sample/input_format_test --tag FORMAT --force
```

## 正解データ（レポートの数字と照合してください）

**Excel（在庫一覧）**

| 物件No | 取得価格 | 現在販売価格 |
| --- | --- | --- |
| X-201 | 35,500,000 | 43,200,000 |
| X-202 | 19,800,000 | 24,300,000 |
| X-203 | 41,000,000 | 46,200,000 |
| **合計** | **96,300,000** | **113,700,000** |

**Shift_JIS（売上実績）**

| 案件No | 売上 | 粗利 | 担当 |
| --- | --- | --- | --- |
| SJ-701 | 38,900,000 | 5,700,000 | 高橋 |
| SJ-702 | 1,480,000 | 1,480,000 | 渡辺 |

レポートにこれらの数字が出ていれば、両形式とも正しく読めています。
担当者名（高橋・渡辺）が文字化けせず出ていれば、Shift_JIS の変換も成功しています。

## 前処理の仕組み

`scripts/lib/prepare_input.py` が実行時に自動で動きます。

```
input/（元データ・変更しない）
  └─ 在庫一覧.xlsx ──┐
  └─ 売上_SJIS.csv ─┤ 読み取り専用で開く
                     ↓
              前処理（Excel展開・文字コード変換）
                     ↓
     logs/tmp/<実行ID>_prepared/（作業用コピー）
       └─ 在庫一覧__在庫一覧.csv   ← AIはこちらを読む
       └─ 売上_SJIS.csv（UTF-8）
```

**元データには一切書き込みません。** 実行前後でチェックサムを照合して確認しています。
