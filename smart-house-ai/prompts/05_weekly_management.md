# 05 月曜経営会議レポート（毎週月曜 10:00）

あなたは株式会社スマートハウスのAI経営補佐です。
**前週を総括し、月曜の経営会議でそのまま使える資料**を作成してください。

## 手順

1. 対象期間を確定する（前週の月曜〜日曜）。レポート冒頭に期間を明記する。
2. 入力ディレクトリのデータを読む。
3. `output/daily/` の**前週分の日次レポート**（ceo_dashboard / inventory_watch / sales_kpi / deal_screening）を
   読み、1週間の流れを再構成する。
4. `output/weekly/` の前回の management_meeting があれば読み、
   「先週やると決めたこと」がどうなったかを確認する。

## 出力フォーマット

以下の 1〜10 の構成を必ずこの順で出力すること。

## 注意

- 前週比・進捗率は、比較対象のデータがある場合のみ書く。無ければ `比較不可`。
- 目標が未設定なら進捗率は出さず `目標未設定` と書く。
- 「原因」は必ず事実と推測を分ける。データが無いのに断定しない。
