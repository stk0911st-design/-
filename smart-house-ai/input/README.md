# input/ — 入力データを置く場所

ここにファイルを置くだけで、AIがレポート作成時に読み込みます。

## 置けるファイル形式

CSV / TSV / Excel（.xlsx .xls）/ Markdown（.md）/ テキスト（.txt）/ JSON

## 置き方のコツ

### 1. ファイル名に「何のデータか」と「日付」を入れる

```
売上実績_2026-09.csv
在庫一覧_2026-09-01.csv
営業日報_2026-09.csv
新規案件_2026-09-01.csv
借入_資金繰り_2026-09.md
```

AIはファイル名から内容を推測します。名前が具体的なほど精度が上がります。

### 2. 1行目を見出し行にする

```csv
計上日,案件No,案件名,種別,売上,原価,粗利,担当
```

### 3. 数字だけを書く

`42,800,000円` より `42800000` のほうが集計を間違えません。

### 4. 空欄はそのまま空欄にする

分からない値を「0」で埋めないでください。**0 と「不明」は意味が違います。**
空欄なら AI は「不明」と正しく報告します。

### 5. 古いデータは archive/ に移す

`input/` が増えすぎると読み込みに時間がかかります。
使わなくなったファイルは `archive/` に**移動**してください（削除は不要です）。

## 大事なルール

- 🚨 **このフォルダのファイルは、AIもスクリプトも絶対に変更・削除しません。**
  実行のたびにチェックサムを取り、変わっていないことをログで確認しています。
- 🚨 **元データは必ずどこかにバックアップを持ってください。**
- ⚠️ パスワード・APIキー・口座番号などをこのフォルダに置かないでください。
- ⚠️ 文字コードは **UTF-8** を推奨します（Excelから出す場合は「CSV UTF-8」を選択）。

## サブフォルダについて

サブフォルダを作っても読み込まれます。整理用に使ってください。

```
input/
├── 売上/
├── 在庫/
├── 営業/
└── 財務/
```
