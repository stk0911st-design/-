# 運用ルール（詳細版）

`CLAUDE.md` の絶対ルールを補足するもの。

## 1. 情報を削除しない

- TODO は完了しても消さない → `- [x]` にして、月次で `todo/archive/YYYY-MM.md` へ移す
- 中止した項目は `- [~]` にして**中止理由を必ず書く**
- 日記は上書きしない。後から分かったことは同じ日の末尾に `## 追記（YYYY-MM-DD 記）` として足す
- ファイル削除・リネームが必要な場合は、事前に確認を取る

## 2. 外部送信は必ず確認

確認が必要な操作:
- メール送信 / 返信 / 転送
- Slack や SNS への投稿
- カレンダー招待の送信（他者を含むもの）
- GitHub の Issue / PR / コメント投稿
- ファイルの外部共有（Drive の共有リンク発行など）

確認の出し方: **宛先・件名・本文の全文**を提示し、明示的な承認を得てから実行する。
下書き（draft）の作成・保存までは承認なしで可。

## 3. 機密の扱い

- コミットされる文書に書かないもの: 実在の社名・取引先名・顧客名・個人名（家族/同僚）・
  住所・電話番号・口座や金額の詳細・社内システム名・認証情報
- 抽象化の例: `A社` `B案件` `上司` `同僚K` `取引先C`
- 対応表が必要なら `private/company-context.md`（push されない）に置く
- Web検索や外部APIに、上記の生情報を渡さない

## 4. 記録の粒度

- 日記: その日の出来事・完了/未完了・気づき・体調や気分・明日への申し送り
- 重要事項: 後日参照する可能性があるもの（決定・約束・期限・金額・体調の変化）
- 迷ったら「残す」

## 5. 履歴の引き継ぎ

セッション開始時に読む順:
`memory/profile.md` → `memory/important.md` → `todo/active.md` → 直近の日記2〜3日分
