# MY-LIFE

生活・仕事・記録の置き場。運用ルールは [`CLAUDE.md`](CLAUDE.md)。

```
MY-LIFE/
├── CLAUDE.md            秘書の運用ルール（必読）
├── 01_今日やること/      TODO.md ＋ 完了アーカイブ/
├── 02_予定/             月別予定・定例予定
├── 03_日記/             YYYY/MM/YYYY-MM-DD.md
├── 04_アイデア/          思いつき・やりたいこと
├── 05_旅行/             行き先候補・旅程・記録
├── 06_バイク/           整備記録・ツーリング・期限管理
├── 07_お金/             支出メモ・固定費・目標（金額詳細は private/ へ）
├── 08_Note/             note 記事の下書き（公開は要確認）
├── 09_X投稿/            X 投稿の下書き（投稿は要確認）
└── 10_資料保管/          プロフィール・重要事項・テンプレート
```

使い方:
- 朝 → 「朝ブリーフお願い」
- 夜 → 「夜レビューお願い」
- それ以外は普通に話しかければ、該当フォルダに振り分けて記録します。
