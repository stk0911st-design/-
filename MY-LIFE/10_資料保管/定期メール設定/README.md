# 定期メール設定（1日5回）

本人宛に 1日5回、秘書からの連絡メールを送るための設定。

## 稼働中の設定（2026-09-05 作成）

| # | 時刻（JST） | cron（UTC） | 名前 | 詳細 |
|---|---|---|---|---|
| ① | 08:00 | `0 23 * * *` | 秘書メール① 朝8:00 今日の段取り | `01_朝8時.md` |
| ② | 12:00 | `0 3 * * *` | 秘書メール② 昼12:00 午後の入り | `02_昼12時.md` |
| ③ | 15:00 | `0 6 * * *` | 秘書メール③ 午後15:00 折り返し確認 | `03_午後3時.md` |
| ④ | 18:00 | `0 9 * * *` | 秘書メール④ 夕方18:00 明日の先出し | `04_夕方6時.md` |
| ⑤ | 21:00 | `0 12 * * *` | 秘書メール⑤ 夜21:00 振り返りと日記 | `05_夜9時.md` |

送信先は **stk.0911st@gmail.com（本人のみ）**。他の宛先・CC・転送は一切しない。

## ⚠ 既知のリスク: メール連携

Claude Code のセッションから作成した定期実行には **Gmail 連携を付けられない**
（`connectors` パラメータが組織で無効）。そのため、発火したセッションが
メール送信ツールを持てず、**送信できない可能性がある**。

- 各プロンプトには「メール送信ツールが使えない場合は、その旨と原因を報告に明記する」
  という指示を入れてあるため、失敗は黙殺されず通知に出る。
- **もしメールが届かない場合は、claude.ai の「Routines」画面から作り直すこと。**
  画面から作れば Gmail 連携が引き継がれる。各ファイルの中身をそのまま
  プロンプト欄に貼り付ければよい。

## 内容の作り分け

同じことを5回送らないよう、時間帯ごとに役割を変えている。

- **朝** … 一日の設計（期限・重複・予定・TODOの重要度順）
- **昼** … 午後の入り（短く。午後の予定と上位3件）
- **15時** … 折り返し（残り時間で片付くもの、出発時刻の目安）
- **18時** … 明日の準備（残タスクの判断、明日の予定と持ち物）
- **21時** … 振り返り（完了/未完了、日記作成、明日のTODO）

## 注意

- 宛先は**本人（stk.0911st@gmail.com）のみ**。他人への送信・CC・転送はしない。
- ⑤（21時）は日記作成まで行うため、既存の「夜レビュー・日記（毎晩23:00）」と内容が重複する。
  ⑤を稼働させたら、23時の定期実行は停止するか、バックアップとして残すかを決める。
