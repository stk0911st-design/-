# 定期メール設定（1日5回）

本人宛に 1日5回、秘書からの連絡メールを送るための設定。

## 重要な制約

Claude Code のセッションからは**メール連携付きの定期実行を作成できない**
（`connectors` パラメータが組織で無効のため、作成した定期実行はメール送信ツールを持てない）。

→ **claude.ai の「Routines（定期実行）」画面から作成すること。**
   画面から作れば Gmail 連携が引き継がれ、メール送信ができる。

## 設定する5本

| # | 時刻（JST） | 名前 | ファイル |
|---|---|---|---|
| ① | 08:00 | 秘書メール① 朝・今日の段取り | `01_朝8時.md` |
| ② | 12:00 | 秘書メール② 昼・午前の締めと午後の入り | `02_昼12時.md` |
| ③ | 15:00 | 秘書メール③ 午後3時・折り返し確認 | `03_午後3時.md` |
| ④ | 18:00 | 秘書メール④ 夕方6時・今日の締めと明日の先出し | `04_夕方6時.md` |
| ⑤ | 21:00 | 秘書メール⑤ 夜・振り返りと明日のTODO | `05_夜9時.md` |

各ファイルの中身をそのまま Routines のプロンプト欄に貼り付ける。

## 注意

- 宛先は**本人（stk.0911st@gmail.com）のみ**。他人への送信・CC・転送はしない。
- ⑤（21時）は日記作成まで行うため、既存の「夜レビュー・日記（毎晩23:00）」と内容が重複する。
  ⑤を稼働させたら、23時の定期実行は停止するか、バックアップとして残すかを決める。
