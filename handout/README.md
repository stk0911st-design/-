# お客さま説明用 市況資料（配布版）の作り方

`customer-market-handout.html` が配布PDFの元データです。毎月、数値を差し替えて
PDFに書き出し、Slack `#312-営業-不動産市況調査版_pdf_お客様説明用-` へ投稿します。

## PDFへの書き出し

日本語フォント（IPAゴシック）と Chromium が入った環境で実行します。

```bash
google-chrome --headless --disable-gpu --no-sandbox \
  --virtual-time-budget=4000 --no-pdf-header-footer \
  --print-to-pdf="いまの不動産市場_お客さま用_YYYY-MM-DD.pdf" \
  customer-market-handout.html
```

A4縦・4ページで出ます。ブラウザで開いて「印刷 → PDFに保存」でも同じものが作れます。

## 毎月差し替える箇所

| 章 | 差し替える数値 | 出所 |
| --- | --- | --- |
| 1 | フラット35・変動・10年固定の金利 | 住宅金融支援機構、各金融機関 |
| 1 | 返済額の試算表 | 金利が動いたら再計算する |
| 2 | 中古マンションの成約価格・件数・在庫・㎡単価 | 東日本レインズ Market Watch（毎月10日前後） |
| 2 | 新築マンションの平均価格・初月契約率 | 不動産経済研究所（月中旬〜下旬） |
| 3 | 価格帯別の成約率（図） | 更新頻度が低い。出所の新しい集計が出たときだけ |

図は本文中にインラインSVGで書いてあります。数値を変えるときは、
`<circle cx=...>` の x 座標と、その横のラベル文字列の両方を直してください。
x 座標は `250 + 成約率 / 18 * 440` で求まります。

## 守ること

- **当社の取引数字・お客さま情報は入れない。** 公表統計と報道のみで作ります。
- **出典と作成日を必ず残す。** 5章と最終行です。
- **社内向けの販売ロジックは入れない。** 「言わないこと」の一覧や価格帯別の
  リソース配分は社内用資料のほうに書きます。この資料はお客さまがご覧になります。
