# 第5期 営業目標 進捗（週次メール）

A3横1枚の「第5期 営業目標 進捗」を毎週つくり直して、メールで送るための仕組みです。

## 毎週の手順（3ステップ）

1. **数字を集める**
   - 成約（契約・決済）… 日報カウンターに登録された成約情報
   - 金額（売上・粗利）… 経営管理シート（小林管理）
2. **`data/fy5.json` を書き換える** — 変更するのはこのファイルだけです。単位はすべて **万円**。
   - `asOf` / `asOfLabel` / `baseNote` … 基準日
   - `fiscal.elapsedMonths` / `remainingMonths` … 経過・残りヶ月
   - `totals` … 全社の実績・予定実績
   - `monthlyGross` … 月別の粗利（`actual`＝契約済・決済済／`forecast`＝契約前の見込）
   - `members` … 担当者別
   - `weeklyNotes` … **全員に出せる** 申し送り
   - `notesKobayashiOnly` … **小林さんあてだけ** に出す申し送り
3. **生成する**

```bash
python3 build.py                    # 小林さんあて（金額あり）
python3 build.py --audience team    # 全員あて（金額をすべて非表示）
```

`out/` に PDF（A3横）・メール本文（HTML／テキスト）・Slack投稿文が出ます。

## 配信（毎週 月曜 8:30／Slack）

| あて先 | チャンネル | 内容 |
| --- | --- | --- |
| 全員（14名） | `#04_日報`（`C04SJC6TUNS`） | `out/slack_<日付>_team.txt`。**金額なし**（達成率と件数のみ） |
| 小林さんのみ | `#00会社目標等`（`C09HXHX7J7K`） | `out/slack_<日付>_kobayashi.txt`。金額あり（確認用） |

`#04_日報` には社用メールのない廣石さん・居松さん・相澤さんも入っているため、
Slackなら全員に届きます（メールでは3名に届きません）。

投稿はこの2か所だけ。他のチャンネルには投稿しません。

## 金額の扱い（重要）

小林さんの指示により、**金額（売上・粗利・預金残高・借入残高・買付金額・査定額）は
社内メンバーあてにも書きません**。

- `--audience kobayashi` … 金額あり。**小林さんのみ**（`#00会社目標等` ／ メールなら本人の3アドレス）。
- `--audience team` … 金額を一切出さず、達成率（％）と件数だけにする。全員あてはこちら。

`team` で生成するときは、成果物に金額表記が混ざっていないかスクリプトが機械的に確認し、
見つかった場合はファイルを書き出さずに停止します。

申し送りも出し分けます。`weeklyNotes` は全員に出るもの、`notesKobayashiOnly` は
小林さんあてだけに出るもの（数字の差異や社内の申し送りはこちら）。

定例の月曜配信は小林さんの承認済みです。文面の型を変えるときは、事前に小林さんの承認をもらってください。

## 数字の定義（元資料と同じ）

- 予定実績 ＝ 実績 ＋ 見込
- 残り／目標まで ＝ 年間目標 − **予定実績**
- 必要なペース ＝（年間目標 − 予定実績）÷ 残りヶ月数

## 必要なもの

```bash
pip install playwright   # PDF 化に Chromium を使います（ブラウザ本体の追加DLは不要）
```
