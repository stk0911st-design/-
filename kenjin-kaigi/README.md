# 賢人会議

尊敬する人の「考え方の型」を模したAIに相談できる1枚もののWebアプリです。
質問を書くと、選んだ人がそれぞれの判断軸で答え、複数人を選んだ場合は「議長のまとめ」まで出ます。

公開URL: https://claude.ai/code/artifact/3bdc2b5c-38da-44b6-bd73-03854bae7610

## 重要な前提（非公式であること）

- 回答は **AIによる創作** です。ご本人の発言・見解ではありません。
- 公開されている著書・発言から推定した「判断の軸・価値観・語り口」を模しています。
- ご本人および所属企業とは一切関係がありません。画面上にもその旨を常時表示しています。
- 実在の発言をそのまま引用しないよう、プロンプト側で明示的に禁止しています。

## 収録している賢人（初期値）

| 人物 | 模している判断の軸 |
| --- | --- |
| スティーブ・ジョブズ | 「何をやらないか」で決める／体験から逆算する／削って研ぎ澄ます |
| 熊谷正寿 | 紙に書いて日付を入れる／人生の年表から逆算／No.1になれる領域を選ぶ |
| 堀江貴文 | まず動く／試行回数を増やす／常識と世間体を疑う／時間を最優先 |
| 藤田晋 | 意思決定の質と量／人と組織文化／撤退ラインを決めてから賭ける |

画面の「＋ 賢人を追加」から、自分で人物を登録することもできます。
（名前・肩書き・考え方を書くと、その型で答えます）

## 使い方

1. 上部で出席者を選ぶ（複数選択可）。
2. 相談内容を書いて「相談する」。
3. 各人が回答（1分ほどかかります）。2人以上選ぶと最後に「議長のまとめ」が出ます。
4. 回答カード下の入力欄から、その人にだけ深掘りの追加質問ができます。
5. 相談は「これまでの相談」に残ります。クリックで読み直せます。

`Ctrl`（`⌘`）＋`Enter` でも送信できます。

## 回答の形式

各人とも次の見出しで返します。読み比べやすくするため、形式は全員そろえています。

- ■ 結論
- ■ なぜそう考えるか
- ■ 今日からやること
- ■ 逆に聞きたい

## 技術メモ

- `index.html` 1ファイルのみ。ビルド不要。
- Claude Artifact の runtime capability を使用。
  - `sample`：ページからClaudeに問い合わせる（**APIキー不要**。閲覧者のClaude利用分を消費します）
  - `db`：相談履歴の保存
- 履歴は `db`（アプリ側の保管領域）と `localStorage` の両方に保存し、
  `db` が使えない環境ではローカルのみで動作します。**履歴の自動削除はしません**（上限100件）。
- 更新する場合は `index.html` を編集して、同じURLへ再公開します。

## 注意

- 公開URLは初期状態では非公開（自分だけ）です。共有はページの共有メニューから明示的に行ってください。
- 相談内容には社内の固有名詞や機密情報を書かないことを推奨します。
