# 秘書ノート

Claude が会話をまたいで覚えておくための記録場所です。
会話で「これを覚えて」と伝えられた内容は、ここに整理して保存します。

## 使い方

1. 覚えてほしいことをチャットで伝える（案件の経緯、取引先、決めたルールなど）。
2. Claude が該当ファイルに追記してコミットする。
3. 毎朝・毎晩の整理は `daily/` と `todo.md` に反映される。

## 書かないもの

- 預金残高・借入残高など社内資金に関する金額
- 個人の自宅住所・私用電話番号・家族の情報
- 健康・病歴などのセンシティブな情報

## ファイル一覧

| ファイル | 内容 |
| --- | --- |
| `profile.md` | 本人・会社の基本情報と指示の一覧 |
| `todo.md` | 現在のTODO。重要度順 |
| `daily/YYYY-MM-DD.md` | 日記。`daily/_template.md` を複製して使う |
| `projects/<案件名>.md` | 案件ごとの経緯。`projects/_template.md` を複製して使う |
| `contacts.md` | 取引先・関係者の業務連絡先 |
| `rules.md` | 社内の運用ルール・定型表記 |
