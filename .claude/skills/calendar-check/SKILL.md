# カレンダー確認

確認するカレンダー（会社用・個人用など）は、ユーザー設定から読む。アドレスはリポジトリに書かない。

## 手順
1. 接続されている**すべてのカレンダー**の対象期間の予定を取得する。
2. 重複や、同じ時間の予定の衝突を見つけて、時系列でまとめる。
3. 朝の整理（`/morning-routine`）では、今日の予定として使う。

## 書き込み
- 予定の登録・変更・削除は、内容を見せて**確認を取ってから**行う。
- 削除は、対象を確認し、必要性を説明してから行う。迷ったら残す。
- 招待メールが外部に送られる登録は、送る前に必ず確認する。

## 禁止
- 金額（資金・残高など）を予定のタイトルや説明に書かない。
