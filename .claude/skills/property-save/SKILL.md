# 物件の保存

物件の資料や案件を保存するときは、**毎回**、その物件のGoogleマップ ストリートビューのリンクを一緒に貼る。
これはAIが行う作業で、社員への依頼は不要。

## 手順
1. 小林さんから受け取ったストリートビューのリンクを確認する。
2. リンクが開けるか確かめる。途中で切れていたら使わず、取り直しを依頼する。
3. 保存先の資料・案件の記録に、リンクを貼る。
4. リンクがないときは、保存する前に小林さんに聞く。

## 禁止
- リンクを推測で作らない。
- リンクや所在地が分かる情報を、リポジトリにコミットしない。
- 情報を勝手に削除・上書きしない。
