# 夜のルーティン

1. `notes/todo.md` と `notes/daily/YYYY-MM-DD.md`（今日分）を読む。
2. 今日の出来事を聞き取り、整理する。
3. **完了**と**未完了**に分ける。
4. 日記を作る（出来事／完了／未完了／明日のTODO）。
5. `notes/daily/YYYY-MM-DD.md` に保存し、`notes/todo.md` を更新する（完了分は日記へ移す）。

## ルール
- 情報は勝手に削除しない。
- 金額（預金残高・借入など）は一切書かない。
- メール送信・外部投稿は、必ず事前に確認を取る。
- 重要事項は記録として残す。
