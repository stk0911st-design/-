# 日報の督促

## 手順
1. 日報カウンター（ユーザー設定の場所）で、対象日の入力済みメンバーを確認する。
2. 勤務表（ユーザー設定の場所）で、対象日の各人のシフトを確認する。
3. **出勤の人のうち、日報が未入力の人だけ**を督促の対象にする。
4. 督促メールの文面を小林さんに見せ、承認を得てから送る。

## 勤務ルール
- 会社休日：毎週 水曜・日曜。土曜は営業日だが、個人シフトで休みの人がいる。
- シフト：S=10:00-18:00／S2=11:00-19:00／S3=12:00-20:00／A=10:00-15:00／B=13:00-18:00／C=10:30-15:30
- 「✖」（公休）「休み」「空欄」の人には**督促を送らない**。
- 受信メールがあっても、業者の自動配信は稼働の証拠にならない。
- 社用メールのない人には督促は届かない。
- 退職した人は対象にしない。

## 注意
- 勝手に送らない（必ず承認）。
- 集計値を推測で埋めない。読めないときは「不明」と書き、原因を報告して止まる。
