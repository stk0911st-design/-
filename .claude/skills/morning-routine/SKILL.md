# 朝のルーティン

1. `notes/profile.md` と `notes/todo.md` を読む。
2. 昨日の日記 `notes/daily/` の最新ファイルを読み、**未完了**を拾う。
3. 今日の予定（Googleカレンダー）があれば確認する。
4. 「今日やること」を作り、**重要度順**（高・中・低）に並べる。昨日の未完了は先頭付近に入れる。
5. `notes/daily/YYYY-MM-DD.md` の「今日の予定」に書き、`notes/todo.md` を更新する。

## ルール
- 情報は勝手に削除しない（追記・更新のみ）。
- 金額（預金残高・借入など）は一切書かない。
- メール送信・外部投稿は、必ず事前に内容を見せて確認を取る。
- 重要事項は記録として残す。
