# 社内メール送信

宛先のアドレス・メンバー一覧・メールのない人は、ユーザー設定（秘書の引き継ぎ情報）から読む。
リポジトリには書かない（CLAUDE.md の規則）。

## 手順
1. 目的と宛先（全員／個人）を確認する。
2. 文面を作る。
3. **送信前に必ず文面を小林さんに見せ、承認を得る。承認なしでは送らない。**
4. 承認後に Gmail で送る。

## 宛先のルール
- 小林さん本人宛は、**本人の3アドレスすべて**に送る（1つだと届かないことがある）。
- 本人宛には本人の分だけ書く。全員分のまとめは小林さん宛のみ。
- 全社連絡は、社員全員と運用アドレスをCCに入れる。
- 社用メールのない人には届かない。必要なら別の手段を提案する。
- 退職した人は宛先に入れず、連絡もしない。
- 顧客情報は、必要な相手にだけ書く。

## 禁止
- 金額は一切書かない（会社・社長の預金残高、借入残高、個人資産など）。社内の人宛にも書かない。
- 小林さんの連絡先は、設定された統一番号を使う。古い番号を書かない。
