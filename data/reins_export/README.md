# ここにレインズのエクスポートCSVを置いてください

| データ | 置き場所 |
| --- | --- |
| 売出（販売中）物件 | `売出/` |
| 成約物件 | `成約/` |

- ファイル名は自由（`*.csv` を全部読みます）。複数ファイルでもOK
- 文字コードは Shift_JIS（cp932）／UTF-8 どちらでも自動判別します
- 前日のファイルは上書きでも別名でも構いません（正規化済みデータが
  `data/snapshots/` に日付ごとに残るので、差分はそこから計算します）
- **成約物件は必ず `成約/` へ。** 売出と混ざると「新規成約」の判定ができません

検索条件は `docs/レインズ検索手順.md` にまとめてあります。

**このフォルダの中身は .gitignore で除外されており、リポジトリにコミットされません。**
レインズの情報は会員規約により会員外への提供・公開ができないため、意図的にそうしています。

## 想定している列名

`config/field_mapping.json` に「正規化名 → 候補列名」の対応表があります。
手元のCSVの列名が入っていない場合は、そこに追記すれば対応できます。
