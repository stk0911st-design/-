# 営業日報 まとめメール自動化

営業日報アプリ（Google Apps Script + スプレッドシート「日報カウンター」）に入力された内容を、
朝・夕にまとめてメール送信するための自動化です。

## 仕様

| 項目 | 内容 |
| --- | --- |
| 入力元 | 日報カウンター（GASアプリ）の記録先スプレッドシート |
| 集計対象 | 「更新日時」が対象日に該当する入力レコード |

3つの送信タイミングがあります。

| タイミング | 対象日 | 宛先 | 内容 |
| --- | --- | --- | --- |
| 平日 毎朝 8:00（JST） | 火〜金＝前日1日分／月＝前週の金・土・日3日分 | 小林様（1件・設定値） | 前営業日分のまとめ |
| 毎朝 9:30（JST） | 当日 | 担当者ごと個別 | 「本日分を入力してください」＋入力ボタン |
| 毎晩 20:00（JST） | 当日 | 小林様（設定により担当者全員をCC） | 当日分のまとめ、未入力者への注意文 |

※ 9:30 と 20:00 の送信は、担当者のメールアドレス一覧など追加の設定
（`STAFF_EMAILS` など）がある場合のみ有効になります。未設定の場合は
8:00 の送信のみが従来どおり行われます。詳細は `gas/README.md` を参照。

※ スプレッドシートID・宛先アドレスなどの社内情報はこのリポジトリには置かず、
実行環境側（Claude のルーティン設定、または Apps Script のスクリプトプロパティ）で管理します。

## データ構造

スプレッドシートには2つの表があります。

**集計表**

`週開始日 / 担当者 / 架電 / メール / 物件情報取得 / 査定 / 訪問・面談 / 現地調査 / 買付・価格提示 / 契約 / その他 / 合計 / コメント`

**生データ表**（この表を集計に使用）

| 列 | 内容 |
| --- | --- |
| key | `report｜<週開始日>｜<担当者>` |
| value | JSON文字列 |
| 更新日時 | 入力（保存）された日時（JST） |

value の JSON キー対応:

| JSONキー | 日本語 |
| --- | --- |
| call | 架電 |
| mail | メール |
| information | 物件情報取得 |
| assessment | 査定 |
| visit | 訪問・面談 |
| site | 現地調査 |
| offer | 買付・価格提示 |
| contract | 契約 |
| other | その他 |
| memo | コメント |
| staff | 担当者 |
| week | 週開始日 |

### 注意：カウンターは「週単位の累計値」

日報アプリのカウンターは週ごとの累計値であり、日別の増分ではありません。
そのため「対象日に入力（保存）があったレコードの、その時点の週累計値」をまとめる形になります。
メール本文でもその旨を明記します。

## 実装方式

2通りの実装を用意しています。

### 1. Claude のルーティン（現在稼働中）

平日 8:00 JST にこのセッションを起こし、スプレッドシートを読み取って集計・送信します
（前営業日分のまとめを小林様へ）。9:30 の担当者リマインドと 20:00 の当日まとめ・全員CC配信は
まだこの方式では稼働しておらず、設定と社内確認が済み次第 `docs/routine-prompt.md` に追記して
有効化します。

- 長所：導入済みで追加作業なし。文面を柔軟に調整できる。
- 短所：Claude 側のセッション／コネクタ状態に依存する。

### 2. Google Apps Script（`gas/DailyReportMailer.gs`）

スプレッドシート側に時間主導トリガーを設定して送信する方式。
Claude に依存せず動き続けるため、恒久運用にはこちらが確実です。

導入手順は `gas/README.md` を参照。
