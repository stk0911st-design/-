# 営業日報 まとめメール自動化

営業日報アプリ（Google Apps Script + スプレッドシート「日報カウンター」）に入力された内容を、
翌営業日の朝に担当者へまとめてメール送信するための自動化です。

## 仕様

| 項目 | 内容 |
| --- | --- |
| 入力元 | 日報カウンター（GASアプリ）の記録先スプレッドシート |
| 集計対象 | 「更新日時」が対象日に該当する入力レコード |
| 対象日 | 火〜金の配信＝前日1日分／月曜の配信＝前週の金・土・日3日分 |
| 配信タイミング | 平日 毎朝 8:00（JST） |
| 宛先 | 社内の指定アドレス1件（設定値として管理） |
| 送信方法 | 自動送信 |

※ スプレッドシートID・宛先アドレスなどの社内情報はこのリポジトリには置かず、
実行環境側（Claude のルーティン設定、または Apps Script のスクリプトプロパティ）で管理します。

## データ構造

スプレッドシートには2つの表があります。

**集計表**

`週開始日 / 担当者 / 架電 / メール / 物件情報取得 / 査定 / 訪問・面談 / 現地調査 / 買付・価格提示 / 契約 / その他 / 合計 / コメント`

**生データ表**（この表を集計に使用）

| 列 | 内容 |
| --- | --- |
| key | `report｜<週開始日>｜<担当者>` |
| value | JSON文字列 |
| 更新日時 | 入力（保存）された日時（JST） |

value の JSON キー対応:

| JSONキー | 日本語 |
| --- | --- |
| call | 架電 |
| mail | メール |
| information | 物件情報取得 |
| assessment | 査定 |
| visit | 訪問・面談 |
| site | 現地調査 |
| offer | 買付・価格提示 |
| contract | 契約 |
| other | その他 |
| memo | コメント |
| staff | 担当者 |
| week | 週開始日 |

### 注意：カウンターは「週単位の累計値」

日報アプリのカウンターは週ごとの累計値であり、日別の増分ではありません。
そのため「対象日に入力（保存）があったレコードの、その時点の週累計値」をまとめる形になります。
メール本文でもその旨を明記します。

## 実装方式

2通りの実装を用意しています。

### 1. Claude のルーティン（現在稼働中）

平日 8:00 JST にこのセッションを起こし、スプレッドシートを読み取って集計・送信します。
設定は `docs/routine-prompt.md` を参照。

- 長所：導入済みで追加作業なし。文面を柔軟に調整できる。
- 短所：Claude 側のセッション／コネクタ状態に依存する。

### 2. Google Apps Script（`gas/DailyReportMailer.gs`）

スプレッドシート側に時間主導トリガーを設定して送信する方式。
Claude に依存せず動き続けるため、恒久運用にはこちらが確実です。

導入手順は `gas/README.md` を参照。

# 不動産株 値上がり率TOP3 日次メール

東証33業種区分「不動産業」の上場銘柄のうち、その日の値上がり率が高い上位3社を
毎日21時（JST）にメール送信します。

## 仕様

| 項目 | 内容 |
| --- | --- |
| 対象 | 東証33業種区分「不動産業」の上場銘柄（REIT・ETFは含まない） |
| 指標 | 当日終値 ÷ 前営業日終値 − 1（値上がり率） |
| 抽出 | 値上がり率の高い順に上位3社 |
| 除外 | 出来高が下限以下の銘柄、株価を取得できなかった銘柄 |
| 配信タイミング | 毎日 21:00（JST）。土日祝など取引がない日は送信しない |
| 宛先 | 指定アドレス1件（設定値として管理） |
| 送信方法 | 自動送信 |
| データ出所 | GOOGLEFINANCE（Google Finance） |

※ 宛先などの情報はこのリポジトリには置かず、Apps Script のスクリプトプロパティで管理します。

## 実装方式

`gas/RealEstateTop3Mailer.gs`（Google Apps Script）。
株価はスプレッドシート上の GOOGLEFINANCE 関数から取得するため、外部の株価サイトや
APIキーは不要です。Claude のセッション状態にも依存せず動き続けます。

対象銘柄は「銘柄マスタ」シートで管理し、JPX が公開している上場銘柄一覧から
33業種区分「不動産業」の銘柄を取り込んで作成します（`importUniverseFromJpx`）。

導入手順は `docs/real-estate-top3-setup.md` を参照。
