# 個人秘書システム

日々の段取り・振り返り・記録を蓄積する個人リポジトリ。
生活の記録はすべて [`MY-LIFE/`](MY-LIFE/) 以下。
運用ルールの本体は [`MY-LIFE/CLAUDE.md`](MY-LIFE/CLAUDE.md)。

## 使い方

- 朝 → 「**朝ブリーフお願い**」（毎朝 8:00 JST に自動実行）
- 夜 → 「**夜レビューお願い**」（毎晩 23:00 JST に自動実行）
- それ以外は普通に話しかければ、該当フォルダに振り分けて記録します。

## 構成

```
MY-LIFE/
├── CLAUDE.md            秘書の運用ルール（必読）
├── 01_今日やること/      TODO.md ＋ 完了アーカイブ/
├── 02_予定/             月別予定・定例予定
├── 03_日記/             YYYY/MM/YYYY-MM-DD.md
├── 04_アイデア/          思いつき・やりたいこと
├── 05_旅行/             行き先候補・旅程・記録
├── 06_バイク/           整備記録・ツーリング・期限管理
├── 07_お金/             固定費・支出メモ（金額詳細は private/）
├── 08_Note/             note 記事の下書き（公開は要確認）
├── 09_X投稿/            X 投稿の下書き（投稿は要確認）
└── 10_資料保管/          プロフィール・重要事項・テンプレート

private/                機密情報の置き場（.gitignore 済み・push されない）
scripts/new-day.sh      当日の日記ファイルを作成
```

## 守っていること

- 情報は勝手に削除しない（完了TODOはアーカイブへ、記録の訂正は追記で）
- 外部への投稿・メール送信（X / note / メール / Slack）は**全文を提示して承認を得てから**
- 会社・取引先・個人の機密はコミットしない（`private/` に置き、記録上は `A社` 等に抽象化）
- 重要事項は `MY-LIFE/10_資料保管/重要事項.md` に残す
- 過去の履歴を読んでから対応する

## 優先度の凡例

| 記号 | 意味 |
|---|---|
| `[S]` | 最優先（今日中必須・期限あり） |
| `[A]` | 重要 |
| `[B]` | 通常 |
| `[C]` | 余力があれば |
| `[-]` | 保留（何待ちかを明記） |

状態: `- [ ]` 未完了 / `- [x]` 完了 / `- [>]` 繰越 / `- [~]` 中止（理由必須）
