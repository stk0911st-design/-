# 社内業務の自動化

社内の定型業務を Google Apps Script + スプレッドシートで自動化したものをまとめています。

| 仕組み | 内容 | ドキュメント |
| --- | --- | --- |
| 営業日報 まとめメール | 日報アプリの入力を翌営業日の朝にまとめて送る | このファイル ／ `docs/routine-prompt.md` |
| 恵比寿 物件在庫の日次蓄積 | 恵比寿の売り物件を毎日ためて、在庫数と月次の動きを追う | `docs/ebisu-land-stock-quickstart.md`（まず試す）／ `docs/ebisu-land-stock.md`（仕様） |

※ スプレッドシートID・宛先アドレスなどの社内情報はこのリポジトリには置かず、
実行環境側（Claude のルーティン設定、または Apps Script のスクリプトプロパティ）で管理します。

# 恵比寿 物件在庫の日次蓄積

渋谷区・恵比寿エリアの売り物件（土地／戸建／アパート／ビル／マンション区分所有）を
毎日ためて、「今日で何件あるか」「今月どの種別が何件はけたか」「その推移」を出し続けます。

| 項目 | 内容 |
| --- | --- |
| 入力元 | レインズの書き出しCSV、自社で集めた情報、収集アプリからのPOST |
| 蓄積先 | スプレッドシート（物件マスタ／日次サマリ／月次サマリ／価格履歴） |
| 実行 | 毎日1回 `runDailyLandStock`（Apps Script のトリガー） |
| 出力 | 毎朝のまとめメール、または Claude ルーティンからの報告 |
| 答え合わせ | 国交省「不動産情報ライブラリ」の取引価格情報（四半期・任意） |

掲載が消えた件数は「掲載終了」として数えます。成約と取下げの合計であり、
成約件数そのものではありません。詳しくは `docs/ebisu-land-stock.md`。

まず試すなら `docs/ebisu-land-stock-quickstart.md`（20分）。手元のリストを1回入れて、
在庫件数と集計が出るところまで確認できます。毎日の収集方法はその後に決められます。

関連ファイル：`gas/LandStock.gs` ／ `gas/LandStockMailer.gs` ／ `gas/LandStockReinfolib.gs` ／
`test/landstock.test.js` ／ `docs/ebisu-land-stock-quickstart.md` ／ `docs/ebisu-land-stock.md` ／
`docs/ebisu-land-stock-routine.md`

# 営業日報 まとめメール自動化

営業日報アプリ（Google Apps Script + スプレッドシート「日報カウンター」）に入力された内容を、
翌営業日の朝に担当者へまとめてメール送信するための自動化です。

## 仕様

| 項目 | 内容 |
| --- | --- |
| 入力元 | 日報カウンター（GASアプリ）の記録先スプレッドシート |
| 集計対象 | 「更新日時」が対象日に該当する入力レコード |
| 対象日 | 火〜金の配信＝前日1日分／月曜の配信＝前週の金・土・日3日分 |
| 配信タイミング | 平日 毎朝 8:00（JST） |
| 宛先 | 社内の指定アドレス1件（設定値として管理） |
| 送信方法 | 自動送信 |

## データ構造

スプレッドシートには2つの表があります。

**集計表**

`週開始日 / 担当者 / 架電 / メール / 物件情報取得 / 査定 / 訪問・面談 / 現地調査 / 買付・価格提示 / 契約 / その他 / 合計 / コメント`

**生データ表**（この表を集計に使用）

| 列 | 内容 |
| --- | --- |
| key | `report｜<週開始日>｜<担当者>` |
| value | JSON文字列 |
| 更新日時 | 入力（保存）された日時（JST） |

value の JSON キー対応:

| JSONキー | 日本語 |
| --- | --- |
| call | 架電 |
| mail | メール |
| information | 物件情報取得 |
| assessment | 査定 |
| visit | 訪問・面談 |
| site | 現地調査 |
| offer | 買付・価格提示 |
| contract | 契約 |
| other | その他 |
| memo | コメント |
| staff | 担当者 |
| week | 週開始日 |

### 注意：カウンターは「週単位の累計値」

日報アプリのカウンターは週ごとの累計値であり、日別の増分ではありません。
そのため「対象日に入力（保存）があったレコードの、その時点の週累計値」をまとめる形になります。
メール本文でもその旨を明記します。

## 実装方式

2通りの実装を用意しています。

### 1. Claude のルーティン（現在稼働中）

平日 8:00 JST にこのセッションを起こし、スプレッドシートを読み取って集計・送信します。
設定は `docs/routine-prompt.md` を参照。

- 長所：導入済みで追加作業なし。文面を柔軟に調整できる。
- 短所：Claude 側のセッション／コネクタ状態に依存する。

### 2. Google Apps Script（`gas/DailyReportMailer.gs`）

スプレッドシート側に時間主導トリガーを設定して送信する方式。
Claude に依存せず動き続けるため、恒久運用にはこちらが確実です。

導入手順は `gas/README.md` を参照。
