# 不動産デイリーチェック

毎日の不動産情報チェックを半自動化する仕組みです。
**レインズ（不動産流通標準情報システム）へのログイン・自動巡回は行いません。**

## なぜレインズを直接見に行かないのか

- レインズは宅建業者専用のクローズドシステムで、会員ID・パスワードが必要
- 会員規約により、会員以外への情報提供や自動収集・スクレイピングは禁止
- そのため「レインズからの取得は会員が手動で行い、その後の正規化・比較・レポート化を
  自動化する」という役割分担にしている

## 全体の流れ

```
[手作業] レインズで検索 → CSVエクスポート
            ↓ data/reins_export/売出/ と /成約/ に保存
[自動] normalize_reins.py … 文字コードと列名の揺れを吸収して日次スナップショット化
[自動] diff_snapshots.py  … 前日比で 新規売出 / 値下げ・値上げ / 掲載終了 / 新規成約 を検出
[自動] fetch_public.py    … 国交省「不動産情報ライブラリ」から公開の取引価格を取得
[自動] daily_report.py    … 監視リストごとに章立てしたレポートを出力
```

手作業ぶんの具体的な検索条件は **[docs/レインズ検索手順.md](docs/レインズ検索手順.md)** にまとめてあります。

## 使い方

```bash
# 1. 当日のレインズCSVを置く
#    data/reins_export/売出/  … 販売中（売出）物件
#    data/reins_export/成約/  … 成約物件
# 2. 一括実行
./run_daily.sh

# 3. 当日のレポートを見る
cat data/reports/$(date +%F).md
```

個別に動かす場合:

```bash
python3 scripts/normalize_reins.py            # CSV -> data/snapshots/<日付>.json
python3 scripts/diff_snapshots.py --json      # 差分をJSONで確認
python3 scripts/fetch_public.py               # 公開データの取得（要APIキー）
python3 scripts/daily_report.py               # レポート生成
```

Python 3.9+ の標準ライブラリのみで動きます（追加インストール不要）。

## 監視リスト

`config/watchlists.json` に4本登録済みです。

| # | 監視リスト | 対象エリア | 対象データ |
| --- | --- | --- | --- |
| 1 | アパート 1億〜2億 | 東京23区・市川市・船橋市・横浜市（戸塚区/泉区/瀬谷区）・厚木市・大和市 | 売出・成約 |
| 2 | 土地・戸建 2億〜4億 | 同上 | 売出・成約 |
| 3 | いわき市好間 全物件 | 福島県いわき市好間 | 売出・成約 |
| 4 | 新宿区原町 中古マンション 5000万〜7500万 | 東京都新宿区原町 | 売出・成約 |

### 条件の書き方

| 項目 | 意味 | 例 |
| --- | --- | --- |
| `対象データ` | 売出・成約のどちらを見るか | `["売出", "成約"]` |
| `エリアグループ` | 「エリアグループ」で定義した名前を参照 | `"首都圏メイン"` |
| `物件種目` | 部分一致（いずれか一致） | `["土地", "戸建"]` |
| `価格下限` / `価格上限` | 万円単位。`null` は無制限 | `20000` / `40000` |
| `土地面積下限` / `建物面積下限` | ㎡ | `100` |
| `駅徒歩上限` | 分 | `10` |
| `築年下限` | 西暦 | `2000` |
| `含むキーワード` / `除くキーワード` | 全項目を対象に含む／含まない判定 | `["角地"]` / `["借地"]` |

エリアの `含む` は **文字列なら単独一致、配列なら「すべて含む(AND)」** です。
`["横浜市", "戸塚区"]` と書くことで、他市の同名区を誤って拾わないようにしています。
`除外` は `含む` より優先されます（横浜市の 栄区・港南区・磯子区・南区・金沢区 を除外指定済み）。

横浜市の範囲を市内全域（除外5区を抜いた13区）に広げたい場合は、監視リストの
`エリアグループ` を `"首都圏メイン（横浜市全域版）"` に書き換えるだけで切り替わります。

### 列名が拾われないとき

`config/field_mapping.json` が「正規化名 → 候補列名」の対応表です。
手元のCSVの列名をここに追記すれば対応できます。

### 公開データのAPIキー（任意）

国土交通省「不動産情報ライブラリ」の取引価格情報APIを使う場合のみ必要です。

```bash
export REINFOLIB_API_KEY="申請して取得したキー"
```

未設定でも日次処理は止まらず、参考相場のセクションが省略されるだけです。

## 出力

- `data/snapshots/YYYY-MM-DD.json` … 正規化済みの当日データ（差分計算の元）
- `data/reports/YYYY-MM-DD.md` … 日次レポート
- `data/public/` … 公開データのキャッシュと相場サマリー

## 情報の取り扱い

- `data/` 配下は `.gitignore` で除外しており、リポジトリには一切コミットされません
- レインズ由来の物件情報は会員規約の範囲内でのみ利用してください（会員外への提供・公開は不可）
- スナップショットは自動削除しません（過去の差分を追えるように残します）
