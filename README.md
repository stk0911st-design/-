# 営業日報 まとめメール自動化

営業日報アプリ（Google Apps Script + スプレッドシート「日報カウンター」）に入力された内容を、
翌営業日の朝に担当者へまとめてメール送信するための自動化です。

## 仕様

| 項目 | 内容 |
| --- | --- |
| 入力元 | 日報カウンター（GASアプリ）の記録先スプレッドシート |
| 集計対象 | 「更新日時」が対象日に該当する入力レコード |
| 対象日 | 火〜金の配信＝前日1日分／月曜の配信＝前週の金・土・日3日分 |
| 配信タイミング | 平日 毎朝 8:00（JST） |
| 宛先 | 社内の指定アドレス1件（設定値として管理） |
| 送信方法 | 自動送信 |

※ スプレッドシートID・宛先アドレスなどの社内情報はこのリポジトリには置かず、
実行環境側（Claude のルーティン設定、または Apps Script のスクリプトプロパティ）で管理します。

## データ構造

スプレッドシートには2つの表があります。

**集計表**

`週開始日 / 担当者 / 架電 / メール / 物件情報取得 / 査定 / 訪問・面談 / 現地調査 / 買付・価格提示 / 契約 / その他 / 合計 / コメント`

**生データ表**（この表を集計に使用）

| 列 | 内容 |
| --- | --- |
| key | `report｜<週開始日>｜<担当者>` |
| value | JSON文字列 |
| 更新日時 | 入力（保存）された日時（JST） |

value の JSON キー対応:

| JSONキー | 日本語 |
| --- | --- |
| call | 架電 |
| mail | メール |
| information | 物件情報取得 |
| assessment | 査定 |
| visit | 訪問・面談 |
| site | 現地調査 |
| offer | 買付・価格提示 |
| contract | 契約 |
| other | その他 |
| memo | コメント |
| staff | 担当者 |
| week | 週開始日 |

### 注意：カウンターは「週単位の累計値」

日報アプリのカウンターは週ごとの累計値であり、日別の増分ではありません。
そのため「対象日に入力（保存）があったレコードの、その時点の週累計値」をまとめる形になります。
メール本文でもその旨を明記します。

## 実装方式

2通りの実装を用意しています。

### 1. Claude のルーティン（現在稼働中）

平日 8:00 JST にこのセッションを起こし、スプレッドシートを読み取って集計・送信します。
設定は `docs/routine-prompt.md` を参照。

- 長所：導入済みで追加作業なし。文面を柔軟に調整できる。
- 短所：Claude 側のセッション／コネクタ状態に依存する。

### 2. Google Apps Script（`gas/DailyReportMailer.gs`）

スプレッドシート側に時間主導トリガーを設定して送信する方式。
Claude に依存せず動き続けるため、恒久運用にはこちらが確実です。

導入手順は `gas/README.md` を参照。

# 都心3区 高級マンション ウォッチ

千代田区・中央区・港区の高級マンション（既定で1億円以上）について、
**売れたもの**と**いま売り出ているもの**を1つのスプレッドシートに蓄積し、
坪単価・経過日数・値下げ率を自動計算して週次でメール配信します。

## 仕様

| 項目 | 内容 |
| --- | --- |
| 対象エリア | 千代田区（13101）・中央区（13102）・港区（13103） |
| 対象種別 | 中古マンション等 |
| 高級帯の定義 | 取引価格 1億円以上（`MIN_PRICE` で変更可） |
| 成約データ | 国土交通省「不動産情報ライブラリ」API（XIT001） |
| 売出データ | `売出ウォッチ` シートへ手入力（公開ポータル・自社情報から） |
| 取り込み | 毎週月曜 朝（直近8四半期を再取得。重複は追加しない） |
| 価格改定 | 売出価格を書き換えると `価格履歴` に自動記録 |
| 配信 | 毎週月曜 朝（任意） |

## 坪単価の計算

坪単価は情報サイトの表示値を使わず、必ず次の式で計算しています。

```
坪単価 = 取引価格 ÷ (専有面積㎡ ÷ 3.305785)
```

サイトによっては坪単価と㎡単価が取り違えられていることがあるためです
（実例は `docs/market-snapshot-2026-09.md` に記載）。

## この環境からの直接取得について

Claude の実行環境からは、レインズ・国土交通省・不動産ポータル各社への
アウトバウンド接続が組織のネットワークポリシーで遮断されています（HTTP 403）。
そのためデータ取得は Apps Script 側（ご自身の Google アカウント）で行う構成にしています。
