# 個人秘書システム

日々の段取り・振り返り・記録を蓄積するための個人リポジトリ。
運用ルールの本体は [`CLAUDE.md`](CLAUDE.md)（セッション開始時に自動で読まれる）。

## 使い方

朝:
```
朝ブリーフをお願い
```
→ 昨日の未完了の確認 → 今日の予定 → 今日やること（重要度順）を提示し、`todo/active.md` を更新。

夜:
```
夜レビューをお願い
```
→ 今日の出来事の整理 → 完了/未完了の仕分け → 日記の作成 → 明日のTODO作成。

## 構成

```
CLAUDE.md              秘書の運用ルール（必読）
memory/
  profile.md           基本情報・進め方の好み
  important.md         重要事項の記録（追記のみ・削除禁止）
  rules.md             運用ルール詳細
todo/
  active.md            現在のTODO（今日／明日以降／待ち）
  archive/YYYY-MM.md   完了アーカイブ（削除せず移動）
diary/YYYY/MM/YYYY-MM-DD.md   日記
templates/             朝ブリーフ・夜レビュー・日記・週次のひな形
scripts/new-day.sh     当日の日記ファイルを作成
private/               機密情報の置き場（.gitignore 済み・push されない）
```

## 守っていること

- 情報は勝手に削除しない（完了TODOはアーカイブへ、日記は追記で訂正）
- 外部への投稿・メール送信は必ず事前確認（下書きまでは可、送信は承認後）
- 会社・業務・個人の機密はコミットしない（`private/` に置き、記録上は `A社` 等に抽象化）
- 重要事項は `memory/important.md` に残す
- 過去の履歴を読んでから対応する

## 優先度の凡例

| 記号 | 意味 |
|---|---|
| `[S]` | 最優先（今日中必須・期限あり） |
| `[A]` | 重要 |
| `[B]` | 通常 |
| `[C]` | 余力があれば |
| `[-]` | 保留（何待ちかを明記） |

状態: `- [ ]` 未完了 / `- [x]` 完了 / `- [>]` 繰越 / `- [~]` 中止（理由必須）
