# 補助金・助成金ウォッチ（毎週木曜 9:00 JST メール配信）

当社が申請できそうな補助金・助成金を毎週チェックし、要件と必要書類をまとめてメール配信するための知識ベースです。
配信ルーティンの設定は `docs/subsidy-routine-prompt.md` を参照。

## 絞り込み条件（当社プロフィール）

| 項目 | 値 |
| --- | --- |
| 業種 | 不動産業（売買・仲介） |
| 所在地 | 東京都 |
| 常時使用する従業員数 | 6〜20人 |
| 当面の投資・取組テーマ | 採用・賃上げ・人材育成 |

※ 具体的な宛先アドレス等の社内情報はこのリポジトリには置かず、ルーティン設定側で管理します。

### この条件から導かれる前提

- 中小企業基本法上、不動産業は「その他の業種」＝資本金3億円以下 **または** 従業員300人以下。当社は国の中小企業向け補助金の対象。
- **小規模事業者持続化補助金は対象外**。同制度の「小規模事業者」は商業・サービス業（不動産業を含む）で常時使用する従業員 **5人以下** が条件のため、6〜20人の当社は申請できない。毎週の調査ではこの制度を候補から外す。
- 主戦場は **厚労省の雇用関係助成金 ＋ 東京都・東京しごと財団の奨励金**。設備・IT投資が発生した場合のみ経産省系の補助金を検討する。

## 優先度A：締切が近い／当社テーマに直結

### A-1. 業務改善助成金（厚生労働省）

| 項目 | 内容 |
| --- | --- |
| 内容 | 事業場内最低賃金を引き上げ、あわせて生産性向上のための設備投資等を行った場合に費用を助成 |
| 助成上限 | 最大600万円（助成率 最大4/5） |
| コース | 50円／70円／90円の3コース（令和8年度から30円コースは廃止、50円以上の引上げが必須） |
| 令和8年度受付 | 2026年9月1日開始 |
| **締切（東京都）** | **2026年9月30日**（＝地域別最低賃金の発効日の前日。東京都は 2026年10月1日に1,280円へ改定・54円引上げ。「発効日の前日」と「11月30日」の早い方が締切） |
| 主な要件 | ①事業場内最低賃金と地域別最低賃金の差額が規定内であること ②賃金引上げ計画・業務改善計画を**事前に**作成し交付申請すること ③申請 → 交付決定 → 賃金引上げ・設備導入 → 実績報告 の順序を守ること |
| 必要書類 | 交付申請書、事業実施計画書、賃金引上げ計画、賃金台帳、労働者名簿、就業規則（賃金規程）、見積書（原則相見積）、事業場の登記事項証明書 等 |

**当社の当てはまり／要確認**：東京都は地域別最低賃金が全国最高（2026年10月から1,280円）のため、**事業場内の最低時給が1,280円＋数十円の範囲に収まっているか**が最大の関門。パート・アルバイト・事務職に低い時給帯がなければ対象外になる可能性が高い。まず自社の最低時給を確認すること。締切が9月末で最短、**確認は最優先**。

- 公式：厚生労働省「業務改善助成金」／東京労働局

### A-2. 手取り時間創出・魅力ある職場づくり推進奨励金（東京都・東京しごと財団）

| 項目 | 内容 |
| --- | --- |
| 内容 | 多様で柔軟な働き方の推進、エンゲージメント向上、賃金引上げ等に取り組む都内企業への奨励金 |
| 奨励金額 | 取組内容に応じて **最大264万円** |
| 対象 | 都内で事業を営む中小企業等（常時雇用する労働者 300人以下） |
| 募集方式 | **事前エントリー制**。令和8年度は第1回が2026年5月20日開始、**各回140社／全10回**の予定 |
| 主な要件 | 就業規則の整備、働き方改革に資する制度導入、賃金引上げ等（回次ごとの募集要項で確認） |
| 必要書類 | 事前エントリー → 支給申請書、就業規則、賃金台帳、労働者名簿、登記事項証明書、都税の納税証明書 等 |

**当社の当てはまり**：従業員規模・所在地とも要件を満たす。賃上げ・人材定着がテーマの当社に最も相性が良い制度。**各回140社の先着枠**があるため、次回エントリー開始日の把握が重要（毎週の調査で回次と残枠状況を必ず確認する）。

- 公式：公益財団法人東京しごと財団 特設サイト（tokyo-engagement.jp）

### A-3. キャリアアップ助成金 正社員化コース（厚生労働省）

| 項目 | 内容 |
| --- | --- |
| 内容 | 有期・パート等の非正規雇用労働者を正社員に転換した場合に助成 |
| 支給額 | 中小企業 1人あたり40万円／重点支援対象者は2期分で最大80万円。年間20人まで |
| 令和8年度の加算 | **情報公表加算**を新設。転換等の情報を自社サイトまたは「しょくばらぼ」で公表すると1事業所あたり20万円 |
| 主な要件 | ①雇用保険適用事業所 ②**キャリアアップ管理者の配置** ③**キャリアアップ計画を転換前に労働局へ提出** ④就業規則等に転換制度を規定 ⑤転換後6か月分の賃金支払い ⑥転換前後で賃金3%以上増額 |
| 必要書類 | キャリアアップ計画書、支給申請書、就業規則（転換規定）、雇用契約書（転換前後）、賃金台帳、出勤簿、労働者名簿 |

**当社の当てはまり**：営業アシスタント・事務職の正社員化があれば直結。**「先に計画書を出す」順序を守らないと不支給**になる点が最大の落とし穴。転換予定があるなら今すぐキャリアアップ計画書の提出を。

### A-4. 東京都正規雇用転換安定化支援助成金（東京都）

| 項目 | 内容 |
| --- | --- |
| 内容 | 国のキャリアアップ助成金（正社員化コース）に**上乗せ**する東京都独自の助成金 |
| 助成額 | 対象労働者1人20万円×**最大5人**（令和8年度に3人→5人へ拡大）＋加算：退職金制度10万円／結婚・出産支援制度10万円／介護支援制度10万円（新設）／賃上げ 1人12万円×最大5人 → **最大190万円** |
| 受付 | 令和8年5月1日より受付中 |
| 主な要件 | ①東京労働局管内の雇用保険適用事業所 ②2023年4月1日以降の正社員転換で**キャリアアップ助成金（正社員化コース）の支給決定を受けていること** ③3年間の指導・育成計画の作成、指定講習受講者による指導、退職金制度・両立支援制度の整備、賃上げ等の取組 |
| 必要書類 | 申請書、キャリアアップ助成金の支給決定通知書の写し、育成計画書、就業規則・退職金規程、賃金台帳 等 |

**当社の当てはまり**：A-3 とセットで狙う「合わせ技」。**A-3 の支給決定が前提**なので、A-3 の計画提出を起点に逆算して動く。

### A-5. 人材開発支援助成金（厚生労働省）

| 項目 | 内容 |
| --- | --- |
| 内容 | 従業員に職務に関連した訓練を実施した場合に、経費・賃金の一部を助成 |
| 主なコース | 人材育成支援コース／教育訓練休暇等付与コース／人への投資促進コース／事業展開等リスキリング支援コース（中小企業は経費助成 **最大75%**） |
| 主な要件 | ①**職業能力開発推進者の選任** ②**事業内職業能力開発計画**の作成・周知 ③訓練開始日の**6か月前〜1か月前**までに「職業訓練実施計画届」を東京労働局へ提出 |
| 必要書類 | 職業訓練実施計画届、訓練別の対象者一覧、事業内職業能力開発計画、カリキュラム、訓練委託契約書・見積書、支給申請書、賃金台帳、出勤簿 |

**当社の当てはまり**：宅建士資格支援、営業研修、査定・不動産DXのリスキリング等が対象になり得る。**訓練開始1か月前までの計画届**が必須なので、研修の実施予定が決まった時点で即動く。

## 優先度B：設備・IT投資が発生したら検討

### B-1. デジタル化・AI導入補助金2026（旧 IT導入補助金）

- 令和7年度補正予算事業から「デジタル化・AI導入補助金」へ名称変更。AIを含むITツール導入費用を補助。
- 主な要件：**GビズIDプライム**の取得、**SECURITY ACTION**の宣言、**IT導入支援事業者（ベンダー）との共同申請**。
- 当社の想定用途：不動産CRM／追客・反響管理の自動化、査定書作成の効率化、電子契約。
- 公式：デジタル化・AI導入補助金2026 事務局（it-shien.smrj.go.jp）

### B-2. 中小企業省力化投資補助金（一般型／カタログ注文型）

- 人手不足解消のための省力化投資を補助。カタログ注文型は2026年3月19日に制度改定済み。
- 一般型：第8回の公募要領が2026年8月18日公開、**申請受付は2026年9月中旬、締切は10月中旬予定**、採択発表は2027年2月上旬予定。
- 主な要件：**GビズIDプライム**、労働生産性の向上目標、賃上げ計画。
- 公式：中小企業省力化投資補助金事務局（shoryokuka.smrj.go.jp）

### B-3. 新事業進出補助金 ／ ものづくり補助金

- 新事業進出補助金は最大9,000万円規模。2026年7月17日にスケジュール変更、応募締切は10月30日（金）18:00。
- 不動産業でも新規事業（例：リノベーション事業、不動産テック）への進出があれば射程に入る。現時点では優先度低。

## 共通の事前準備（申請の前提になるもの）

1. **GビズIDプライム** — 経産省系補助金でほぼ必須。**発行に2〜3週間**かかるため未取得なら今すぐ申請。
2. **SECURITY ACTION**（★一つ星／二つ星の自己宣言） — デジタル化・AI導入補助金で必須。
3. **就業規則**（労基署へ届出済のもの）、賃金規程、退職金規程
4. **賃金台帳・出勤簿・労働者名簿**（直近2年分）
5. **労働保険料の納付済み証明**（未納があると雇用関係助成金は不支給）
6. **登記事項証明書、直近2期分の決算書、都税・国税の納税証明書**
7. 商工会議所／商工会の会員であること（一部制度で有利）

## 毎週の調査でチェックすること

1. 優先度Aの各制度の **募集回次・受付開始日・締切** に動きがないか
2. 東京しごと財団の奨励金の **次回エントリー枠** の状況
3. 新規に公表された東京都・区市の中小企業向け助成金（特に人材・賃上げ系）
4. 締切まで30日を切った制度は **最上部に「至急」として掲載**
5. 数値・日付は必ず一次情報（各制度の公式サイト・公募要領）で裏取りし、不明な点は「要確認」と明記する
