# 物件紹介メール 検討先分類表（案）

物件紹介メールの送り先（買取業者・デベロッパー・投資家など）を、
**買う物件のジャンル別**に分けるための分類一覧。

- この段階では「分類の枠」だけを定める。各分類に入る会社・担当者は今後詰める。
- 1社が複数の分類に入ってよい（例：戸建用地とアパート用地の両方を買う会社）。
- 会社名・担当者名・メールアドレス・価格帯などの実データはこのファイルに書かない
  （リポジトリ外の名簿で管理する）。
- 分類コードは、今後の名簿・メール配信リストでタグとして使う想定。

## 今後詰める項目（各分類の中身）

各分類について、次の項目を名簿側で決めていく想定。

- 検討先の会社名・担当者・連絡先（名簿はリポジトリ外で管理）
- 対象エリア（都心・23区・首都圏・地方など）
- 対象規模（面積・戸数など）
- 価格帯（名簿側でのみ管理。メール本文・このファイルには書かない）
- 優先度（まず最初に送る先／二番手以降）
- 送付方法（メール一斉送信か個別送信か）と、送付前の確認フロー
