# Googleドライブのミラー保存（共有ドライブへの自動コピー） 導入手順

会社のGoogleドライブ（例：「02.SH書類」）の中身を、毎晩自動で
**Google Workspace の共有ドライブ**へコピーして保存します。保険（バックアップ）です。

- 共有ドライブに入ったファイルは**会社のもの**になります。社員が退職しても消えません。
- 社員は「**投稿者**」にします。ファイルの追加・編集はできますが、**削除はできません**。
- このスクリプトは**ファイルを一切削除しません**。コピー元で消されたファイルも、ミラー側に残ります。

使うファイル：`gas/DriveMirror.gs`

## しくみ

| 項目 | 内容 |
| --- | --- |
| コピー元 | 会社のフォルダ（個人のGoogleアカウントで共有しているもの） |
| コピー先 | Workspace の共有ドライブの中のフォルダ |
| 動く時間 | 毎日 1:00 以降に1周を開始。15分ごとに数分ずつ進め、終わったら翌日まで休む |
| 2回目以降 | 新しいファイルと、更新されたファイルだけをコピー |
| 更新されたファイル | 前のコピーの名前に「（旧版 日付）」を付けて残し、新しくコピー |
| コピーしないもの | 名前に「パスワード」「ログイン情報」を含むもの、指定したフォルダ（個人フォルダなど）、ショートカット、フォーム |
| 記録 | 「ミラー台帳」スプレッドシート（実行アカウントのマイドライブに自動で作成） |
| 報告 | 1周終わるたびに、指定のアドレスへ件数とエラーをメール |

## 用意するもの

- Google Workspace の**管理者アカウント**（以下「Workspace アカウント」）
- 共有ドライブが使えるプラン（使えない場合は相談してください）

## 手順1　共有ドライブを作る（Workspace アカウントで）

1. Workspace アカウントで Google ドライブを開き、左の「**共有ドライブ**」→「**＋ 新規**」を押す。
2. 名前を `SH書類_ミラー（自動コピー）` にして「**作成**」。
3. 共有ドライブ名の右の「▼」→「**メンバーを管理**」を開き、次のように追加する。
   - 社長（Workspace アカウント）：**管理者**
   - 社員：**投稿者**（追加・編集はできるが、削除・移動はできない）
4. 同じ「▼」→「**共有ドライブの設定**」で、
   「**共有ドライブ メンバー以外のユーザーにアクセスを許可**」を**オフ**にする。
5. 共有ドライブの中に、フォルダ `02.SH書類` を作る（ここがコピー先）。
6. 作ったフォルダを開き、アドレスバーの `folders/` の後ろの英数字（フォルダID）を控える。

### 個人フォルダもミラーする場合（推奨）

個人フォルダは本人と社長だけが見る場所なので、上の共有ドライブ（社員全員が見られる）には入れません。
別の共有ドライブを作ります。

1. 共有ドライブ `個人フォルダ_ミラー（社長のみ）` を作る。メンバーは**社長だけ**（管理者）。
2. 中にフォルダ `22_個人フォルダ` を作り、フォルダIDを控える。

## 手順2　コピー元を Workspace アカウントに共有する（今のアカウントで）

コピー元のフォルダを持っている（または編集できる）アカウントで行います。

1. Google ドライブで「02.SH書類」を右クリック →「**共有**」→「**共有**」。
2. Workspace アカウントのメールアドレスを入れ、権限を「**閲覧者**」にして「**送信**」。
3. 個人フォルダもミラーする場合は、「22_【個人フォルダ】」の**中の各個人フォルダ**を、
   同じように1つずつ Workspace アカウントに「閲覧者」で共有する
   （個人フォルダは上のフォルダからの権限を引き継がない設定のため、1つずつ必要です）。
4. 控えておくもの：「02.SH書類」のフォルダID、「22_【個人フォルダ】」のフォルダID。

## 手順3　スクリプトを作る（Workspace アカウントで）

1. Workspace アカウントで <https://script.google.com> を開き、「**新しいプロジェクト**」。
2. 左上の「無題のプロジェクト」を押して、名前を `ドライブ自動コピー` にする。
3. `コード.gs` の中身をすべて消し、`gas/DriveMirror.gs` の内容を貼り付けて「**保存**」（フロッピーのアイコン）。
4. 「**プロジェクトの設定**」（歯車アイコン）→「**タイムゾーン**」を
   `(GMT+09:00) 日本標準時 - 東京` にする。
5. 同じ画面の下「**スクリプト プロパティ**」→「**スクリプト プロパティを追加**」で次を入れて「**保存**」。

   | プロパティ | 値 |
   | --- | --- |
   | `MIRROR_JOBS` | コピーの組み合わせ（下の例） |
   | `REPORT_TO` | 報告メールの宛先（社長） |
   | `EXCLUDE_KEYWORDS` | （任意）名前に含まれていたらコピーしない言葉。カンマ区切り。未設定なら `パスワード,ログイン情報` |

   `MIRROR_JOBS` の例（`<…>` を控えたフォルダIDに置き換える。1行で入れてかまいません）：

   ```json
   [
     {"name": "SH書類", "source": "<02.SH書類のID>", "dest": "<共有ドライブ内 02.SH書類のID>",
      "exclude": ["<22_【個人フォルダ】のID>"]},
     {"name": "個人フォルダ", "source": "<22_【個人フォルダ】のID>", "dest": "<共有ドライブ内 22_個人フォルダのID>"}
   ]
   ```

   - 1つ目：会社のフォルダ全体。個人フォルダは `exclude` で外す。
   - 2つ目：個人フォルダだけを、社長のみの共有ドライブへ（ミラーしないなら2つ目は書かない）。
   - `name` は台帳の「ジョブ」欄に出る名前です。**あとから変えない**でください（変えると全部コピーし直しになります）。

## 手順4　確認する（コピーはされません）

1. 上の関数の選択欄で `previewMirror` を選び、「**実行**」。
2. 初回は「承認が必要です」と出るので、「**権限を確認**」→ Workspace アカウントを選ぶ →
   「**詳細**」→「**ドライブ自動コピー（安全ではないページ）に移動**」→「**許可**」。
3. 下の「実行ログ」に、ジョブごとに「直下のフォルダ ◯件・ファイル ◯件がコピー対象」
   「直下でコピーしないもの」が出れば OK。
   - 「コピーしないもの」に個人フォルダや ID・パスワードのファイルが入っているか確認してください。

## 手順5　開始する

1. 関数の選択欄で `setupMirror` を選び、「**実行**」。
2. 実行ログに「準備できました。台帳：…」と出れば完了です。
   - 左の「**トリガー**」（時計のアイコン）に `runMirror`（15分ごと）が1つ入っていることを確認。
3. 次の 1:00 以降から自動でコピーが始まります。
   - 初回はファイルが多いため、**数日かけて**少しずつコピーします。終わると報告メールが届きます。

止めたいときは `stopMirror` を実行します（台帳やコピー済みのファイルはそのまま残ります）。
再開は `setupMirror` をもう一度実行します。

## 注意

- **ふだんの作業は今までどおり「02.SH書類」で行います。** ミラー側で編集しても、元のフォルダには
  反映されません（元のファイルが更新されると、ミラー側の編集分は「旧版」として残ります）。
- コピーなので、**変更履歴やコメントは引き継がれません**。ファイルの中身は同じです。
- 元のフォルダの中でフォルダを別の場所へ移動しても、ミラー側は最初にコピーした場所のままです。
- 動画（朝礼・夕礼の録画など）を含めると容量が大きくなります。Workspace の保存容量を確認してください。
- Google の1日の上限に当たった場合は、その日はそこで止まり、次の実行で続きから再開します。
- 台帳（ミラー台帳）は消したり並べ替えたりしないでください。消すと全部コピーし直しになります。
- エラーが続くファイル（コピーが禁止されているファイルなど）は、報告メールの
  「うまくコピーできていないもの」に出ます。
