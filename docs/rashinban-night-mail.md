# 羅針盤 夜の実績メール

小林敏の司令塔ページ「羅針盤」に、その日 打ち込まれた内容と進み具合を、
本人あてに毎晩メールで送る自動化です。

| 項目 | 内容 |
| --- | --- |
| 送信時刻 | 毎日 21:00（途中経過）と 22:00（確定版）JST |
| cron（UTC） | `0 12 * * *` ／ `0 13 * * *` |
| 曜日 | 毎日（会社の休日も送る。入力がない日は「入力なし」と明記） |
| 宛先 | 小林敏の3アドレスすべて（本人あては3つとも送る運用） |
| 起動モード | 既存セッションを継続（コネクタを保持しているため） |
| データ元 | 羅針盤のデータベース（events / tasks / diary / state） |

## メールに載せる項目

1. 今日の予定（済んだものは「済」）
2. 今日できたこと（完了したやること）
3. 今日 新しく打ち込んだこと（追加したやること・予定）
4. いま残っているやること（3層それぞれの件数、重点は全件）
5. 繰越が溜まっているもの（2日以上放置しているもの、何日放置か）
6. 持ち越しの予定（済んでいない過去の予定）
7. 今日の日記（本文。締めがまだなら「未確定」と添える）
8. 目標の達成率（年・半期・今月の各％）
9. 秘書の所感 3行（重点の消化、繰越の溜まり、明日いちばん先に手を付けること）

22時の確定版には、これに加えて **明日の予定** を載せます。

## 守っているルール

- **金額は一切書かない。**データに金額が入っていても本文に出さない。達成率の％のみ可。
- 当日の入力が1件もなくても「本日の入力はありませんでした」と明記して必ず送る。
- 集計できないときはメールを送らず、原因を残して終了する。
- 社外秘。指定の3アドレス以外には送らない。外部サービスへ投稿しない。

## 注意（コネクタについて）

このルーティンは、対話セッションを起こして実行する方式です。
ルーティン自体にはコネクタが保存されていないため、新しいセッションを立てる方式に
切り替える場合は、claude.ai のルーティン画面から作り直す必要があります。
メールが届かない日が続いたときは、この点をまず疑ってください。
