# 夜の天気＆トピックスメール（Claude ルーティン）

毎日 20:00（JST）に、6都市の天気と最近の明るい話題を調べて本人あてにメールします。
営業日報とは関係のない個人向けの配信です。

| 項目 | 値 |
| --- | --- |
| cron（UTC） | `0 11 * * *` |
| 対応する日本時間 | 毎日 20:00（土日・祝日も配信） |
| 起動モード | 既存セッションを継続（Gmail コネクタを保持しているため。新規セッション方式ではコネクタが付かない） |
| 使うコネクタ | Gmail |
| 対象都市 | 軽井沢・草津（群馬県草津町）・札幌・釧路・福岡・那覇 |

JST 20:00 は UTC 11:00 で日付が変わらないため、曜日の指定は不要です。

## 天気の取り方について

この実行環境のネットワーク設定では、天気サイト（tenki.jp、Yahoo!天気、気象庁、Open-Meteo）に
直接アクセスできません。そのため Web 検索の結果から数値を拾います。
検索で拾えなかった値は推測で埋めず「取得できず」と書きます。

数値をより確実に取りたい場合は、環境設定の Network access に
`api.open-meteo.com` や `www.jma.go.jp` を許可ドメインとして追加すると、
直接取得に切り替えられます。

## ルーティンのプロンプト

宛先アドレスは伏せています。実際のルーティンには実値を入れて登録してください。

```text
【定期実行】夜の天気＆トピックスメールを作って送信してください。

■ 対象都市（6都市）
軽井沢（長野県軽井沢町）／草津（群馬県草津町・草津温泉）／札幌／釧路／福岡（福岡市）／那覇

■ 手順
1. 今日の日付（JST）と明日の日付を確認する。
2. 各都市について WebSearch で「<都市名> 天気 明日 <M月D日>」などを検索し、
   明日の天気（晴れ・曇り・雨・雪）、最高気温、最低気温、降水確率を拾う。
   雨や雪の予報があれば必ず目立つように書く（☔ 雨、⛄ 雪）。
   数値が見つからなければ推測で埋めず「取得できず」と書く。
   天気サイトへの WebFetch はネットワーク設定で拒否されるので、検索だけで済ませる。
3. 各都市について「<都市名> ニュース 話題 <YYYY年M月>」などで検索し、
   ここ1週間ほどの話題を1〜2件選ぶ。読んで元気が出る話題
   （イベント、開業、スポーツの活躍、季節の見どころ、グルメなど）を優先し、
   事件・事故・訃報は選ばない。見つからなければ季節の見どころで代える。
   それぞれ出典のリンクを付ける。
4. Gmail の send_message で送信する。
   宛先：<RECIPIENT>（本人の3アドレスすべて）
   件名：「【今夜の天気とトピックス】M月D日(曜)」
   htmlBody：「小林さん、今日もお疲れさまでした。」で始め、
     ① 明日の天気の一覧表（都市／天気／最高／最低／降水確率）
     ② 都市ごとのトピックス（見出し＋1〜2行の説明＋出典リンク）
     ③ 最後に一言（明日も良い一日を、など）
     ④「※本メールは Web 検索の結果を自動でまとめたものです。」
   ※宛先の3アドレスはいずれも本人専用（社員が見る共有アドレスではない）。
   スマホで読みやすいよう、表は6行・4〜5列に収め、文字は大きめにする。

■ 注意
- 会社・社員・顧客・金額の情報は一切書かない（天気と各都市の公開ニュースだけ）。
- 宛先以外には送らない。
- 送信後、件名と取得できなかった項目があればそれを報告して終了。
```
