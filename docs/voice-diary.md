# 音声日記

話すだけで日記になるページです。営業日報の仕組みとは完全に別で、こちらは個人用です。

**ページ**: https://claude.ai/code/artifact/156e026b-15be-4822-a6f8-d50baacb1dd0

（このリンクは自分のアカウント専用です。共有しない限り他の人からは見えません）

## 使い方

1. ページを開く（スマホのホーム画面に追加しておくと毎晩ラク）
2. 真ん中の丸いボタンを押して、今日あったことを話す
3. 話し終わったらもう一度ボタンを押し、文字を確認して **記録する**
4. 何回でも足せます。1日分が時刻つきで並びます
5. 夜、**メモから日記をつくる** を押すと、その日のメモから日記本文・ひとこと・明日やることができます
6. 文面は自分で書き直せます。直した内容がそのまま保存されます

## 3通りの入力

| 方法 | 使う場面 |
| --- | --- |
| 丸いボタン（音声認識） | PC・Android のブラウザ。話した内容がその場で文字になる |
| キーボードのマイク | iPhone で確実に入れたいとき。入力欄をタップ → キーボードのマイクで話す |
| 手入力 | 静かな場所、細かい直し |

iPhone の Safari はブラウザ内の音声認識が途中で止まることがあります。
止まる場合は入力欄をタップして、キーボードのマイクを使ってください。同じ欄に入ります。

## 保存のしかた

- 入力するたびに、その端末（ブラウザ）とサーバー側の両方に保存されます
- サーバー側にも入るので、スマホで入れてPCで見る、ができます
- **自動では消えません。** 消えるのは「消す」ボタンか、メモの「削除」を押して確認したときだけです
- 右下の **ぜんぶ書き出す（.md）** で、全期間をテキストファイルとして手元に落とせます

保存の形（1日1件）:

```
days/<YYYY-MM-DD>
  date       … 日付
  notes[]    … { id, at（記録時刻）, text（話した内容） }
  diary      … 日記本文
  todos[]    … 明日やること
  mood       … 今日をひとこと
  updatedAt  … 最終更新
```

## 毎晩のルーティン（設定済み）

毎晩22時ごろに Claude 側が自動で動き、その日の吹き込みから日記と明日のTODOをまとめます。

| 項目 | 値 |
| --- | --- |
| ルーティン名 | 音声日記 夜のまとめ（毎晩22:00） |
| cron（UTC） | `0 13 * * *` |
| 対応する日本時間 | 毎日 22:00 ごろ |
| 起動 | 毎回あたらしいセッション（コネクタ不要のため） |
| 通知 | 完了時にスマホへプッシュ |

動き:

- 吹き込みが0件の日は、何も書き込まず「今日はまだ吹き込みがありません」とだけ知らせる
- 日記が既に入っている日は上書きしない（自分で書いた文章が優先）
- 前日のTODOのうち、完了が確認できないものは「持ち越し」として明日のTODOの先頭に入る

ページ上の **メモから日記をつくる** を押せば、その場でも同じことができます。
ルーティンは「押し忘れた日の受け皿」です。

登録に使ったプロンプト:

```text
【定期実行】音声日記の時間です。

1. 音声日記のページ（アーティファクト）の days コレクションを読み、今日の日付のメモを確認する。
2. メモがあれば、日記本文・明日やることを整えて同じ日付のドキュメントに書き戻す。
   メモに書かれていないことは足さない。既存の日記本文がすでに手書きで直されている場合は上書きしない。
3. メモが0件なら、何も書き込まず「今日はまだ吹き込みがありません」とだけ知らせる。
4. 未完了のTODOは翌日に持ち越して、明日のTODOの先頭に置く。

記録は勝手に消さないこと。外部への送信はしないこと。
```

ページ上の **メモから日記をつくる** を押せば、その場でも同じことができます。
ルーティンは「押し忘れた日の受け皿」として使うのがおすすめです。
