# 不動産業界トレンド週次レポート（ルーティン設定）

毎週、不動産大手の売上・利益の発表実績を調べ、読みやすい PDF にまとめて小林さんへ送ります。

> **運用変更（2026-10-30）**：毎週月曜の自動実行は停止しました（設定は削除せず無効化）。
> 今後は毎週土曜に、担当者が調査して小林さんへ Slack で共有します。
> 下の設定は、再開する場合の参照用に残しています。

| 項目 | 値 |
| --- | --- |
| cron（UTC） | `47 23 * * 0` |
| 対応する日本時間 | 毎週月曜 8:47 |
| 起動モード | 新しいセッションを毎回起動 |
| 必要なコネクタ | Slack、Gmail |
| 送り先 | 小林さん本人のみ（Slack DM。送れなければ Gmail） |

## 調査対象

| 区分 | 企業 | 見る範囲 |
| --- | --- | --- |
| 戸建て（最重点） | 飯田グループホールディングス（一建設・飯田産業・東栄住宅・タクトホーム・アーネストワン・アイディホーム 等の各社） | 月次の販売・受注実績、直近決算の売上・営業利益・粗利 |
| 戸建て（最重点） | オープンハウスグループ | 月次・四半期の売上・営業利益・粗利、仲介・戸建・マンション別 |
| 総合大手 | 積水ハウス、大和ハウス工業、住友林業、旭化成ホームズ 等 | 直近決算の売上・営業利益・粗利 |
| 買取再販・建築 | 上記以外の買取再販・戸建分譲の上場企業 | 直近決算の売上・営業利益・粗利 |

- 数字は各社の IR（決算短信・月次開示）の発表値をそのまま使う。
  読めなかった項目は「不明」と書き、推測で埋めない。
- 各数字に「出典（資料名・発表日）」を必ず添える。
- 前回レポートから更新があった企業は「NEW」を付け、前期比・前年同期比も載せる。

## PDF の構成

1. 今週のポイント（3〜5行）
2. 飯田グループ：直近の実績と推移
3. オープンハウスグループ：直近の実績と推移
4. 大手一覧表（売上・営業利益・粗利・前年比・発表日）
5. 業界トレンドメモ（金利、地価、新設住宅着工などの動き）
6. 出典一覧

## ルーティンのプロンプト

宛先などの実値は伏せています。登録時に実値を入れてください。

```text
【定期実行】不動産業界トレンド週次レポートの時間です。次の手順で実行してください。

1. Web 検索で、飯田グループHD・オープンハウスグループ・積水ハウス・大和ハウス工業・
   住友林業・旭化成ホームズ等の最新の売上・営業利益・粗利の発表値と、月次実績を調べる。
   IR 資料などの一次情報を優先し、数字は推測で補完しない。不明は「不明」と書く。
2. docs/weekly-industry-report.md の「PDF の構成」に沿って、A4 の読みやすい PDF を作る。
   日本語フォント（Noto Sans CJK 等）を使い、表は罫線・色分けで見やすくする。
3. Slack の DM で <RECIPIENT> へ、PDF を添付して送る。
   Slack で送れない場合は Gmail で <RECIPIENT> へ送る。
4. 送信後、送った先・ファイル名・更新のあった企業を報告して終了する。
   PDF が作れない、または数字を確認できない場合は送らず、原因を報告して止まる。

小林さん本人以外には送らない。社内情報（社員名・顧客情報・自社の金額）は一切含めない。
```

## 運用メモ

- 取り上げる企業の追加・削除は、この表を更新してからルーティンのプロンプトを直す。
- 決算発表が集中する時期（5月・8月・11月・2月）は更新企業が増える。
- 月次開示のない企業は、決算発表のたびに更新する。
