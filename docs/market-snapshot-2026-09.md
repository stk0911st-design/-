# 都心3区 高級マンション市況スナップショット（2026年9月5日時点）

千代田区・中央区・港区の高級マンション（1億円以上を目安）の売れ行きを見るための、
現時点で確認できた数値をまとめたものです。

> **数値の扱いについて**
> 出所によって「成約ベース」「売出（掲載）ベース」「新築」「中古」が混ざっています。
> 単価の水準が2倍近く違うのは、多くの場合この定義の違いです。
> 表の「区分」列を必ず見てから比較してください。

---

## 1. いちばん確度の高い数字（成約ベース・都心3区）

出所：東日本レインズの月例データをもとにした集計（ダイヤモンド不動産研究所）

| 項目 | 直近値 | メモ |
| --- | --- | --- |
| 都心3区 中古マンション 成約価格 | **1億3,095万円**（2026年7月） | 6月・7月と2カ月連続で上昇 |
| 同 年内の底 | 1億1,723万円（2026年5月） | 5月→7月で約 +11.7% |
| 都心3区 成約㎡単価 | **239.25万円/㎡**（2026年7月） | 坪換算 **約791万円/坪** |
| 在庫数 | 前年比 **約1.5倍** | 価格は上昇、在庫も膨張という「ねじれ」 |

### ここから読めること

- **価格は堅調だが、在庫が前年の1.5倍**。売り手が強気で出す→残る→でも高値成約は続く、
  という状態です。売出から成約までの期間（滞留日数）が今いちばん見るべき指標になります。
- 成約単価 約791万円/坪 は「都心3区の中古マンション全体」の平均です。
  高級帯（1億円超）はこの上に乗るので、後述の物件別データと桁が違う点に注意。

出所：不動産経済研究所ほか

| 項目 | 値 | 時点 |
| --- | --- | --- |
| 首都圏 新築平均価格 | 1億660万円（㎡単価 156.3万円） | 2026年5月 |
| 首都圏 新築平均価格 | 1億137万円（㎡単価 153.0万円） | 2026年6月 |
| 23区 億ション比率 | **63.5%**（過去最高圏） | 2026年5月 |
| 都心6区 平均価格 | 1億9,503万円（前年比 +20.2%） | 2026年5月 |
| 初月契約率 | 64.9% | 2026年5月 |
| 在庫（新築） | 6,270戸・5カ月連続圧縮 | 2026年5月 |
| 2025年の最高額物件 | 25億円（港区・新宿区） | 2025年 |

### ここから読めること

- 新築は**供給が細って在庫が減り、単価だけが上がる**局面。23区の新築の6割超が億超えで、
  「億ション」はもはや高級帯の指標として機能していません。
- 一方の中古（第1章）は**在庫が前年1.5倍**。新築と中古で在庫の方向が逆を向いています。
  中古の売却提案では、この在庫増を前提にした価格設定の説明が要ります。

| 麻布台ヒルズレジデンスB | 売出レンジ（1K〜2LDK） | 9,950万円 〜 3億9,450万円 | — |
| 麻布台ヒルズレジデンスB | 2LDK+S・88.67㎡（26.82坪） | 3億3,500万円 | **約1,249万円/坪** |

> 一部の情報サイトが三田ガーデンヒルズの平均坪単価を「284.4万円」と表示していますが、
> 同じページの㎡単価（443〜482万円/㎡）と整合しません。**明らかな誤値**なので使わないでください。
> 坪単価は必ず「価格 ÷（専有面積 ÷ 3.30578）」で自分で計算し直すのが安全です。

### 千代田区

番町（一番町〜六番町）が中核。千鳥ヶ淵沿い・大使館エリア。
中古の平均築年が23年と古く、**築古でも単価が落ちにくい**のがこのエリアの特徴です。

### 中央区

銀座・日本橋（都心型）と、晴海・勝どき・佃（湾岸タワー）で性格が大きく異なります。
中央区全体の平均を高級帯の判断に使うと湾岸に引っ張られるので、
**必ず町丁目で分けて**見てください。

## 5. 当面の着眼点（次回更新で確認すること）

1. **都心3区の成約㎡単価**が8月・9月も上昇を続けたか（3カ月連続なら基調転換）
2. **中古在庫の前年比1.5倍**が縮むか、さらに膨らむか
3. **売出から成約までの日数**（レインズの登録日と成約日の差）— 今いちばんの先行指標
4. 高級帯の**値下げ（価格改定）件数** — 在庫膨張が効いてくると最初にここに出ます
5. 新築の**初月契約率が70%を割り続けるか**（好調ラインは70%）
