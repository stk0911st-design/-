# 「今週の不動産ニュース」週報ルーティン

毎週火曜の朝に、不動産業界の今週の動きを1件にまとめて Slack に投稿するための
Claude ルーティンです。

## なぜ Claude のルーティンなのか

週報は2つの部分からできています。

| 部分 | 担当 | 理由 |
| --- | --- | --- |
| 株価の週間値上がり率TOP3 | Apps Script | 機械的に計算できる。Claude に依存させない |
| ニュース・数字・読み方 | Claude ルーティン | 調査と取捨選択の判断が必要 |

Apps Script が月曜21時に週次の数字をメールで出し、
翌朝のルーティンがそれを読み取って週報に差し込みます。

## 作成手順

このルーティンは **claude.ai のルーティン画面で作成してください。**
セッション側から作成するとコネクタ（Slack・Gmail・スプレッドシート）が
付与されず、起動しても何もできません。

1. claude.ai のルーティン画面を開く
2. 新しいルーティンを作成する
3. スケジュールを **毎週火曜 8:00** にする
4. コネクタに **Slack / Gmail / Google スプレッドシート** を付ける
5. 下のプロンプトを貼り付ける（`<SPREADSHEET_ID>` と `<CHANNEL_ID>` は実値に置き換える）

実値はこのリポジトリには置きません。ルーティンの設定画面に直接入れてください。

## プロンプト

```
毎週火曜の定期タスク：「今週の不動産ニュース」を作って Slack に投稿する。

## 目的

不動産業界の直近1週間の動きを、社内の誰でも読める形で1件にまとめ、
Slack のチャンネル <CHANNEL_ID> に投稿する。

## 手順

1. 直近1週間の不動産業界の動きを Web 検索で調べる。切り口は次のとおり。
   - 首都圏 中古マンション 成約価格・成約件数・在庫（レインズの月次）
   - 首都圏 新築マンション 価格・供給（不動産経済研究所の月次）
   - 地価・路線価・金利（政策金利と長期金利）
   - 不動産業界の制度・税制・法改正の動き
   - 買取再販、再建築不可・借地・共有持分に関わる話題

   その週にあらたに公表された一次データが無ければ、「無い」と書く。
   古い数字を今週のものとして書かない。

2. 株価の週間値上がり率TOP3を取る。
   Gmail を次のクエリで検索する。
     subject:不動産株 週間値上がり率TOP3 newer_than:8d
   件名に「テスト送信」を含むものは対象外。

   - 見つかれば、本文から 比較期間・順位・銘柄名・コード・週間騰落率・終値 を読み取る
   - 見つからなければ、この欄は「準備中」とし、
     Apps Script の設定が未了であることを1行書く
   - 自分で株価を検索して3社を作らない。断片的な情報から順位を推測しない

3. 補助として、スプレッドシート <SPREADSHEET_ID> の「週次履歴」シートを
   get_values で確認する。2 で読み取った週と同じ基準日の行があれば、その値を使う。

4. 投稿本文を次の構成で書く。

   - 見出し：今週の不動産ニュース（第N号）と対象期間
   - 冒頭1段落：その週の要旨を1〜2文
   - 要点3つ：箇条書き。数字を入れる
   - 数字の表：指標／時点／値／前年比など。各行に出典を添える
   - 読み方：買取再販の現場にどう効くか。3〜4項目
   - 株価 週間値上がり率TOP3：取れた場合のみ実数。取れなければ準備中
   - 出典：URL の一覧

   第N号の N は、同チャンネルの過去の投稿を slack_read_channel で確認して
   続きの番号にする。

5. Slack のチャンネル <CHANNEL_ID> に1件だけ投稿する。

## 守ること

- 数字は出典の公表値をそのまま使う。推測で埋めない。
  取れなかった項目は「—」または「準備中」と明示する。
- 集計主体や定義が違う数字を、横に並べて単純比較しない。
  時点と出典を必ず各行に添える。
- 成約価格（実際に売れた値）と売り出し価格（売主の希望値）を混同しない。
- 週刊誌やSNS発の情報は「裏付け未確認」と明記する。
- 投稿先は <CHANNEL_ID> のみ。他のチャンネルやメールには送らない。
- 1件にまとめる。複数投稿に分けない。
- 調べた結果どの指標も更新が無かった週は、そのことを短く書いて終える。
  埋めるために話を膨らませない。
```

## 時間割

| 曜日・時刻（JST） | 動くもの | 内容 |
| --- | --- | --- |
| 毎日 21時 | Apps Script | 日次の値上がり率TOP3をメール＋記録＋Slack |
| 月曜 21時 | Apps Script | 週間の値上がり率TOP3をメール＋記録＋Slack |
| 火曜 8時 | Claude ルーティン | 週報をまとめて Slack に投稿 |

火曜朝の週報が月曜夜の数字を使えるよう、週次は月曜に出しています。
曜日を変える場合は `setupWeeklyTop3Trigger` に `ScriptApp.WeekDay` の値を渡します。
