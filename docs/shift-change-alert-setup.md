# 勤務表の変更アラート 導入手順

勤務表のシフト（プルダウン）を**月が始まった後に**変更すると、変更した人の画面に
次のポップアップが出るようにします。

> 勤務表の予定が変更されました。
> ・〇〇さん 10/15：S → 休み
> 【必ず】サイボウズ ガルーンの予定（休み／出勤）も同じように変更してください。

あわせて、次の2つを自動で残します。

- 変更したセルに**メモ**（変更日時と「変更前 → 変更後」）を追記
- **「変更履歴」シート**に1行記録（変更日時・シート・氏名・対象日・変更前・変更後・変更した人）

使うファイル：`gas/ShiftChangeAlert.gs`

## アラートが出る条件

| 条件 | アラート |
| --- | --- |
| 月が始まった後（当月・過去の月のシート）でシフト欄を変更 | 出る |
| 来月以降のシート（月初前に組んでいる段階）を編集 | 出ない |
| 氏名の下の備考行、見出し、集計欄の編集 | 出ない |
| 同じ値を選び直した | 出ない |

## 導入手順

スプレッドシートの**編集権限がある人**が行います（オーナーアカウント推奨）。

1. 勤務表のスプレッドシートを開き、メニューの「**拡張機能**」→「**Apps Script**」を開く。
2. 左の「ファイル」の「＋」→「**スクリプト**」で新しいファイルを作り、名前を
   `ShiftChangeAlert` にする。
3. `gas/ShiftChangeAlert.gs` の内容をすべて貼り付け、「**保存**」（フロッピーのアイコン）を押す。
   - ※ すでに別のファイルに `function onEdit(` がある場合は、そのまま保存せずに相談してください
     （`onEdit` は1つしか置けません）。
4. 「**プロジェクトの設定**」（歯車アイコン）→「**タイムゾーン**」が
   `(GMT+09:00) 日本標準時 - 東京` になっているか確認する。
5. 動作確認：当月のシートで、だれかのシフトを1つ変えて、すぐ元に戻す。
   - ポップアップが2回出て、「変更履歴」シートが自動で作られ2行記録されれば完了。
   - 確認で付いたセルのメモは、セルを右クリック →「**メモを削除**」で消せます。

トリガーの追加や「承認」の操作は不要です（単純トリガーで動きます）。

## 注意

- 「変更した人」の欄は、Google の仕様でオーナー以外のアカウントだと空欄
  （「取得不可」）になることがあります。だれが変えたかを確定させたいときは、
  セルを右クリック →「**編集履歴を表示**」で確認してください。
- コピー＆貼り付けや連続入力で複数セルをまとめて変えた場合、変更前の値は
  「（不明）」と記録されます（Google の仕様で取得できないため）。
- 勤務表のレイアウト（日付の行＝13行目、氏名＝B列、シート名「YYYY年M月」）が
  変わったら、スクリプト冒頭の設定値を直してください。
