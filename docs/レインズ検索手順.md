# レインズでの検索条件メモ（毎日の手作業ぶん）

毎日ここを見ながらレインズで検索 → CSVエクスポート → 指定フォルダに保存、が唯一の手作業です。
慣れれば5分程度。レインズ側で検索条件を「登録済み条件」として保存しておくと、次回からは
呼び出すだけになります。

保存先:

| データ | 保存先フォルダ |
| --- | --- |
| 売出（販売中）物件 | `data/reins_export/売出/` |
| 成約物件 | `data/reins_export/成約/` |

同じフォルダに複数ファイルを置いても構いません（全部まとめて読み込みます）。

## エクスポート時の注意

- **成約物件は必ず「成約」フォルダへ。** 売出と混ざると「新規成約」の判定ができません。
- 文字コードは Shift_JIS でも UTF-8 でも自動判別します。
- ファイル名は自由です（前日と同じ名前で上書きしても問題ありません。
  正規化済みのデータが `data/snapshots/` に日付別で残るため、差分はそこから計算します）。
- 列名が違って項目が拾えないときは `config/field_mapping.json` に列名を追記してください。

## 取り込みと確認

```bash
./run_daily.sh                  # 正規化 → 公開データ取得 → レポート作成
cat data/reports/$(date +%F).md # 当日のレポートを表示
```
