## 運用手順

1. `data/brokers.json` を最新の調査結果で更新する
2. `python3 tools/build_broker_report.py` で `out/` に HTML とテキストを生成
3. HTML を Google ドライブの該当フォルダへ Google ドキュメントとして保存
4. 本文に保存先リンクを添えてメール送信

## データの信頼度マーク

本文の会社名に付く記号は出典の確からしさを表します。

| 記号 | 意味 |
| --- | --- |
| （無印） | 各社IR・プレスリリースなど一次情報で裏取り済み |
| ※ | 業界紙・集計サイト経由。年度ラベルの取り違えに注意 |
| ※※ | 未確認。次回までに補完する |

⑤「判断軸」は各社の公式方針ではなく、公表実績と実際の打ち手から組み立てた解釈です。
本文にもその旨を明記します。

## 年度表記のルール

日本の会計年度で統一します。

- FY2025 ＝ 2025年4月〜2026年3月 ＝ 2026年3月期 ＝「2025年度」

集計サイトは「2026年版」＝FY2025データ、のように1年ずれた見出しを付けることが多いので、
JSON に取り込む際は必ず決算期に読み替えてから入れること。

推進センターの「不動産業統計集20XX」は前年度（FY20XX-1）のデータです。

## 実行環境の制約

この環境では WebFetch と直接の curl がブロックされているため、調査は WebSearch の
結果で組み立てる。一次資料の PDF を開けないので、数字は複数の検索結果で突き合わせ、
裏が取れないものは空欄のまま「要補完」とし、推測で埋めない。
