# 業者向け 物件紹介メールの差し込み一斉送信（所要 20分ほど）

新宿区・豊島区の売買仲介業者へ、物件紹介メールを**1社ずつ個別に**送る仕組みです。
会社名を差し込んで送るので、宛名が「ご担当者様」止まりになりません。
BCC 一括ではないため、宛先アドレスが他社に見えることもありません。

使うスクリプトは `gas/BrokerBlastMailer.gs` です。

## 0. 先に用意するもの

| もの | 備考 |
| --- | --- |
| 業者名簿（会社名・メールアドレス） | **これが無いと始まりません。** 集め方は後述 |
| 物件概要書（PDF） | 添付用 |
| 間取図（PDF または JPG） | 添付用 |
| 物件の確定情報 | 間取り・専有面積・所在階・現況・媒介形態・引渡し時期 |
| 差出人情報 | 担当者名・TEL・FAX・宅建免許番号・住所 |

## 1. スプレッドシートを新規作成

1. Google ドライブで新しいスプレッドシートを作る
2. 名前を分かりやすく付ける（例：業者向け物件紹介メール）

## 2. Apps Script を開いてコードを貼る

1. そのスプレッドシートで **拡張機能 → Apps Script**
2. 最初から入っている `function myFunction() {}` を全部消す
3. `gas/BrokerBlastMailer.gs` の中身を全部貼り付ける
4. 保存（フロッピーのアイコン、または Ctrl+S）

スプレッドシートに紐付けて作ったので、`SPREADSHEET_ID` の設定は要りません。
別ファイルを対象にする場合だけ、**プロジェクトの設定 → スクリプト プロパティ** に
`SPREADSHEET_ID` を追加してください。

## 3. シートを作る

1. 上の関数の選択欄で `setupBrokerBlastSheets` を選び、**実行**
2. 初回は権限の確認が出ます
   - 「このアプリは確認されていません」→ **詳細** → **（プロジェクト名）に移動** → **許可**
   - ご自身が作ったスクリプトなので問題ありません
3. スプレッドシートに戻ると、`業者名簿` と `文面` の2つのタブができています

### `業者名簿` タブ

2行目から下に貼り付けていきます。

| 列 | 見出し | 内容 |
| --- | --- | --- |
| A | 会社名 | 差し込まれる名前。例：`株式会社〇〇不動産` |
| B | 宛名 | 担当者名。**空欄でよい**（空欄なら「ご担当者様」になる） |
| C | メールアドレス | 1セルに1件だけ。カンマ区切りは不可 |
| D | 配信停止 | `TRUE` なら送らない。返信で停止依頼が来たらここを立てる |
| E | 送信済み | 送信に成功すると自動で `TRUE` になる。**手で触らない** |
| F | 送信日時 | 自動で入る |
| G | エラー | 失敗した理由が自動で入る |

### `文面` タブ

B列に値を入れます。

| 行 | 項目 | 入れるもの |
| --- | --- | --- |
| B1 | 差出人名 | 例：`<自社名> 営業部` |
| B2 | 件名 | 件名を1行で |
| B3 | 本文 | 本文全文。`{{会社名}}` `{{宛名}}` が差し込み箇所 |
| B4 | 添付ファイルID | Google Drive のファイルID。複数ならカンマ区切り |
| B5 | 返信先アドレス | 任意。空欄なら送信アカウントに返信が来る |
| B6 | 控え用BCC | 任意。自社の控え用に1件だけ指定できる |

**文面は社内情報なのでリポジトリには置いていません。** このシートで管理します。
文言を直したいときはコードを触らず、B2・B3 を書き換えてください。

### 添付ファイルIDの調べ方

1. Google ドライブで物件概要書のファイルを右クリック → **リンクをコピー**
2. `https://drive.google.com/file/d/　ここがファイルID　/view?usp=...`
3. `/d/` と `/view` の間の文字列をコピーして B4 に貼る
4. 2つ以上添付するときはカンマで区切る

ファイルの共有設定は変えなくて構いません。スクリプトがご自身の権限で
読み取って添付するので、受信側には添付ファイルとして届きます。

## 4. 名簿をチェックする

1. `validateBrokerList` を選び、**実行**
2. **表示 → 実行ログ** を開く

次が出ます。

- 送信できる件数／配信停止／送信済み
- アドレスの形式エラーがある行
- 重複しているアドレス（後の行を外してください）
- 会社名が空欄の行
- Gmail の本日の残り送信可能数

形式エラーと重複を直してから次に進みます。

## 5. 文面を確認する（送信されません）

1. `previewBrokerBlast` を選び、**実行**
2. **実行ログ** に、1件目に実際に送られる件名・本文・添付ファイル名が出ます

ここで必ず目で確認してください。あわせて次の警告が出ていないか見ます。

- `⚠ 差し込まれていない箇所が残っています` → `{{　}}` の書き間違い
- `⚠ 未記入の【　】が N 箇所あります` → 間取り・面積・階などが未記入

**未記入の `【　】` が残っていると、送信も下書き作成もできません。**
業者に出す文面なので、空欄のまま出ない作りにしてあります。

## 6. 下書きで試す

1. まず名簿を**自分のアドレス1〜2件だけ**にして `createBrokerBlastDrafts` を実行
2. Gmail の下書きフォルダを開き、実物を確認する
   - 宛名が会社名に差し替わっているか
   - 添付が付いているか
   - 署名の免許番号・住所・TEL が正しいか
3. 問題なければ下書きを消し、本番の名簿に差し替える

自分宛てに1通だけ実送信して受信状態を見るのが、いちばん確実です。

## 7. 実送信

1. `sendBrokerBlast` を選び、**実行**
2. **実行ログ** に 送信／失敗／未送信 の件数が出ます

- 1回の実行で **50件** までです（`BATCH_LIMIT`）
- 送信できた行は `送信済み` が `TRUE` になり、次回の実行では飛ばされます
- 50件を超える名簿は、日を分けて何回か実行してください
- 1通ごとに約1.2秒の間隔を空けて送ります

### Gmail の1日の送信上限

| アカウント種別 | 1日の上限 |
| --- | --- |
| 無料の Gmail | 約100通 |
| Google Workspace | 約1,500通 |

`validateBrokerList` と `sendBrokerBlast` のログに、その時点の残り数が出ます。
上限に達すると未送信として残り、翌日の実行で続きが送られます。

## 8. 配信停止の依頼が来たら

「配信停止」と返信が来たアドレスを、その日のうちに止めます。

1. Apps Script のエディタで `markUnsubscribed` を選ぶ
2. ただし引数が必要なので、エディタ上で一時的に次の関数を作って実行するのが簡単です

```javascript
function 配信停止を反映() {
  markUnsubscribed('aaa@example.com, bbb@example.com');
}
```

3. 名簿の `配信停止` 列が `TRUE` になります
4. 名簿に無いアドレスはログに出ます（取引先からの依頼など、手で追加してください）

名簿の行を削除するのではなく `配信停止` を立てる形にしてあります。
うっかり同じ先へ再送しないためです。

## 法令上の注意

広告・宣伝を含むメールなので **特定電子メール法** の対象です。
本文の末尾に次を必ず入れてください（文面案には入れてあります）。

- 送信者の名称（会社名）
- 住所
- 問い合わせを受け付ける連絡先（メールアドレスまたは電話番号）
- 受信拒否（配信停止）の通知ができる旨とその宛先

事前の同意について、**インターネット上で公開されている法人・個人事業者の
業務用アドレス**宛であれば、同意なしに送信できます（法3条1項3号）。
個人のアドレスや、公開されていないアドレスには送らないでください。

## 名簿の集め方

公開されている業務用アドレスを使います。候補は次のとおりです。

| 方法 | 内容 |
| --- | --- |
| レインズの会員情報 | 会員業者の商号・所在地・連絡先。最も確実 |
| 全日本不動産協会の会員名簿 | 所属団体の名簿。自社が所属している団体から当たるのが早い |
| 全宅連／ハトマークサイトの業者検索 | 都道府県・市区町村で絞り込める |
| 東京都の宅建業者名簿 | 免許番号・商号・所在地。閲覧可 |

集めた名簿を `業者名簿` タブに貼り付けてください。
CSV やテキストでお送りいただければ、重複除去と形式チェックをして整えます。

## トラブル対応

| 症状 | 対処 |
| --- | --- |
| `「業者名簿」シートがありません` | `setupBrokerBlastSheets` を実行する |
| `件名（B2）が空です` | `文面` タブの B2 に件名を入れる |
| `未記入の【　】が N 箇所あります` | 本文の空欄を埋める |
| `添付ファイルを取得できません` | B4 のファイルIDが正しいか、ファイルが削除されていないか確認 |
| 1件も送られない | 名簿の `配信停止` `送信済み` 列が全部立っていないか確認 |
| 特定の行だけ失敗する | `エラー` 列の内容を見る。多くはアドレスの形式か存在しないドメイン |
| 送信済みを取り消したい | `送信済み` 列の `TRUE` を手で消す（再送されるので注意） |
