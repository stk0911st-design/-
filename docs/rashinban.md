## 画面の構成

**ヘッダー帯**

- 日付（曜日つき）／第5期 期末までの残り日数／今月の残り日数
- 日替わりの名言（31本を日番号で順送り）
- 人生の目標（自由に追記・削除できる）

**タブ**：今日 ／ 実施済み ／ 未実施 ／ 日記

**今日タブ**

1. 今月カレンダー — 水曜・日曜を休みとして色分け。日付を押すとその日の予定を追加できる
   - 予定には「完了」チェックがある。済んでいない過去の予定は **持ち越し** として今日のマス（⟳付き）と
     カレンダー下の「持ち越し」欄に出続ける。「→今日」で今日の日付に移せる
   - カレンダーの下に「予定一覧」（済んでいない過去の分 ＋ 今日から先）を日付順で表示
2. 目標カード — 年 → 半期 → 今月。％は直接打ち替え。**金額は表示しない**
3. やること3層 — 今日の重点 ／ 次にやること ／ 必ずやる（急ぎではない）
4. 今日の締め — 完了と残りを集計し、日記を残し、残りに「繰越◯日」を付けて明日へ送る

**実施済み／未実施**：締めや操作で送られたものが日付順に積み上がる。どちらからも今日へ戻せる。

**日記**：締めるたびに、本文・できたこと・残ったことが1日分ずつ残る。

## データの持ち方

| コレクション | 中身 |
| --- | --- |
| `state/top` | 人生の目標（life）、目標カード（goals） |
| `tasks` | やること。`status` は open / done / backlog、`carry` が繰越日数 |
| `diary` | 1日1件。ID は `YYYY-MM-DD` |
| `events` | カレンダーの予定。`done` が完了、`doneAt` が完了時刻。`done` がない古い記録は未処理として扱う |

## 保存されているか分からなくなったら

保存のつながっていない画面（下書き表示など）で書き込むと、内容はどこにも残りません。
その状態のときは **画面のいちばん上に赤い警告帯** が出ます。警告が出ているときは書き込まず、
ピン留めした羅針盤を開き直してください。画面下部にも「保存中です」と出ていれば正常です。

## 手直しするときのルール

1. **金額は一切表示しない**（売上・粗利・残高・査定額など）。既存の設計を崩さない。
2. 既存のデータを勝手に消さない。作りを変えるときも過去の記録が読めるように保つ。
3. 編集は必ず「現在の版を読む → 同じ URL へ更新」。新しい URL を作らない。
4. 再公開の前に変更点を箇条書きで示し、承認を得てから公開する。
5. 会社の内部情報を外部サービスへ出さない。

## 操作チャットでできること

- A. 見た目・レイアウトの手直し（配置、文字サイズ、色、スマホ表示）
- B. 機能の追加・変更（タブ、並べ替え、検索、週次サマリ、名言の入れ替え）
- C. 中身の操作（人生の目標／目標と％／今日のやること／予定）
- D. 記録の確認（実施済み・未実施・日記の振り返り、繰越が溜まっているものの洗い出し）
- E. 不具合の修正
