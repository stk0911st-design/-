# 不動産株 値上がり率TOP3 日次メール 導入手順

東証33業種区分「不動産業」の上場銘柄のうち、その日の値上がり率が高い上位3社を
毎日21時（JST）にメールでお届けします。

実装は `gas/RealEstateTop3Mailer.gs`（Google Apps Script）です。

## データ取得について

株価は Apps Script の `UrlFetchApp` で **stooq** の日足CSVから取得し、
取得できなかった銘柄だけ **Yahoo Finance** のチャートAPIで補います。

> **GOOGLEFINANCE 関数は使いません。**
> 同関数は米国株では動作しますが、東京証券取引所の銘柄（`TYO:8801` など）は
> すべてエラーになることを実機で確認したためです。
> Apps Script は Google のサーバー上で動くので、外部サイトへ直接アクセスできます。

## 1. スプレッドシートとスクリプトを用意する

1. Googleドライブで新しいスプレッドシートを作る（名前は「不動産株TOP3」など任意）。
2. 「拡張機能 → Apps Script」を開く。
3. `gas/RealEstateTop3Mailer.gs` の内容を貼り付けて保存する。

## 2. 宛先を設定する

「プロジェクトの設定 → スクリプト プロパティ」に追加します。
宛先はここで管理し、コードやリポジトリには置きません。

| プロパティ | 値 |
| --- | --- |
| `RE_TOP3_RECIPIENT` | 送信先メールアドレス（カンマ区切りで複数可） |
| `RE_TOP3_CC` | （任意）CCアドレス |
| `RE_TOP3_MIN_VOLUME` | （任意）出来高の下限。未設定なら0（＝出来高0の銘柄だけ除外） |

## 3. 対象銘柄リストを作る

### 推奨：JPXの上場銘柄一覧から全銘柄を取り込む

1. Apps Scriptの左メニュー「サービス」で **Drive API** を追加する
   （JPXが配布するExcelをスプレッドシートに変換するために使います）。
2. `importUniverseFromJpx` を実行する。
3. 「銘柄マスタ」シートに、33業種区分が「不動産業」の上場銘柄（約140社）が入ります。

JPXの一覧は月次で更新されるため、**数か月に一度 `importUniverseFromJpx` を実行し直す**と
新規上場・上場廃止が反映されます。

### 代替：初期リストで始める

`initUniverseSheet` を実行すると、主要な不動産銘柄47社の暫定リストが入ります。
全銘柄ではないため、メール本文にその旨の注意書きが入ります。
あとから `importUniverseFromJpx` に切り替えられます。

### 銘柄コードの確認

`validateUniverse` を実行すると、各コードで株価が取得できるかを確認し、
取得できなかったコードを実行ログに出します。

## 4. 文面を確認する

`previewRealEstateTop3` を実行すると、送信せずにGmailの下書きが作られます。
初回は権限の承認を求められます（スプレッドシート／Gmail／外部リクエスト）。

## 5. 毎日21時のトリガーを設定する

`setupRealEstateTop3Trigger` を実行します。21時台と22時台に1本ずつ登録されます。

Apps Scriptの時間主導トリガーは指定時刻ちょうどではなく前後に幅があるため、
22時台の1本は「21時台の実行が何らかの理由で失敗した場合の予備」です。
同じ取引日を二重に送らないよう、送信済みの取引日をスクリプトプロパティ
`RE_TOP3_LAST_SENT_DATE` に記録して判定しています。

## 動作仕様

| 項目 | 内容 |
| --- | --- |
| 対象 | 東証33業種区分「不動産業」の上場銘柄（REIT・ETFは含まない） |
| 指標 | 当日終値 ÷ 前営業日終値 − 1（値上がり率） |
| 抽出 | **値上がりした銘柄のみ**を対象に、値上がり率の高い順に上位3社 |
| 除外 | 出来高が下限以下の銘柄、株価を取得できなかった銘柄、最終取引日のデータがない銘柄 |
| 配信 | 毎日21時（JST）。土日祝など取引がない日は送信しない |
| 送信方法 | 自動送信 |
| データ出所 | stooq（日足CSV）／取得できない銘柄は Yahoo Finance で補完 |

### 値上がり銘柄が3社に満たない日

値下がりした銘柄は「値上がり率TOP3」に混ぜません。

- 値上がりが1〜2社だけの日：その社数だけを載せ、「本日値上がりした銘柄はN社のみでした」と明記します。
- 1社も値上がりしなかった日：「本日は値上がりした銘柄がありませんでした」とし、
  参考として下落率が最も小さかった銘柄を1社だけ添えます。

### 土日・祝日の扱い

全銘柄の取得結果から最終取引日を判定し、前回送信した取引日と同じであれば送信しません。
したがって土日・祝日・年末年始は自動的にスキップされ、祝日カレンダーを別途持つ必要はありません。

### 注意

- 値上がり率は小型株・低位株が上位に来やすい指標です。大手中心で見たい場合は、
  「銘柄マスタ」のC列（市場区分）でプライム市場のみに絞り込んでください。
- stooq・Yahoo Finance はいずれも公開データです。仕様変更で取得できなくなった場合は、
  `parseStooqCsv_` / `parseYahooChart_` の解釈部分を直してください。
