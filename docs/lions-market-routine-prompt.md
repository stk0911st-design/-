## 夜報用プロンプト（20:15）

朝報用と同じ内容で、次の3点だけ差し替えてください。

| 箇所 | 朝報 | 夜報 |
| --- | --- | --- |
| 冒頭 | 「朝報として」 | 「夜報として」 |
| 手順3 | 「基準データと比べて変化した点」 | 「当日の朝報と比べて、日中に動いた点」 |
| 件名 | 【朝報 YYYY/M/D】 | 【夜報 YYYY/M/D】 |

夜報の本文構成には、末尾に次の項目を追加します。

```
     ■ 明日ウォッチする点
```
