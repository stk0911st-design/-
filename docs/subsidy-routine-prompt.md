# Claude ルーティン設定（補助金ウォッチ）

毎週木曜 9:00（JST）に補助金・助成金の最新状況を調べ、まとめメールを送信します。

| 項目 | 値 |
| --- | --- |
| cron（UTC） | `0 0 * * 4` |
| 対応する日本時間 | 毎週木曜 9:00 |
| 起動モード | 毎回新規セッション（このセッションの状態に依存させないため） |
| 宛先 | ルーティン設定側で管理（このリポジトリには記載しない） |

日本時間 9:00 は UTC 0:00。曜日はまたがないため木曜＝`4` のままでよい
（営業日報メールの 8:00 JST は UTC 23:00 で前日に戻るため曜日を1日ずらす必要があった点と対照的）。

## ルーティンのプロンプト

宛先アドレスは伏せています。実際のルーティンには実値を入れて登録してください。

```text
【定期実行】週次の補助金・助成金ウォッチです。以下の手順で実行してください。

■ 当社プロフィール（この条件に合うものだけを取り上げる）
業種：不動産業（売買・仲介）／所在地：東京都／常時使用する従業員数：6〜20人／
当面の投資・取組テーマ：採用・賃上げ・人材育成。
※小規模事業者持続化補助金は「従業員5人以下」要件のため対象外。取り上げないこと。

■ 手順
1. WebSearch で以下を調査し、前回配信からの変更点を洗い出す。
   (a) 業務改善助成金（厚労省）：受付状況・東京都の締切
   (b) 手取り時間創出・魅力ある職場づくり推進奨励金（東京しごと財団）：次回エントリー回次・開始日・残枠
   (c) キャリアアップ助成金 正社員化コース（厚労省）：要件・支給額の改定
   (d) 東京都正規雇用転換安定化支援助成金：受付状況
   (e) 人材開発支援助成金：コース改定・時限措置
   (f) デジタル化・AI導入補助金2026／中小企業省力化投資補助金：公募回次と締切
   (g) 東京都・区市の新規の中小企業向け助成金（特に人材・賃上げ系）
2. 締切までの残日数を計算し、30日を切っているものを「至急」として最上部に置く。
3. 制度ごとに「制度名／実施主体／補助・助成額／補助率／締切／主な要件／必要書類／
   当社の当てはまり・次の一手／公式URL」を整理する。
4. 数値・日付は必ず一次情報（公式サイト・公募要領）で確認する。裏が取れないものは
   推測で書かず「要確認」と明記する。
5. Gmail の send_message で送信する。
   宛先 <RECIPIENT> ／ 件名「【補助金ウォッチ】YYYY年M月D日（木）｜至急N件・新着N件」／
   htmlBody で「おはようございます。今週の補助金・助成金の状況です。」＋
   至急セクション＋制度別カード＋「今週やること」の箇条書き＋
   「※本メールは公開情報をもとに自動調査したものです。申請前に必ず公募要領をご確認ください。」
6. 前回から変更がない週も、締切カウントダウンと「今週やること」を添えて必ず送信する。
7. 調査が正しくできなかった場合はメールを送らず、原因を報告して終了する。

当社の従業員数・所在地などの情報は外部サービスへ投稿しないこと。検索は制度名など
一般的なキーワードのみで行う。送信後は件名・宛先・掲載件数を報告して終了。
```

## 運用メモ

- 判断材料が増えたら `docs/subsidy-watch.md` の「絞り込み条件」と制度カードを更新する。
  設備投資やIT導入の予定が出てきたら優先度Bの制度を優先度Aへ繰り上げる。
- 資本金額・決算期・雇用保険適用事業所番号などが分かると、対象判定の精度が上がる。
