# 毎週木曜のSNS集客ミーティング（運用の記録）

小林の指示（2026-11-18）で、毎週木曜に、SNS・ホームページ関係の進み具合を確認する会議を、恒例にする。

> 実値（Zoom のURL・ID・パスコード・氏名以外の個人情報）は、このリポジトリに書かない。
> 会議のURLは、カレンダーの予定に書く。

## 基本

- **頻度**：毎週木曜（年内は固定）。島田さん在宅の日。
- **時間**：14:00〜15:00ごろ（開始が14:00か14:30かは、小林に確認して、決まりしだいここに書く）。
- **参加者**：小林、島田さん。伊勢さんは、今後SNS関係を手伝うため、**スケジュールが合うときに参加**。森さんは、レジュメの連絡先（CC）。
- **目的**：毎週、**「決まったこと」と「決まらないこと」を、その場で決めて、記録する。**

## 毎週の流れ

1. **前日（水）**：秘書（Claude）が、聞くことリスト（レジュメ）を作り、小林に見せる。OKが出たら、Slack で、島田さん・森さん・伊勢さんに送る。
2. **当日（木）**：レジュメに沿って進める。決まったこと・決まらないことを、その場で、確認する。
3. **当日（木）夕方まで**：秘書が、会議の記録（決まったこと／決まらないこと／宿題と期限）を作り、小林に見せたうえで、Slack と、このリポジトリの記録に残す。
4. **翌週のレジュメ**：決まらなかったことと、宿題の進み具合を、最初の項目に入れる。

## レジュメの固定の項目

0. 最初の5分：最優先で聞くこと（公開できていないもの、報告が抜けているもの）
1. ホームページの改善・改築
2. SNSの全件検査と、ハッシュタグ「満タン」
3. 小林のClaudeからも、全SNSに投稿できるようにする
4. 森さん・皆さんのClaudeでも、保存・Backlog書き込みができるようにする
5. こぼれていそうなこと（秘書の提案）
6. 小林が、その場で決めること
7. 時間の目安（1時間）

## 毎週の記録のひな形

```
# SNS集客ミーティング 記録（M/D 木）
参加：
## 決まったこと
- （内容／担当／期限）
## 決まらないこと（来週に持ち越し）
- （内容／決めるために必要なこと）
## 宿題
- （担当／期限）
## 次回までの確認
- （数字・URL・見本など）
```

## 記録の置き場

- 会議の記録：Slack（打ち合わせのグループ）と、Google ドライブ（小林のみ閲覧）。
- 決定した運用ルールは、`docs/` に反映する（例：`docs/sns-post-style.md`、`docs/sns-hashtag-bank.md`、`docs/sns-buzz-method.md`）。

## 注意

- 金額・お客様の情報・部屋番号は、記録に書かない。
- 認証情報（ID・パスワード・トークン）は、記録にも、Slack・メールにも書かない。
- 「決まったこと」は、小林が確認してから、記録として確定する。
