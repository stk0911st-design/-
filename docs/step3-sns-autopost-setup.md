# ステップ3：LINE・Instagram 自動投稿の導入手順

毎週の「【LINE原稿】」メールを読み、配信予定日（木曜）の 20 時台に
LINE 公式アカウントと Instagram へ自動で投稿する仕組みの導入手順です。
承認の方式は2つから選べます（スクリプト プロパティ `APPROVAL_MODE`）。

- `optout`：代表から「NG」「中止」の返信がない限り投稿する（現在の手動運用と同じ考え方）
- `optin`：代表が「OK」と返信したものだけ投稿する

移行の段階は `docs/line-weekly-topics.md` の「自動投稿への移行計画」を参照。

```
火曜 8:00  Claude ルーティン：原稿＋Canva 画像を作り、代表にメール
   ↓
代表：止める場合だけ「NG」と返信（optout）／投稿してよければ「OK」と返信（optin）
   ↓
木曜 20時台  Apps Script（SnsAutoPoster.gs）：LINE 一斉配信＋Instagram 投稿 → 結果をメールで通知
```

所要時間の目安：LINE 15分／Instagram 30分／Apps Script 15分。

> Meta（Instagram）や LINE の管理画面は、表示名や場所がときどき変わります。
> 手順どおりのメニューが見つからないときは、同じ意味の項目を探してください。

---

## A. LINE：Messaging API を有効にしてトークンを発行する

1. パソコンで **LINE Official Account Manager**（https://manager.line.biz/）にログインし、
   「株式会社スマートハウス」のアカウントを開く。
2. 右上の **「設定」** → 左メニュー **「Messaging API」** → **「Messaging APIを利用する」**。
3. 開発者情報の登録画面が出たら、名前とメールアドレスを入力して進める。
4. 「プロバイダーを選択」で **「プロバイダーを作成」** → 名前に「株式会社スマートハウス」→ **「同意する」** → **「OK」**。
   （プライバシーポリシー・利用規約の URL は空欄で構いません）
5. **LINE Developers**（https://developers.line.biz/console/）に同じ LINE アカウントでログイン。
6. 手順4で作ったプロバイダー → 「株式会社スマートハウス」のチャネル → **「Messaging API設定」** タブ。
7. 一番下の **「チャネルアクセストークン（長期）」** → **「発行」**。表示された長い文字列をコピーする。
   → これが `LINE_CHANNEL_ACCESS_TOKEN`。**他人に見せない・メールに貼らない**。

補足：
- Messaging API を有効にしても、これまでどおり LINE Official Account Manager からの手動配信やチャットは使えます。
- **送信数の上限に注意**。LINE 公式アカウントは「友だち数 × 配信回数」が月の無料メッセージ数を超えると送れません
  （自動投稿はエラーになり、通知メールが届きます）。週1回なら月4〜5回分です。
  「設定」→「利用と請求」でプランと今月の送信数を確認してください。

## B. Instagram：プロアカウント化とトークンの発行

### B-1. プロアカウントに切り替える（済みなら不要）

1. スマホの Instagram アプリで会社アカウントを開く → 右上の **≡** → **「アカウントの種類とツール」**。
2. **「プロアカウントに切り替える」** → カテゴリ「不動産」など → **「ビジネス」** を選ぶ。

### B-2. Meta のアプリを作り、トークンを発行する

1. パソコンで **Meta for Developers**（https://developers.facebook.com/）に Facebook アカウントでログイン。
   （初回は開発者登録を求められるので、画面の案内に従う）
2. 右上 **「マイアプリ」** → **「アプリを作成」**。
   - アプリ名：`スマートハウスSNS投稿` など
   - ユースケース：**「Instagramでメッセージやコンテンツを管理」**
   - 「ビジネスポートフォリオ」は、まだなければ「今はリンクしない」で可。
3. 作成後のダッシュボードで **「Instagram APIを設定（Instagramログイン）」**（または「API設定（Instagramログイン）」）を開く。
4. **「アクセストークンを生成する」** の **「アカウントを追加」** → 会社の Instagram アカウントでログイン → 許可。
   - 「テスター」への追加を求められたら、左メニュー **「アプリの役割」→「役割」→「Instagramテスターを追加」** で
     会社アカウントを追加し、Instagram（ブラウザ版）の **「設定」→「ウェブサイトのアクセス許可」→「アプリとウェブサイト」→「テスターへの招待」** で承認する。
5. アカウントの横に表示される **「トークンを生成」** → 表示された文字列をコピー。
   → これが `IG_ACCESS_TOKEN`（有効期限60日。スクリプトが週1回自動で延長します）。
6. 権限に **`instagram_business_basic`** と **`instagram_business_content_publish`** が含まれていることを確認。

`IG_USER_ID` は、C の手順で `testInstagramConnection` を実行するとログに表示されます。

## C. Apps Script を設定する

**原稿メールが届く Gmail のアカウント**（Claude が原稿メールを送っているアカウント）でログインして作業します。

1. https://script.google.com/ → **「新しいプロジェクト」**。左上の名前を「SNS自動投稿」に変更。
2. `gas/SnsAutoPoster.gs` の内容を丸ごと貼り付けて保存（💾）。
3. 左の ⚙ **「プロジェクトの設定」** → 一番下 **「スクリプト プロパティ」** → **「スクリプト プロパティを追加」** で次を登録。

   | プロパティ | 値 |
   | --- | --- |
   | `LINE_CHANNEL_ACCESS_TOKEN` | A-7 でコピーした文字列 |
   | `IG_ACCESS_TOKEN` | B-2-5 でコピーした文字列 |
   | `IG_USER_ID` | 手順5で確認（いったん空欄で可） |
   | `APPROVER_EMAILS` | 原稿メールの送信元と、代表が返信に使うアドレス（カンマ区切り。`<CC>` の3件） |
   | `NOTIFY_TO` | 投稿結果の通知先（カンマ区切り） |
   | `APPROVAL_MODE` | `optout`（代表から NG・中止の返信がない限り投稿）。代表の「OK」返信を必須にするなら `optin` |
   | `DRY_RUN` | `true`（最初の1回は投稿せずに確認する） |
   | `IMAGE_FOLDER_ID` | （任意）画像を保存する Drive フォルダのID |
   | `LINE_WITH_IMAGE` | （任意）`true` で LINE にも画像を付ける。まずは付けずに始めるのがおすすめ |

4. エディタ上部の関数選択で **`testLineConnection`** → **「実行」**。
   初回は「承認が必要です」→ アカウントを選択 →「詳細」→「（安全ではないページ）に移動」→「許可」。
   実行ログに「LINE 接続OK: 株式会社スマートハウス」と出れば成功。
5. **`testInstagramConnection`** を実行。ログに出た数字を `IG_USER_ID` に登録する。
6. **`setupSnsTrigger`** を実行（1時間おきの自動実行が登録される）。
7. 原稿メールが届いたら **`previewSnsDrafts`** を実行し、ログで本文・画像URL・承認状態が読めていることを確認。

### 試運転（DRY_RUN）

- `DRY_RUN` が `true` の間は、承認済みでも投稿せず「【SNS自動投稿】…【DRY_RUN】投稿予定の内容です」というメールが届くだけです。
- 1回試運転して内容に問題がなければ、`DRY_RUN` を `false` に変更（または削除）します。
- 試運転した週は投稿済み扱いになるため、その週の分は手動で配信してください。

## 毎週の使い方（代表）

以下は `optin` の場合。`optout` の場合は、何もしなければ投稿され、止めるときだけ「NG」と返信する。

| やりたいこと | 操作 |
| --- | --- |
| そのまま投稿する | 原稿メールに **「OK」とだけ** 返信 |
| 今週は投稿しない | 「NG」または「中止」と返信（何も返信しなくても投稿されません） |
| 直してから投稿する | Claude に修正を依頼 → 新しい原稿メールが届く → 新しいほうに「OK」 |

- 返信は、原稿メールが届いている Gmail から行うのが確実です。別のアドレスから返信する場合は **「全員に返信」** にしてください。
- 「OK、ただしここを直して」のような返信は承認扱いになりません（投稿されません）。
- 木曜 20:00 を過ぎてから「OK」しても、24:00 までなら次の定時実行で投稿されます。それ以降は見送られます。
- 投稿後・見送り時・エラー時には「【SNS自動投稿】」という件名で結果メールが届きます。

## 注意

- トークンはスクリプト プロパティにだけ保存し、リポジトリ・メール・チャットには書かないこと。
- 投稿画像は Drive に保存され、「リンクを知っている全員が閲覧可」になります（Instagram と LINE が画像を取りに来るため）。
  画像は投稿で公開される内容なので問題ありませんが、同じフォルダに社内資料を置かないでください。
- LINE・Instagram で同じ文章を二重投稿しない仕組みにしてあります。失敗した側だけ1時間後に再試行します。
