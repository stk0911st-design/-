# 社内通知用PDF「不動産仲介業者の最近の状況」

大手仲介の状況と市況を、社員向けに配れる形にまとめたA4・5ページのPDFです。

## 作り方

```sh
python3 tools/build_market_pdf.py          # out/market-brief.html を書き出す
/opt/pw-browsers/chromium-1243/chrome-linux64/chrome \
  --headless --disable-gpu --no-sandbox --no-pdf-header-footer \
  --print-to-pdf="out/不動産仲介業者の最近の状況_YYYY-MM-DD.pdf" \
  --virtual-time-budget=4000 file://$PWD/out/market-brief.html
```

reportlab ではなく、印刷用CSSを書いたHTMLを Chromium の `--print-to-pdf` で
変換しています。日本語の組版とグラフの見た目が素直に出るためです。
日本語フォントは IPAPGothic（`/usr/share/fonts/opentype/ipafont-gothic/`）。

出来上がりの確認は `pdftoppm -png -r 80 <pdf> pg` で各ページを画像にして見ます。
`.page` は高さ297mm固定・`overflow:hidden` なので、入りきらない分は
切れてしまいます。文章を足したらページ数と各ページの末尾を必ず目で見ること。

## 構成（A4・5ページ）

| ページ | 内容 |
| --- | --- |
| 1 | 3行サマリー／首都圏中古マンションのグラフ2点 |
| 2 | 市場の全体像（中古・新築・金利・倒産・戸建）／大手7社の実績 |
| 3 | 取扱件数の5年推移／体制のちがい／利益の出方 |
| 4 | 大手は何を基準に動いているか（7点） |
| 5 | 自社商圏エリア／制度／出典・注記 |

## グラフの決まり

- 2つの指標を1つのグラフに重ねない（軸を2本持たせない）。
  成約件数の前年同月比と成約平均価格は、別々のグラフにしています。
- 前年同月比は0を基準にした発散表現。プラスは青 `#2a78d6`、マイナスは赤 `#e34948`。
  この2色は配色チェッカー（色覚特性・コントラスト）を通して全項目パスを確認済み。
  色だけに意味を持たせないよう、各棒に数値を直接表示しています。
- 成約平均価格は単一系列なので凡例を置きません（見出しが系列名）。
- 3月・4月は数値が取れていないため、線をつながず途切れさせています。
  数字が無い期間をつなぐと、連続して下がったように見えて誤解を生むためです。

## 中身のルール

- 当社の売上・粗利・残高・買付金額・査定額は一切載せない。
  載せてよい金額は、各社・業界団体・報道が公表している公開情報のみ。
- 顧客の個人名、物件の部屋番号、社員個人の成績は載せない。
- 「大手は何を基準に動いているか」は各社の公式方針ではなく、
  実績と打ち手からの解釈。本文の冒頭にその断りを必ず置く。
- 確認できていない項目は「—」のままにし、推測で埋めない。

## データの出どころ

数値は `data/brokers.json`（月2回のレポートと同じ調査結果）と揃えています。
JSON を更新したら、この資料の数字も合わせて直すこと。
