# 社内通達 自動配信

通達を1本出すのに、これまで手作業だったもの（メール送信・Slack投稿・カレンダー登録・
Drive保管）を、管理シートに1行書くだけで済むようにする仕組みです。

スクリプトは `gas/NoticeDistributor.gs`。

## できること

管理シート「通達一覧」に1行足して配信日時を入れておくと、その時刻に次を自動で行います。

| 順番 | 内容 |
| --- | --- |
| 1 | 全従業員へ HTML メールを送信（PDFの添付にも対応） |
| 2 | Slack の通達チャンネルへ投稿 |
| 3 | 実施期間があれば、Google カレンダーへ終日予定を登録 |
| 4 | 通達ドキュメント・PDF を保管フォルダへ移動 |
| 5 | 結果を行に書き戻し、社長へ完了報告メールを送信 |

本文は Google ドキュメントに書きます。見出し・箇条書き・表は、そのまま
メールの体裁と Slack の書式に変換されます。文面をシートに貼る必要はありません。

## 前回の配信で起きた問題と、その対策

| 起きたこと | 対策 |
| --- | --- |
| Slack の予約投稿を修正版で入れ直したら、旧版と2本投稿された | この仕組みでは予約投稿を使わず、配信時刻が来たときに1回だけ投稿します。内容を直したいときはドキュメントを直すだけで、投稿は増えません |
| PDF原本を連携経由で Drive に入れられなかった | スクリプトが本人の Google アカウントで動くため、Drive の移動も Gmail への添付もそのまま通ります |
| 日付を直すと4か所（メール・Slack・カレンダー・Drive）を直す必要があった | 直すのはドキュメントとシートの1行だけ。4か所には配信時に同じ内容が流れます |

サイボウズ Office への登録だけは連携がないため手作業のままです。Google カレンダー側の
「サイボウズ Office」は Cybozu から Google への一方向の取り込みで、書き込みはできません。

## 設置手順

### 1. 管理スプレッドシートを用意する

Google ドライブで空のスプレッドシートを作り、名前を「社内通達 配信管理」にします。
シートの中身は、あとでスクリプトが自動で作ります。

### 2. スクリプトを貼る

1. そのスプレッドシートで「拡張機能 → Apps Script」を開く
2. `gas/NoticeDistributor.gs` の中身をすべて貼り付けて保存する

### 3. スクリプトプロパティを入れる

「プロジェクトの設定 → スクリプト プロパティ」に次を追加します。
アドレスやIDなどの社内情報は、すべてここに入れます（リポジトリには置きません）。

| プロパティ | 内容 | 必須 |
| --- | --- | --- |
| `RECIPIENTS` | 全従業員の宛先。カンマ区切り | 必須 |
| `PRESIDENT_EMAIL` | 完了報告・見本送信の宛先 | 必須 |
| `COMPANY_NAME` | 文書ヘッダーに出す会社名 | 任意 |
| `SIGNER` | 発信者の肩書き・氏名（例：代表取締役　○○ ○○） | 任意 |
| `SLACK_WEBHOOK_URL` | Slack の Incoming Webhook URL | 任意 |
| `SLACK_CHANNEL_URL` | 完了報告に載せるチャンネルURL | 任意 |
| `CALENDAR_ID` | 登録先カレンダーID。未設定なら本人のカレンダー | 任意 |
| `ARCHIVE_FOLDER_ID` | 通達の保管フォルダID | 任意 |
| `SPREADSHEET_ID` | スプレッドシートに紐付けて作った場合は不要 | 条件付き |

`SLACK_WEBHOOK_URL` の作り方：Slack の管理画面 → App ディレクトリ →
「Incoming Webhooks」を追加 → 通達チャンネルを選ぶ → 表示された URL をコピー。
未設定でも動きますが、その場合 Slack への投稿は省略されます。

### 4. 動作確認とトリガー設置

1. スプレッドシートを開き直すと、メニューに「通達配信」が出ます
2. 「設定を確認する」で、必須項目が埋まっているか確認します
3. 「自動チェックを設置する（10分おき）」を実行します
   - 初回は Google の権限確認が出ます。許可してください
4. テスト用に1行入れて「選んだ行を見本で送る（社長のみ）」を試します

## 毎回の使い方

### 通達を出すとき

1. 通達の本文を Google ドキュメントで書く（見出し・箇条書き・表をそのまま使えます）
2. 管理シート「通達一覧」に1行足す

| 列 | 入れるもの |
| --- | --- |
| 文書番号 | 例：SH-2026-HR-013。空欄でも可 |
| 件名 | メールの件名・Slackの見出しになります |
| 本文（ドキュメント） | 1で作ったドキュメントの URL を貼る |
| 添付PDF | 添付したい PDF の URL。不要なら空欄 |
| 配信日時 | 送りたい日時。例：2026/9/20 9:00 |
| 実施開始日 | キャンペーン等の開始日。空欄ならカレンダー登録なし |
| 実施終了日 | 終了日。空欄なら開始日だけの1日予定 |
| 宛先 | 空欄なら全従業員。一部だけに出すときはアドレスを書く |
| 状態 | **空欄のままにする**（ここが空の行だけが配信対象です） |

3. 送る前に確認したいときは、その行を選んで「選んだ行を見本で送る（社長のみ）」
4. あとは配信日時が来れば自動で送られます

### 送る前に内容を直したいとき

ドキュメントを直すだけです。配信時にその時点の内容が読み込まれます。
日付を変えるときは、シートの「配信日時」「実施開始日」「実施終了日」を直します。

### 止めたいとき

その行の「状態」に `中止` と書きます。空欄以外の行は配信対象から外れます。

### 失敗したとき

社長宛に「【配信エラー】…」のメールが届き、原因が書かれています。
行を直して「状態」を空欄に戻すと、次の確認（10分おき）で再度配信します。

## Claude に頼む場合

スクリプトを使わず、その場で流したいときは Claude に次を伝えれば同じことをします。

```
この通達を[日時]に社員へ配信してください。実施期間は[開始]〜[終了]です。
```

Claude 側の手順（この会話で確立したもの）:

1. 通達の全文を Google ドキュメントにして、Drive の「通達済／社長通達分」へ保管
2. 全従業員宛メールの下書きを作り、まず社長へ【見本】を送って確認を取る
3. Slack の通達チャンネルへ投稿（予約投稿を使った場合、内容を直すときは
   **必ず旧い予約を削除してから**入れ直す。削除しないと2本投稿されます）
4. Google カレンダーへ実施期間の終日予定を登録
5. 配信後、社長へ完了報告

## 注意

- 配信予定時刻を24時間以上過ぎた行は、事故防止のため自動では送りません。
  送る場合は配信日時を入れ直し、状態を空欄にしてください。
- 添付できる PDF は 24MB までです。超えるものは添付せず、本文だけ送ります。
- アドレス・フォルダID・Webhook URL は、必ずスクリプトプロパティに置いてください。
  このリポジトリには社内情報を置きません。
