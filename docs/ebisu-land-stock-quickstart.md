# まず試す（所要 20分ほど）

手元にある恵比寿の物件リストを1回入れて、在庫件数と集計が出るところまで確認します。
**毎日の収集をどうするかは、ここで中身を見てから決めれば大丈夫です。**

作業はすべてご自身の Google アカウントで完結します。

---

## 1. スプレッドシートを作る（2分）

1. Google ドライブで新しいスプレッドシートを作る
2. 名前を付ける（例：恵比寿 物件在庫）

## 2. Apps Script にコードを貼る（5分）

1. そのスプレッドシートで **拡張機能 → Apps Script**
2. 最初から入っている `function myFunction() {}` を全部消す
3. `gas/LandStock.gs` の中身を全部貼り付ける
4. 左の **ファイル → ＋ → スクリプト** で新しいファイルを作り、`gas/LandStockMailer.gs` を貼る
5. 保存（Ctrl+S）

`LandStockReinfolib.gs`（国交省の成約データ）は後からで構いません。

## 3. シートを作る（2分）

1. 上の関数の選択欄で `setupLandStockSheets` を選び、**実行**
2. 初回は権限の確認が出ます
   - 「このアプリは確認されていません」→ **詳細** → **（プロジェクト名）に移動** → **許可**
   - ご自身が作ったスクリプトなので問題ありません
3. スプレッドシートに戻り、`取込` `物件マスタ` `日次サマリ` などのタブができていればOK

## 4. 手元のデータを入れる（5分）

`取込` シートの2行目以降に貼ります。**全部の列が埋まっていなくても構いません。**
最低限あるとよいのは **種別・所在地・価格** の3つです。

| 取得日 | 情報元 | 元物件ID | 種別 | 所在地 | 最寄駅 | 徒歩分 | 価格 | 土地面積 | 建物面積 | 間取り | 築年月 | 階数 | 掲載URL | 備考 |
| --- | --- | --- | --- | --- | --- | --- | --- | --- | --- | --- | --- | --- | --- | --- |
| | 自社 | | 売地 | 渋谷区恵比寿南1-2-3 | JR恵比寿 | 5 | 1億2,000万円 | 105.2㎡ | | | | | | |
| | 自社 | | 中古一戸建 | 渋谷区恵比寿4-5-6 | JR恵比寿 | 8 | 1億8,000万円 | 88㎡ | 132㎡ | 4LDK | 2015年3月 | | | |
| | 自社 | | 中古マンション | 渋谷区恵比寿西1-1-1 | JR恵比寿 | 3 | 9,800万円 | | 55.4㎡ | 2LDK | 2008年6月 | 8階 | | |
| | 自社 | | 一棟アパート | 渋谷区恵比寿3-9-9 | JR恵比寿 | 10 | 4億2,000万円 | 210㎡ | 380㎡ | | 1998年 | | | |

読み取りのコツ:

- **取得日は空でOK**。実行した日が自動で入ります
- **種別は普段の言い方のまま**でOK。「売地」「中古一戸建」「一棟アパート」「区分所有」などを
  土地／戸建／アパート／ビル／マンション(区分) に自動で寄せます
- **価格は「1億2,000万円」「9800万円」「12000」どれでも**読めます
- **面積は「132.45㎡」「40坪」どちらでも**読めます
- 所在地に「恵比寿」が入っていない行は集計から外れます（消しはしません）

## 5. 読み取り結果を確認する（3分）

**集計する前に、意図どおり読めているかを確かめます。シートは変更されません。**

1. 関数の選択欄で `previewLandStockIntake` を選び、**実行**
2. 下に出る **実行ログ** を見る

こんな形で1行ずつ出ます。

```
2 | 2026-09-06 | 土地 | 渋谷区恵比寿南1-2-3 | 対象 | 12000万円 | 105.2㎡ | 建物- | 新規 | h:xxxxxxxx
3 | 2026-09-06 | 戸建 | 渋谷区恵比寿4-5-6 | 対象 | 18000万円 | 88㎡ | 132㎡ | 新規 | h:xxxxxxxx
--- 集計
全 4行 ／ 対象 4件 ／ エリア外 0件
種別の内訳: 土地 1件、戸建 1件、マンション(区分) 1件、アパート 1件
```

ここで見るところ:

| 出方 | 意味 |
| --- | --- |
| 種別が違う | 種別欄の書き方を変えるか、教えてください。寄せ方を調整します |
| 「価格読めず」 | 「応談」など数字が無い行。価格なしのまま集計されます |
| 「エリア外」が多い | 所在地の書き方を確認。判定語は `LS_AREA_KEYWORDS` で変えられます |

## 6. 集計する（1分）

1. 関数の選択欄で `runDailyLandStock` を選び、**実行**
2. スプレッドシートに戻って確認

| タブ | 見るところ |
| --- | --- |
| `物件マスタ` | 1物件1行。初回確認日・状態・坪単価が入っているか |
| `日次サマリ` | 今日の日付で、種別ごとの在庫件数と「合計」が出ているか |
| `月次サマリ` | 今月の行で、新規＝入れた件数になっているか |
| `取込ログ` | 取込行数・新規件数の記録 |

**ここまでで「今日で何件あるか」が出ます。**
掲載終了・月次の推移は、明日以降ためていくことで出てきます。

## 7. 毎朝のメールを設定する（3分）

### まず文面を確認する（送信されません）

1. 関数の選択欄で `previewLandStockMail` を選び、**実行**
2. 実行ログに、実際に送られる文面が出ます

初日は「いまの在庫」と「今月の動き」の2つの表が出ます。
前日比は `-`、月次の推移は表ごと出ません（比べる日・月がまだないため）。
2か月ぶんたまると推移の表が出てきます。

### 宛先を入れる

1. 左の歯車 **プロジェクトの設定**
2. **スクリプト プロパティ → プロパティを追加**

   | プロパティ名 | 値 |
   | --- | --- |
   | `LS_RECIPIENT` | 送信先メールアドレス |
   | `LS_CC` | （任意）CCアドレス。カンマ区切り |

3. **スクリプト プロパティを保存**

### 毎日のトリガーを入れる

1. 左の時計アイコン **トリガー** → 右下 **トリガーを追加**
2. 次のように設定して保存

   | 項目 | 値 |
   | --- | --- |
   | 実行する関数 | `sendLandStockMail` |
   | イベントのソース | 時間主導型 |
   | 時間ベースのトリガーのタイプ | 日付ベースのタイマー |
   | 時刻 | 午前7時〜8時 |

`sendLandStockMail` は**送る前に集計も実行します**。トリガーはこの1本だけで足ります。

翌朝メールが届いたら完成です。

## この先

毎日データを入れ続けて初めて、掲載終了と月次の傾向が出てきます。
毎日の収集をどうするかは、次のどれかになります。

| やり方 | 向いている場合 |
| --- | --- |
| `取込` シートに毎日貼る | 件数が少なく、手作業で回せる |
| ドライブのフォルダにCSVを置く | レインズの書き出しを使う。`LS_CSV_FOLDER_ID` を設定すれば自動で読みます |
| 入力画面から送る | 担当者が現場で登録する。`Receiver.gs` の `type:'land'` を使います |
| メールで届く物件情報を拾う | 業者からのメールを自動で取り込む。別途仕組みが必要です |

中身を見てから決めて構いません。決まったら教えてください。

## うまくいかないとき

| 症状 | 見るところ |
| --- | --- |
| `日次サマリ` に行ができない | `取込ログ` の「取込行数」が0なら、所在地に「恵比寿」が入っているか確認 |
| 在庫が急に減った | `取込ログ` を確認。取込が0件の日は掲載終了の判定を止めるので、在庫は減りません |
| 掲載終了が出ない | 3日連続で取込に現れないと掲載終了になります（`LS_GRACE_DAYS` で変更可） |
| 同じ物件が2件に分かれた | 所在地や面積の書き方が変わると別物件になります。`元物件ID` を入れると確実です |
| メールが届かない | `LS_RECIPIENT` が入っているか、トリガーの実行履歴にエラーが出ていないか |

詳しい仕様は `docs/ebisu-land-stock.md` を参照してください。
