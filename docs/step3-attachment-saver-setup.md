# ステップ③ メールの添付ファイルを自動でドライブに保存する（所要 15分ほど）

毎晩19:30の自動保存では、物件メールの本文をドキュメントにしてフォルダへ保存しています。
ただし添付ファイル（PDFの概要書など）は Claude から取り出せないため、これまでは
「添付は元メールから取り出してこのフォルダに入れてください」と書いて、手作業にしていました。

このステップで Apps Script を1本入れると、**添付ファイルも自動で同じフォルダに入る**ようになります。
一度設定すれば、あとは何もしなくて大丈夫です。

## このスクリプトがすること

1時間に1回、自動で次の動きをします。

1. Gmail で **「ドライブ保存済」ラベルが付いていて、添付があるメール**を探す
2. 毎晩の自動保存で作ったドキュメントには「元メール：https://mail.google.com/…」というリンクが
   書いてあります。このリンクを手がかりに、**そのメールのドキュメントが入っているフォルダ**を見つける
3. 添付ファイルをそのフォルダに保存し、メールに **「添付保存済」ラベル**を付ける
   - 同じ名前・同じ大きさのファイルがすでにフォルダにあるときは、二重に保存しません
   - メールの署名に入っている小さなロゴ画像（30KB 未満の画像）は保存しません
4. フォルダが見つからなかったメールは保存せず、**「添付保存_要確認」ラベル**を付けて残します

※ メールの削除、フォルダやファイルの削除・名前の変更は一切しません。
※ スクリプトは小林さんご自身の Google アカウントの中だけで動きます。外部には何も送りません
　（お知らせメールを設定した場合も、届く先はご自身で指定したアドレスだけです）。

## 始める前に

- 作業は **物件メールが届いている Google アカウント**（毎晩の自動保存で使っているのと同じアカウント）で
  ログインして行ってください。別のアカウントで作ると、メールもフォルダも見えないため動きません。
- パソコンのブラウザ（Chrome など）での作業をおすすめします。

---

## 1. Apps Script のプロジェクトを作る

1. ブラウザで **https://script.google.com** を開く
2. 左上の **＋ 新しいプロジェクト** を押す
3. 画面上部の「無題のプロジェクト」という文字を押して、名前を付ける
   - 例：`メール添付ファイル 自動保存`
   - **名前を変更** を押して確定

## 2. コードを貼り付ける

1. 画面中央に最初から入っている
   ```
   function myFunction() {

   }
   ```
   を **全部消す**（Ctrl+A で全選択 → Delete）
2. このリポジトリの `gas/AttachmentSaver.gs` の中身を **全部コピーして貼り付ける**
3. 保存する（上のフロッピーディスクのアイコン、または Ctrl+S）
   - 保存できると、ファイル名の横の丸印が消えます

## 3. 設定を入れる（任意・あとからでも変えられます）

設定しなくても動きます。必要なものだけ入れてください。

1. 左端の歯車アイコン **プロジェクトの設定** を押す
2. いちばん下の **スクリプト プロパティ** → **スクリプト プロパティを追加**
3. 下の表から必要なものを入れて、**スクリプト プロパティを保存**

| プロパティ | 入れる値 | 何のためか |
| --- | --- | --- |
| `NOTIFY_TO` | お知らせを受け取るメールアドレス（例：`<小林さんのアドレス>`） | フォルダが見つからないメールが出たときに、メールで知らせてもらう。入れなければメールは来ません |
| `START_DATE` | `2026/10/01` のような日付 | この日以降のメールだけを対象にする。**入れなければ、9月からの保存済みメールも全部さかのぼって**添付を保存します |
| `EXCLUDE_FROM` | `@<自社のドメイン>` など。複数はカンマ区切り | 自社から送ったメール（買付証明書など）の添付は保存しない、というときに使う |
| `MIN_IMAGE_KB` | 数字（例：`50`） | これより小さい画像は署名ロゴとして保存しない。入れなければ 30 |

### さかのぼり（9月からの分）について

`START_DATE` を入れなければ、これまで「ドライブ保存済」になったメールの添付もすべて保存します。
1回に15件ずつ、1時間ごとに進むので、件数が多いと **全部終わるまで1日ほど** かかります。
途中で止まっても、次の回に続きから進みます。

## 4. まず「確認モード」で動かしてみる（何も保存されません）

いきなり保存せず、どのメールの添付がどのフォルダに入るかを先に確かめます。

1. 左端の **< >（エディタ）** を押して、コードの画面に戻る
2. 画面上部の、関数を選ぶ欄（▼のついた欄）で **`previewAttachmentSave`** を選ぶ
3. その左の **▷ 実行** を押す
4. 初回だけ、権限の確認が出ます
   1. 「承認が必要です」→ **権限を確認**
   2. ご自身のアカウントを選ぶ
   3. 「このアプリは Google で確認されていません」と出たら、左下の **詳細** →
      いちばん下の **（プロジェクト名）（安全ではないページ）に移動** を押す
      - ご自身が作ったスクリプトなので問題ありません
   4. 許可する内容の一覧が出たら、**すべて選択** にチェックを入れて **続行**（または **許可**）
      - Gmail を読む・ラベルを付ける、ドライブにファイルを作る、お知らせメールを送る、
        トリガーを作る、の権限です
5. 画面下に **実行ログ** が出ます。次のように表示されていれば正常です

```
【確認モード】対象のメール：15件（1回の上限 15件）
■ （メールの件名） → （保存先のフォルダ名）
  保存予定：物件概要書.pdf（820KB）
■ （メールの件名） → （保存先のフォルダ名）
  保存予定：販売図面.pdf（6.6MB）
  待ち：（メールの件名）（保存先ドキュメントがまだ見つかりません。次回もう一度探します）
保存 12件／同名で保存済みのためスキップ 0件／ドキュメント待ち 1件／要確認 0件／エラー 0件
```

- `→` の右側が保存先のフォルダ名です。**フォルダ名が合っているか**を数件見てください
- 「待ち」は、ドキュメントを作った直後で検索にまだ出てこないものです。次の回にもう一度探します
- 「要確認」は、受信から2日たってもフォルダが見つからないものです（下の「困ったとき」を参照）

> **ログに「保存予定」が1件も出ず、全部「待ち」になる場合**
> ドキュメントの中のメールIDでフォルダを探す仕組みが、うまく働いていない可能性があります。
> 本番に進まず、ログをそのままコピーして Claude に送ってください。調整します。

## 5. 本番を1回、手で動かす

1. 関数を選ぶ欄で **`saveAttachments`** を選び、**▷ 実行**
2. 実行ログの最後に `保存 ○件` と出たら完了です
3. 確かめる
   - **Google ドライブ**：ログに出たフォルダを開き、添付ファイルが入っていること
   - **Gmail**：左のラベル一覧に **「添付保存済」** ができていて、保存したメールに付いていること

## 6. 1時間ごとに自動で動くようにする（トリガー）

どちらか一方の方法で設定してください。

### 方法A：ボタンで作る（かんたん）

1. 関数を選ぶ欄で **`setupHourlyTrigger`** を選び、**▷ 実行**
2. 実行ログに「saveAttachments を1時間ごとに動かすトリガーを作りました。」と出ればOK

### 方法B：画面から作る

1. 左端の時計アイコン **トリガー** を押す
2. 右下の **＋ トリガーを追加** を押す
3. 次のように選ぶ
   - 実行する関数を選択：**saveAttachments**
   - 実行するデプロイを選択：**Head**
   - イベントのソースを選択：**時間主導型**
   - 時間ベースのトリガーのタイプを選択：**時間ベースのタイマー**
   - 時間の間隔を選択：**1時間おき**
   - エラー通知設定：**毎日通知を受け取る**
4. **保存**

トリガーの画面に `saveAttachments` が1行あれば設定完了です（**2行以上あると二重に動く**ので、
その場合は1行を残して、行の右の︙ → **トリガーを削除** で消してください）。

## 毎日の運用

基本的に何もしなくて大丈夫です。毎晩19:30に Claude がフォルダとドキュメントを作り、
そのあと1時間以内にこのスクリプトが添付を入れます。

Gmail のラベルで状況が分かります。

| ラベル | 意味 |
| --- | --- |
| ドライブ保存済 | 本文のドキュメントが保存されたメール（毎晩の自動保存が付ける） |
| 添付保存済 | 添付もフォルダに保存し終えたメール |
| 添付保存_要確認 | 保存先のフォルダが見つからず、添付を保存できなかったメール |

## 困ったとき

**「添付保存_要確認」が付いたメールがある**
- 本文のドキュメントが削除された、別の場所に移された、ドキュメントの「元メール」の行が消えた、
  などが考えられます
- 添付は Gmail から手で保存してください（メールを開き、添付にマウスを乗せると出る
  **ドライブに追加** ボタン）
- フォルダとドキュメントを用意し直したあとで、そのメールから「添付保存_要確認」ラベルを外すと、
  次の回にもう一度自動で保存を試みます

**メールに後から添付付きの返信が届いた**
- 「添付保存済」になったあとに同じやり取りへ届いた添付は、自動では保存されません
  （同じメールを何度も処理しないための仕組みです）
- 手で保存するか、そのメールから「添付保存済」ラベルを外すと、次の回にもう一度保存します
  （すでに入っているファイルは二重に保存されません）

**止めたい**
- 左端の時計アイコン **トリガー** で、`saveAttachments` の行の︙ → **トリガーを削除**
- 保存済みのファイルやラベルはそのまま残ります

**動いているか確かめたい**
- 左端の **実行数** を押すと、いつ動いて成功したか・失敗したかの一覧が見られます

**パスワード付きの zip や、ダウンロードリンク形式の資料**
- メールに添付されている zip はそのままフォルダに保存します（中身の展開はしません）
- 「こちらからダウンロード」のようなリンク形式の資料は添付ではないので対象外です。
  これまでどおりドキュメント内のリンクから取得してください
