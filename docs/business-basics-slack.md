# 社会人基礎トレーニング（毎朝 Slack＋メール配信）

毎朝、社会人としての基礎知識を「問題＋答え」のセットで3本、Slackとメールに自動配信します。
その場で読んですぐ分かる長さにするのが方針です。

## 配信仕様

| 項目 | 内容 |
| --- | --- |
| 配信曜日 | 月・火・木・金（水曜は休み） |
| 配信時刻 | 8:57（JST） |
| cron（UTC） | `57 23 * * 0,1,3,4` |
| 配信先 | Slack の社内チャンネル1つ ＋ 自分宛メール1件（IDとアドレスは実行環境側で管理） |
| 形式 | 問題(❓)→答え(✅)→ひとこと(💡) を1本ずつ、計3本 |
| 実行方式 | Claude のルーティン（既存セッションを継続。Slackコネクタを保持しているため） |

JST 8:57 は UTC 23:57 で日付が前日に戻るため、曜日指定も1日ずらして
`0,1,3,4`（日・月・水・木）になります。

## 3本の構成

| 枠 | テーマ | 例 |
| --- | --- | --- |
| 1本目 | 社会人マナー（勤怠・報連相） | 遅刻しそうなときの連絡、勤務変更の申し出、早退・欠勤、有給の申請 |
| 2本目 | ビジネスメールの書き方 | 宛名・敬称、社内/社外の使い分け、件名、CC/BCC、依頼・催促・お詫び |
| 3本目 | 日替わりローテーション（下記3ジャンルを順番に） | ― |

3本目のローテーション：

1. 一般社会常識・ビジネスマナー（名刺交換、上座下座・席次、訪問時の作法、身だしなみ）
2. 電話応対・緊急時の連絡（取次ぎ、伝言、クレーム一次対応、緊急連絡の順序）
3. 冠婚葬祭・お悔やみ対応（弔電、お悔やみメール、慶弔の作法、香典・のし）

配信のたびに 1→2→3→1… と順に進めます。
前回どこまで進んだかは、配信先チャンネルの直近の投稿（見出しに `【社会人基礎トレーニング】` が入っている）
を読んで判断します。判断できない場合は「1. 一般社会常識」から始めます。

## 重複を避ける仕組み

実行時に配信先チャンネルの直近の投稿を読み、すでに出題済みのテーマと
重複しない問題を作ります。過去ログはチャンネルそのものを台帳として使います。

## 敬称・呼び方のルール（2本目でよく出る論点）

- 社内の上司を社内向けに書くとき：役職は敬称なので「高橋課長」。「高橋課長様」は二重敬語で誤り。
- 社外に自社の上司を出すとき：敬称・役職の「様」を付けず「課長の高橋」または「高橋」。
- 社外の相手：「株式会社○○ 営業部 部長 ○○様」のように、会社名→部署→役職→氏名＋様。

## 文章のトーン

朝いちばんに読むものなので、明るく・やさしく・短くを優先します。

- 「できていないと恥ずかしい」ではなく「知っていれば安心」「これだけ押さえればOK」
- 命令口調（〜しなさい／〜すべき）は使わない。「〜すると安心です」「〜が伝わります」
- 1文を短く。答えは3〜4行以内
- そのまま口に出せる・コピペできるセリフを「」で1つ入れる
- 絵文字は ❓（問題）✅（答え）💡（ひとこと）の決まった位置だけ
- 最後にその日の内容に合った短い応援の一言を添える（毎回同じ文言にしない）

## ルーティンのプロンプト

社内情報（チャンネルID）は伏せています。実際のルーティンには実値を入れて登録してください。

```text
【定期実行】社会人基礎トレーニングのSlack配信です。以下の手順どおりに実行してください。

1. 今日の日付・曜日（JST）を確認する。月・火・木・金のみ配信。それ以外の曜日なら何もせず終了する。
2. Slack の slack_read_channel でチャンネル <CHANNEL_ID> の直近30件を読み、
   見出しに「【社会人基礎トレーニング】」が入った過去の投稿を確認する。
   - 3本目のジャンルが前回どれだったかを見て、今回は次のジャンルにする
     （1.一般社会常識・ビジネスマナー → 2.電話応対・緊急時の連絡 → 3.冠婚葬祭・お悔やみ対応 → 1に戻る）。
     判断できなければ 1 から始める。
   - 過去に出題済みの問題とテーマが重複しないようにする。
3. 問題を3本つくる。1本目＝社会人マナー（勤怠・報連相）、2本目＝ビジネスメールの書き方、
   3本目＝手順2で決めたジャンル。
   敬称ルール：社内向けは「高橋課長」（「高橋課長様」は誤り）、社外向けは「課長の高橋」。

   ■ 文章のトーン（重要）
   - 明るく、やさしく、読みやすく。朝いちばんに読んで気持ちが軽くなる感じ。
   - 「できていないと恥ずかしい」ではなく「知っていれば安心」という書き方。
   - 命令口調は使わない。「〜すると安心です」「〜が伝わります」とやわらかく。
   - 1文を短く。答えは3〜4行以内。
   - そのまま口に出せる・コピペできるセリフや文例を「」で1つ入れる。
   - 絵文字は各ブロックの決まった位置だけ（❓ ✅ 💡）。

4. slack_send_message でチャンネル <CHANNEL_ID> に1通だけ投稿する。書式：

   ☀️ **【社会人基礎トレーニング】YYYY年M月D日(曜)**
   おはようございます。今日の3本です。1分だけおつきあいください。

   **① 社会人マナー：<小見出し>**
   ❓ <場面の問題。1〜2行>
   ✅ <答え。3〜4行以内。「」でそのまま使えるひとことを入れる>
   💡 <やさしい補足を1行>

   **② ビジネスメール：<小見出し>**
   ❓ ... / ✅ ... / 💡 ...

   **③ <ジャンル名>：<小見出し>**
   ❓ ... / ✅ ... / 💡 ...

   （最後に、その日の内容に合った短い応援のひとことを1行だけ添える。毎回同じ文言にしない）

5. 続けて Gmail の send_message で、同じ3本を <MAIL_ADDRESS> 宛に送る。
   件名は「【社会人基礎トレーニング】YYYY年M月D日(曜)」。htmlBody で、
   上部に薄いオレンジの見出しブロック、3本それぞれを左に色付きの縦線を引いたブロックにして
   ❓ ✅ 💡 の3行で構成する。body にはプレーンテキスト版も入れる。
6. Slack・メールとも1日1通のみ。すでに同じ日付の投稿がチャンネルにあれば二重送信せず終了する。
7. 送信後、3本の小見出し・3本目のジャンル・Slack投稿リンク・メール送信の可否を報告して終了する。

このチャンネルは社内向け。指定のチャンネル以外に投稿したり、社外へ送ったりしないこと。
特定の個人・取引先を題材にせず、一般的な事例として書くこと。
誰かを注意する・叱るような書き方はしないこと。
```

## 運用メモ

- 祝日は考慮していません。祝日も配信されます。止めたい場合はルーティンを一時停止してください。
- 配信先を自分宛DMや別チャンネルに変えたい場合は、ルーティンのプロンプト内のチャンネルIDを変更します。
- メール配信をやめる場合は、ルーティンのプロンプトから手順5を削除します。
- 曜日・時刻の変更はルーティンの cron（UTC）を変更します。
