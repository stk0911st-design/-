## 中心命題

2026年の不動産市場は「上昇」から**「分断」**へ移行した。
価格はまだ上がっているが、売れる量が止まった。

| 側面 | 数値 |
| --- | --- |
| 仕入れ側（地価） | 東京23区の住宅地 **+8.7%**。調査350地点すべてで上昇 |
| 実需側（成約） | 首都圏中古の成約件数 2026年8月 3,180件、**−10.5%**、5カ月連続減 |
| 同上 | 東京都区部の成約㎡単価が **76カ月ぶり**に前年割れ |
| 高額帯 | 7,000万〜9,000万円台の成約率 16〜17% → **6.8%** |

## 通用しなくなったロジック

| 言わないこと | 矛盾する事実 |
| --- | --- |
| 「金利が上がる前に買いましょう」 | すでに上がった |
| 「不動産は上がり続けます」 | 区部の成約㎡単価は76カ月ぶりに前年割れ |
| 「今が底です」 | 在庫は増加中、成約率は低下中 |
| 「待てば固定が下がる」 | 財政拡張が長期金利を押し上げている |
| 「ペアローンで限度額いっぱい」 | 金融庁も不動産融資に警告（2026年2月） |

## 通用するロジック6本

1. **実質金利** — 変動1.2〜1.6%に対しCPI 2.4%。控除0.7%を引けば変動1.2%の実質負担は名目0.5%
2. **返済額固定×賃金上昇** — 実質賃金9カ月連続プラス、所定内給与+3.7%。返済負担率は時間とともに下がる
3. **交渉可能性** — 1億円台の在庫は約2倍。買い手に初めて交渉力が生まれた
4. **住居費固定** — 賃料も上がる。比較対象を生涯の総住居費に置く
5. **税制** — 住宅ローン減税が2030年入居まで延長。子育て世帯のZEH水準で13年最大409.5万円
6. **金利タイプ分岐** — 「変動は安いが上がる前提」と明示して選ばせる。記録に残す

## 価格帯別の販売計画

| 価格帯 | 2026年の状態 | 方針 |
| --- | --- | --- |
| 〜4,000万円台 | 成約率8〜12%で横ばい | 件数の軸。ここを守る |
| 5,000〜6,000万円台 | 成約件数約3割減、成約率約半分 | ロジック転換が必要な主戦場 |
| 7,000〜9,000万円台 | 16〜17% → 6.8% | 母数を増やす。成約率で計画を置かない |
| 1億円台 | 11〜12% → 4%台、在庫約2倍 | 長期戦に設計変更 |
| 1.5〜1.9億円 | 成約率2%台、在庫消化に約3年 | 媒介期間と価格戦略を作り替える |
| 2億円以上 | 3%台後半 → 半分以下 | 金利ロジックは効かない |
| 神奈川・埼玉・千葉 | 需要維持または微減 | 打撃が小さい。資源を寄せる余地 |

## 結論

> この局面で優位に立つのは、買い手を説得できる仲介ではなく、
> **売主に市場を数値で説明できる仲介**である。

在庫㎡単価 110.08万円 と成約㎡単価 86.26万円 の **27.6%** の差は、
売主の価格観が半年遅れていることを意味する。賃金の伸び（年+3.7%）で
この差が埋まるには約6.7年かかる。つまり売主が下げるか、成約しないかのどちらかになる。

## 今後の確認指標（優先順）

1. 日銀12月会合の結果（固定金利に直結）
2. 東京都区部の成約㎡単価（**3カ月連続マイナスなら基調転換**）
3. 1億円台の在庫（約2倍から縮むか）
4. 売出から成約までの日数（最も早く出る先行指標）
5. 実質賃金（マイナス転落ならロジック2が使えなくなる）
6. FRB 12月FOMC

## 社内で週次集計する数値

- 自社媒介物件の、売出からの経過日数（90日超の件数）
- 価格改定を行った件数と、その平均引き下げ率
- 成約案件の、当初売出価格からの乖離率
- 商談消滅の理由のうち「資金計画」が原因の件数

4つ目が増えていれば、案内している価格帯が顧客の審査可能額と合っていない。
物件ではなく案内の入り口を直す。
