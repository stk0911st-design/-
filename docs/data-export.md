# データのエクスポート方法（入力アプリ → 手元のファイル）

営業日報の入力アプリ（アーティファクト）は3種類あり、**保存先が違うためエクスポートの手順も違います**。
2026-09-08 時点の調査結果をまとめます。

| アプリ | アイコン | 保存先 | 外部から読めるか |
| --- | --- | --- | --- |
| 営業日報カウンター（共有中の最新版） | 🏠 | 各端末のブラウザ（localStorage） | 読めない |
| 営業日報カウンター（db 版） | 🗄️ | アーティファクトのデータベース | 未確認（現状データなし） |
| 日報カウンター実務版 | 📋 | アーティファクトのデータベース | 読める（テスト入力が少量あり） |

## 1. 共有中の最新版（🏠）からのエクスポート

現場が使っているのはこの版です。データは**開いた端末のブラウザの中だけ**にあり、
サーバーにも Claude にも届いていません。そのため、**担当者ごとに自分の端末で書き出す**必要があります。

1. 画面の下のほうにある **「データの書き出し」** カードを開く
2. 次のどちらかを押す
   - **CSV｜今週ぶん** … 表示中の週（月〜日）
   - **CSV｜全期間** … その端末に残っている全データ
3. 画面にテキスト枠が出て、CSV の中身が表示される
   （この版は「ファイルとして保存」の機能を切ってあるため、ダウンロードはされません）
4. **「画面に出してコピー」** を押すとクリップボードにコピーされる
   （押せない場合は枠の中を全選択してコピー）
5. Excel か Google スプレッドシートの A1 に貼り付けて保存する

CSV の列：
`日付 / 曜日 / 担当者 / 役職 / 区分 / 項目 / 件数 / 備考 / 指示元 / 状況 / 内容`

含まれるもの：カウンター（区分・項目ごと）、査定、引き継ぎ、ご意見、ひとこと、出勤、社長の指示。

### 注意

- **別の端末・別のブラウザで入力した分は入っていません。** 端末ごとに書き出してください。
- ブラウザの履歴・サイトデータを消すと、その端末のデータは消えます。書き出しは早めに。
- プレビュー画面ではなく、公開 URL（claude.site）で開いた画面で操作してください。

## 2. 実務版（📋）からのエクスポート

「データの書き出し」タブに2つのボタンがあります。こちらは**ファイルとしてダウンロード**されます。

- **CSV｜今月ぶん** … `日報_YYYY-MM.csv`
- **バックアップ｜全期間（JSON）** … `日報バックアップ_YYYY-MM-DD.json`（daily / deals / requests / goals / config を丸ごと）

保存先がデータベースなので、端末に関係なく全員分がまとめて出ます。
また Claude 側からも直接読み出せるため、依頼があれば Claude が集計して CSV を作ることもできます。

## 3. Claude に読ませたい場合（自動集計のため）

最新版（🏠）は Claude から読めないため、次のどれかが必要です。

| 方法 | 手間 | 備考 |
| --- | --- | --- |
| A. 受け皿（`gas/Receiver.gs`）で保存のたびにスプレッドシートへ控えを書く | 中 | `docs/step1-receiver-setup.md` の手順。疎通テスト待ち |
| B. 最新版をデータベース保存に切り替える | 中 | 実務版と同じ方式。過去分は各端末から CSV で移す必要あり |
| C. 各担当者が週1回 CSV を書き出して共有フォルダに置く | 小 | 人力。忘れると穴が空く |

いまの本命は A（受け皿）で、`docs/step2-connection-test.md` の結果待ちです。
