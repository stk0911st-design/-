# 明日の天気メール（首都圏）ルーティン設定

毎日 19:30（JST）に、翌日の首都圏（1都3県）の天気をメールで配信します。

| 項目 | 値 |
| --- | --- |
| 配信タイミング | 毎日 19:30（JST） |
| cron（UTC） | `30 10 * * *` |
| 対象日 | 実行日の翌日 |
| 対象地域 | 東京（23区）／横浜／さいたま／千葉 |
| 宛先 | 指定アドレス1件（設定値として管理） |
| 送信方法 | 自動送信（利用者から事前承認済み） |
| 起動モード | 既存セッションを継続（Gmail コネクタを保持しているため） |

日本時間 19:30 は UTC 10:30。日付は前後しないため、曜日指定のずれはありません。

## 情報源についての注意

このリポジトリを動かす実行環境では、天気サイトへの直接アクセス（WebFetch / curl）が
egress プロキシでブロックされています。確認済み：

- `tenki.jp` … ブロック
- `weather.yahoo.co.jp` … ブロック
- `www.jma.go.jp`（気象庁 bosai JSON API を含む） … ブロック

そのため予報の取得は **WebSearch 経由**で行います。ルーティンのプロンプトにもその旨を明記しています。
将来 egress ポリシーが変わって気象庁の JSON API（`https://www.jma.go.jp/bosai/forecast/data/forecast/<地域コード>.json`、
東京 `130000` / 神奈川 `140000` / 埼玉 `110000` / 千葉 `120000`）に到達できるようになれば、
そちらの方が正確・安定します。

## ルーティンのプロンプト

社内情報（宛先アドレス）は伏せています。実際のルーティンには実値が入っています。

```text
【定期実行】明日の首都圏の天気メールを送信してください。この会話で決めた手順どおりに実行してください。

■ 前提
- 現在は日本時間の 19:30 頃です。まず `TZ=Asia/Tokyo date` で日本時間の今日の日付を確認し、その翌日を「対象日」とします。
- 対象地域は首都圏（1都3県）：東京（東京23区）／神奈川（横浜）／埼玉（さいたま）／千葉（千葉）。

■ 手順
1. WebSearch で対象日の各地の天気予報を調べる。
   検索例：「東京 明日の天気 <YYYY年M月D日>」「横浜 明日の天気 <YYYY年M月D日>」
   「さいたま 明日の天気 <YYYY年M月D日>」「千葉 明日の天気 <YYYY年M月D日>」
   「関東地方 気象 予報 <YYYY年M月D日> 警報 注意報」
   ※ このネットワークからは tenki.jp / weather.yahoo.co.jp / www.jma.go.jp への直接アクセス（WebFetch・curl）は
     ブロックされています。WebSearch の結果を使ってください。WebFetch がブロックされたら深追いせず WebSearch に切り替えること。
2. 各地点について「天気」「最高気温／最低気温」「降水確率」をまとめる。
   取得できなかった項目は「—」にし、推測で数値を書かない。
3. 傘の要否、寒暖差、警報・注意報、台風・大雨などの特記事項があれば「ひとこと」としてまとめる。

■ 送信（確認不要・自動送信してよい）
- Gmail の send_message を使う。
- 宛先：<RECIPIENT>
- 件名：【明日の天気】<YYYY年M月D日(曜)> 首都圏
- htmlBody：
  ・冒頭「小林様　お世話になっております。<対象日>の首都圏の天気をお届けします。」
  ・地点別の表（地点／天気／最高気温／最低気温／降水確率）。東京・横浜・さいたま・千葉の順。
  ・「ひとこと」（傘の要否・服装・注意事項）
  ・末尾に小さめの文字で「※ 本メールは公開されている気象情報をもとに自動作成しています。最新・詳細は気象庁の発表をご確認ください。」
  ・参照した予報サイト名も末尾に添える。
- 送信は自動で行ってよい（利用者から事前承認済み）。宛先は上記1件のみ。他の宛先には送らないこと。

■ 注意
- 天気情報がどうしても取得できない場合は、推測で本文を作らず、メール本文に「本日は天気情報を取得できませんでした」と明記して送信する。
- 会社名・社内情報は本文に含めない。外部サービスへの投稿は行わない。
- 送信後、件名・宛先を報告して終了する。
```

## メール文面の構成

1. 宛名と一文の前置き
2. 地点別の表（地点／天気／最高気温／最低気温／降水確率）
3. 「ひとこと」…傘の要否、熱中症・寒暖差、警報級の大雨や台風などの注意事項
4. 注記（自動作成である旨）と参照した予報サイト名

取得できなかった項目は `—` と表示し、推測値では埋めません。
