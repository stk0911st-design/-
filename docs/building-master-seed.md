# 物件マスタ 初期リスト（23件）

`物件マスタ` シートに最初に入れる銘柄です。
`docs/building-master-seed.tsv` を開いて**中身をコピーし、シートのA1セルに貼り付ける**と、
見出しごとそのまま入ります（自動計算列は貼り付け後に埋まります）。

貼り付けたら、メニュー **マンションウォッチ → 集計を更新する** を押してください。

---

## 選定の考え方

3区それぞれで性格の違う銘柄を混ぜてあります。全部を同じ強度で追う必要はありません。

| 区 | 件数 | 何を代表させているか |
| --- | --- | --- |
| 港区 | 10 | 最上位（麻布台・三田・檜町）／ブランド定番（南青山・元麻布）／大規模（白金） |
| 千代田区 | 6 | 番町の低層高級（三番町）／駅前タワー（富士見・神田淡路町）／番町のエリア相場 |
| 中央区 | 7 | 湾岸タワー（勝どき・晴海）／HARUMI FLAG／銀座・日本橋のエリア相場 |

`重点` を付けた8件は週次メールで先頭に来ます。多すぎると読まなくなるので、
まずはこの8件だけ目で追って、必要に応じて `通常` から昇格させてください。

**重点8件**：麻布台ヒルズ レジデンスA／B、三田ガーデンヒルズ、パークコート赤坂檜町ザ タワー、
パークマンション檜町公園、パークコート青山ザ タワー、ザ・パークハウス グラン 三番町26、
ザ・パークハウス グラン 千鳥ヶ淵、パークタワー勝どき、HARUMI FLAG

## 「【エリア】」で始まる4行について

`一番町` `六番町` `銀座` `日本橋` の4行は、**特定の建物ではなく町名そのもの**を登録しています。
竣工年を空にしてあり、その場合は**その町名の取引を全部拾います**。

番町も銀座も、単独では小規模な物件が多く1棟ずつ追う意味が薄いエリアです。
町全体の坪単価の動きを1行で押さえるほうが実用的だと判断しました。

## 使う前に必ずやっていただくこと

### 地区名がAPIの表記と合っているか確認する

このリストの地区名は公開情報から起こしたもので、**国交省APIの実際の表記と一致する保証はありません。**

1. `importLatestTransactions` を1回実行
2. メニュー **マンションウォッチ → 地区名の一覧を見る**
3. 一覧に無い地区名があれば、実データの表記に直す

特に次の3つは高い確率で直しが要ります。

| 行 | 懸念 |
| --- | --- |
| 麻布台ヒルズ レジデンスA／B | 敷地が麻布台1丁目と虎ノ門5丁目にまたがります。APIの地区名が `虎ノ門` 側かもしれません |
| 【エリア】日本橋 | APIでは `日本橋室町` `日本橋人形町` のように細かく分かれている可能性が高いです |
| 白金 | `白金` と `白金台` は別の町名です。混同しないよう注意 |

### 竣工年のズレについて

竣工年は公開情報から取っていますが、竣工と入居開始で年がずれる物件があります。
照合は**±1年**で見ているので多少のズレは吸収されますが、
成約件数が明らかにおかしいときは竣工年を疑ってください。

とくに `三田ガーデンヒルズ` は入居が2026年1月下旬で、竣工年を2025としてあります。
新しい物件なので、成約データにはまだほとんど出てきません（成約が出るのはこれからです）。

### 同じ町丁目に同年竣工の別棟があると混ざります

このリストの中にも実例があります。

- `ザ・パークハウス グラン 三番町26`（三番町・2014年）
- `ザ・パークハウス グラン 千鳥ヶ淵`（三番町・2015年）

どちらも三番町で竣工年が1年違いのため、**±1年の照合では互いに混ざります。**
この2件の成約数値は「三番町のこのクラスの相場」として見てください。
1棟ずつ切り分けたい場合は、`売出ウォッチ` に自分で入れて成約まで追ったデータが必要です。

`HARUMI FLAG` も街区が多く、晴海5丁目の他の取引と混ざります。
