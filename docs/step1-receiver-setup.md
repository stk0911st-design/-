# ステップ① 受け皿を作る（所要 10分ほど）

入力アプリから送られてくる内容を受け取って、スプレッドシートに書き込む
「受け皿」を作ります。作業はすべてご自身の Google アカウントで完結します。

## 1. スプレッドシートを新規作成

1. Google ドライブで新しいスプレッドシートを作る
2. 名前を分かりやすく付ける（例：日報・営業データ受け皿）

## 2. Apps Script を開いてコードを貼る

1. そのスプレッドシートで **拡張機能 → Apps Script**
2. 最初から入っている `function myFunction() {}` を全部消す
3. `gas/Receiver.gs` の中身を全部貼り付ける
4. 保存（フロッピーのアイコン、または Ctrl+S）

## 3. 合言葉を設定する

1. 左の歯車 **プロジェクトの設定**
2. 下の方の **スクリプト プロパティ → プロパティを追加**
3. プロパティ名 `TOKEN`、値に好きな文字列（例：`sh-nippo-2026-xxxx`）
   - 推測されにくいものにしてください。あとでアプリ側にも同じ文字列を入れます
4. **スクリプト プロパティを保存**

## 4. 動作確認（この時点で1回）

1. 上の関数の選択欄で `selfTest` を選び、**実行**
2. 初回は権限の確認が出ます
   - 「このアプリは確認されていません」→ **詳細** → **（プロジェクト名）に移動** → **許可**
   - ご自身が作ったスクリプトなので問題ありません
3. スプレッドシートに戻り、`_log` と `日報明細` のタブができていればOK
4. `日報明細` にできたテスト行は消して構いません

## 5. ウェブアプリとして公開

1. 右上の **デプロイ → 新しいデプロイ**
2. 歯車（種類の選択）→ **ウェブアプリ**
3. 設定
   - 説明：`受け皿 v1`（何でも可）
   - **次のユーザーとして実行：自分**
   - **アクセスできるユーザー：全員**
4. **デプロイ** → 表示された **ウェブアプリの URL** をコピーして控える
   - `https://script.google.com/macros/s/……/exec` という形

### 「アクセスできるユーザー：全員」について

URL を知っている人なら誰でもアクセスできる状態になります。ただし合言葉
（`TOKEN`）が一致しないデータは弾くようにしてあるので、URL と合言葉の両方を
知らない限り書き込めません。URL と合言葉は社外に出さないでください。

---

ここまでできたら、**ウェブアプリの URL** と **設定した合言葉** を控えたうえで、
ステップ②（疎通テスト）に進みます。
