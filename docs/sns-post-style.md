# SNS投稿文のスタイル（読みやすく・丁寧に・少し上品に）

「読みにくい」という指摘を受けて、投稿文（Instagram・Facebook・Threads・X・TikTok・ホームページのトピックス）と、
Slack の確認用の下書きを、同じ形に統一する。

> 会社名・免許番号・LINEのURLなどの実値は、このリポジトリに書かない。
> `<LINE_URL>` `<LICENSE_NO>` のようなプレースホルダで示す。

## 基本ルール

- 内容ごとに空行を入れる。1行は短く、1段落は2〜3行まで。
- 頭に見出しを1行置く（例: `✦ 見出し`）。
- 色味はブランドの緑を、絵文字で少しだけ入れる（`🌿` `🍃` `✦`）。1投稿につき3つまで。多用しない。
- 落ち着いた丁寧な言葉で書く。「！」の連続や、くだけすぎた書き方は避ける。
- 区切り線（`───────`）で、本文・ご案内・会社情報・ハッシュタグを分ける。
- ハッシュタグは本文から2行あけて、最後にまとめる（数の目安は `docs/sns-material-system.md` を参照）。
- 金額・お客様情報・部屋番号は載せない。担当者は名前を出さず「営業担当A」などと書く。

## ひな形

```
✦ 見出し（1行）

本文1段落目（2〜3行）

本文2段落目（2〜3行）

───────
🌿 不動産のご相談は、恵比寿のスマートハウスへ
無料査定もやっています。
お悩みごとも、どうぞお気軽に。

公式LINEからもご相談いただけます
<LINE_URL>
───────
当社は意外と自由な会社です。
株式会社スマートハウス
<LICENSE_NO>

#ハッシュタグ #ハッシュタグ …
```

## 媒体ごとの注意

| 媒体 | 注意 |
| --- | --- |
| Instagram | 本文のURLはリンクにならない。「プロフィールのリンクから公式LINEへ」と書く |
| Facebook | ひな形どおり |
| Threads | ハッシュタグは付けない（または1〜2個） |
| X | 文字数が短い。見出し＋1文＋ご案内＋タグ2〜3個に縮める |
| TikTok | 本文は短く。冒頭1〜3秒の文字も、同じ言葉づかいにそろえる |
| ホームページ（トピックス） | 見出し＋本文。LINEボタンへのリンクを入れる |

物件の投稿は、取引態様・免許番号・CG の注記を、必ずご案内の下に入れる。

## Slack の確認用の下書き

Slack では文字に色を付けられない。次の形で読みやすくする。

- 見出しを太字にする。内容ごとに空行を入れる。
- 投稿する文章は、引用（`>`）で囲んで、説明の文と見分けがつくようにする。
- 媒体ごとに、見出しで分ける。
- 長い一覧は、表または箇条書きにする。
- 緑の四角（`:large_green_square:`）を、見出しの頭に使ってもよい。1メッセージに1〜2個まで。
