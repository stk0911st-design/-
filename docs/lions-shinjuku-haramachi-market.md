## 4. 現時点の読み（初版の所見）

1. **在庫は増え、成約は減っている。** 東京都で在庫 +21.3%・成約 -18.7%。
   売り手優位から買い手優位へ振れつつある局面。売出は「早く・適正価格で」が有利。
2. **エリア単価はまだ強い。** 若松河田・牛込柳町いずれも前年比プラス圏。
   ただし牛込柳町は前月比 -5% と頭打ちのサインが出ている。
3. **当物件の位置づけ。** 推定 約251万円/坪 は、
   エリア平均（若松河田 約443万円/坪）を大きく下回る。
   築42年・小型住戸中心という属性による差で、
   **実需向けの2LDK〜3LDK住戸は現在の売出事例（約281万円/坪）に近い水準を狙える余地**がある。
4. **直接の比較対象はライオンズマンション牛込の 4,380万円（51.5㎡）。**
   この物件の売れ行き（値下げ・成約・取下げ）が当物件の価格戦略の先行指標になる。

## 5. データ取得に関する制約（重要）

現在のセッションは社内ネットワークポリシーにより、
不動産ポータル・国土交通省サイトへの直接アクセスが遮断されています（全て403）。

- 遮断されているドメイン：suumo.jp／athome.co.jp／homes.co.jp／land.mlit.go.jp／
  reinfolib.mlit.go.jp／reins.or.jp／mansion-review.jp／ieshil.com／
  mansion-market.com／rehouse.co.jp／sumnara.jp／cowcamo.jp／
  ebisu-fudousan.com／ebisu-sales.com
- そのため上記の数値は **検索エンジン経由で得られた各サイトの掲載内容**です。
  一次ページを開いて確認したものではないため、**時点のズレ・端数の誤差が混じり得ます**。

### 精度を上げるための決定事項（2026-09-15 小林さん承認）

| # | 内容 | 担当 | 状態 |
| --- | --- | --- | --- |
| 1 | レインズ（会員）から成約・在庫・新規登録の**実数**を抽出し、本ファイルに実数として反映する | 小林さん→秘書AI | 抽出データ（CSV等）の提供待ち |
| 2 | 上記の遮断ドメインを**社内ネットワークの許可リストに追加**する | 小林さん | 手配待ち |

- 1が入るまでは、成約数・在庫数は「検索経由で得た公表値」を使う（傾向把握レベル）。
- 2が通れば、ポータルの在庫数・売出一覧を毎回自動取得できるようになる。

### 未解決：ルーティンから Gmail が使えない

作成したルーティンには **Gmail コネクタが紐付けられませんでした**。
このセッションが持つコネクタ権限を、ルーティン側へ引き渡せない制約があるためです
（create_trigger の警告：this trigger stores no MCP connectors）。

そのため現状、上記2つのルーティンは
**調査と本ファイルの更新・push まではできるが、メール送信ができません。**

#### 解決策（どちらか）

**案1（推奨）：claude.ai の「ルーティン」画面から作り直す**
1. claude.ai → 設定 → ルーティン（Routines）を開く
2. 上記2件（`trig_01APPbT9tSaTg9y4bGPSZZ9z` / `trig_01U68F5uEA1HxQqfG5aQb8r1`）を削除
3. 同じプロンプト・同じ時刻で新規作成し、**コネクタに Gmail を選択**して保存

**案2：既存ルーティンはそのまま使い、通知で受け取る**
ルーティンは調査結果を本ファイルに push するので、
GitHub の通知でブランチの更新を受け取り、中身を確認する運用にする。
ただし「まとめメールが届く」形にはならない。
