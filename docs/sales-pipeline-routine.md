# 営業パイプライン（毎晩の報告）ルーティン

その日に出社した営業の人と、代表・取締役（融資担当）に向けて、
「今日のお礼」と「目標までの進み」を1枚の PDF（2ページ）にまとめ、
Slack の営業パイプラインのチャンネルへ毎晩投稿する仕組みです。

## 動き方

| 項目 | 内容 |
| --- | --- |
| 起動 | Claude のルーティン。月・火・木・金・土の 19:00 ごろ（JST）。会社休日の水曜・日曜は動かない |
| 宛先 | その日に出社した営業の人＋代表＋取締役（融資担当）。勤務表で出社を確かめ、休みの人には送らない |
| 投稿先 | Slack の営業パイプラインのチャンネル（対象者へのメンション付き）。PDF を添付 |
| PDF | `pipeline-pdf/render.js` で作る。ひな形は `pipeline-pdf/template.html`、データの形は `pipeline-pdf/sample-data.json` |

チャンネル ID・ユーザー ID・ファイル ID・社員名などの実値は、このリポジトリには置かず、
ルーティンのプロンプト側だけに書きます。

## 材料

1. **今日の「ありがとう」**：朝礼夕礼のチャンネル、営業系のチャンネル、日報カウンターの当日分から、
   営業に関わる「やったこと」を人ごとに拾う。顧客名・売主名・金額は書かない。
2. **目標までの進み（割合だけ）**：
   - まず経営進捗管理表（ドライブ）の「経営ダッシュボード」から、売上の達成率・想定進捗率・基準日を取る。
   - 管理表の基準日が、Slack に投稿済みの最新の営業パイプライン PDF の基準日より古いときは、
     その PDF の割合（決済済・契約済・契約予定・いまの目安）を使う。
   - どちらを使ったかと基準日を、PDF と投稿の両方に書く。
   - **金額（円）は一切書かない。** 管理表から読むのは割合と件数だけ。
3. **これからの山場**：代表のカレンダーとサイボウズの予定のうち、決済・契約・現地・面談など営業に関わるもの（金額や会議URLは書かない）。

## 守ること

- 金額（売上・粗利・預金・借入・買付額・査定額・目標額）は書かない。`render.js` も、
  データに「円」「万」「¥」などが入っていると PDF を作らずに止まる。
- 拾えなかった材料は「確認できませんでした」と書く。推測で埋めない。
- 生成した PDF とデータは `pipeline-pdf/out/`（`.gitignore` 済み）に置き、コミットしない。

## 手元で PDF を試す

```bash
node pipeline-pdf/render.js pipeline-pdf/sample-data.json pipeline-pdf/out/sample.pdf
```

Playwright と Chromium が入っている環境で動きます。日本語は IPA ゴシック（無ければ Google Fonts の Noto Sans JP）で表示します。
