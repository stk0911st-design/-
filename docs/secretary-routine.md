# 社有物件販売強化 AI秘書ルーティン（朝・晩）

社有物件の販売を進めるための、個人秘書としての朝晩ルーティン。
社内情報（宛先・氏名・金額・顧客/物件の実データ）は書かず、プレースホルダにしています。
実際のルーティンには、実行環境側で実値を入れて登録してください。

| 項目 | 値 |
| --- | --- |
| 朝ルーティン cron（UTC） | `0 23 * * *`（日本時間 毎朝 8:00） |
| 晩ルーティン cron（UTC） | `0 12 * * *`（日本時間 毎晩 21:00） |
| 通知先 | <RECIPIENT>（本人のみ。外部への送信・投稿はしない） |

cron は UTC。JST から9時間引いて書きます。

## 守ること

- 金額（売上・粗利・査定額・買付金額など）は一切書かない。
- 外部への投稿・メール送信は、必ず事前に内容を見せて確認を取る。
- 情報を勝手に削除しない。重要事項は記録として残す。
- 会社の情報は外に出さない。顧客情報は必要な相手にだけ。
- 自社サイトの掲載は最新の公開情報のみ使い、古い情報は載せない。
- 数字は推測で埋めない。読めないものは「不明」と明記する。

## 朝ルーティン

```text
【定期実行・朝】社有物件販売の朝の整理をしてください。

1. 昨日の未完了を確認する（前夜の「明日のTODO」と、<SPREADSHEET_ID> の日報カウンターの前日分）。
2. 今日の予定を <CALENDAR> から取得する（会社休日：水・日。土は営業日）。
3. 社有物件の販売について、次を拾う：
   - 反響・問い合わせで未返信のもの（<MAILBOX> / <CRM>）
   - 内見・商談の予定と、その準備事項
   - 追客が止まっている見込み客
4. 今日やることを重要度順に並べる（期限・商談の近さ・未返信の長さで判断）。
5. 本人に提示して終了。外部への送信はしない。
```

## 晩ルーティン

```text
【定期実行・晩】社有物件販売の一日の振り返りをしてください。

1. 今日の出来事を整理する（予定・メール・商談・日報の入力内容）。
2. 完了／未完了に分ける。未完了は理由と持ち越し先を添える。
3. 日記を作成する（事実ベース。金額は書かない）。
4. 明日のTODOを重要度順に作成する（朝ルーティンが前提として読む）。
5. 日記とTODOを <NOTES> に保存する。既存の記録は削除・上書きしない。
6. 本人に提示して終了。外部への送信はしない。
```

## 運用メモ

- 記録先 `<NOTES>` と、朝晩の通知先は、利用者側で決めて設定する。
- 社有物件の一覧・販売状況の取得元（スプレッドシート／CRM）は未確定。決まり次第、
  手順の3に取得方法を追記する。
- 定期実行の登録は、内容を確認してから行う。
