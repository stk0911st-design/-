# FP 3級・2級 毎日5問メール

2026年10月21日開始。宅建の直前5問（10/12〜10/18、全13通）の後継です。

宛先はご本人と代表の2件のみ。アドレスはルーティン側で管理しています。

## ねらい

宅建で身につけた知識が、FPの6分野のうち「不動産」「相続・事業承継」、
それに「タックスプランニング」の一部と重なります。

| 分野 | 宅建との重なり |
|---|---|
| 1. ライフプランニングと資金計画 | ほぼなし（社会保険・年金は新しい領域） |
| 2. リスク管理（保険） | ほぼなし |
| 3. 金融資産運用 | ほぼなし |
| 4. タックスプランニング | 一部（不動産の譲渡、各種の税） |
| 5. 不動産 | **大きい**（登記、媒介、借地借家、都計法、建基法、区分所有、税） |
| 6. 相続・事業承継 | 一部（相続分、遺言、不動産の評価） |

重なっているところは「もう知っている」と気づけるように見せて自信にし、
新しい3分野は丁寧に積み上げる、という組み立てにしています。
宅建で学んだ論点には 🏠 の印を付けます。

## 配信のかたち

| 項目 | 内容 |
|---|---|
| 頻度 | 毎日1通（夜） |
| 問題数 | 5問・すべて ○× の一問一答 |
| レベル | 3級と2級を織り交ぜる（基本は3級3問・2級2問） |
| 分野 | 6分野を順に軸にする。軸から3〜4問、残りは別分野から |
| ○×の比 | 3対2 か 2対3。どちらかに偏らせない |
| 構成 | 問題5問 → 答えと解説 → 今日の3点 → 短い励まし |

## 書くときの決まり

- **年度で変わる数字に注意する。** 控除額、保険料率、年金額、非課税枠、特例の上限などは
  改正で動きます。扱わないか、「年度によって変わるので最新の数字はテキストで確認を」と
  必ず添えるか、どちらかにします。自信のない数字を断定で書きません。
- **試験の日程・受検資格・申込方法・会場・持ち物は書きません。** 制度が変わっている
  可能性があり、推測で書くと迷惑になります。「公式サイトでご確認ください」までにとどめます。
- 特定の回の問題をそのまま載せず、よく問われる論点を一問一答に書き直したものだと明記します。
- 毎日続くものなので、「やらないと間に合わない」という書き方をしません。
  読めない日があってよい、という空気で書きます。

## 送信前の確認

宅建の配信で実際に起きた失敗を踏まえた項目です。

1. 問題5問と答え5つがそろっているか
2. **○×の表示と解説の結論が一致しているか** — 問題文から自分で判定 → 答案欄と照合 →
   解説の結論と照合、の3段で確かめる（宅建で1度、正答の表示を間違えて訂正メールを出しました）
3. 3級と2級のラベルが両方入っているか
4. 年度で変わる数字に断りが入っているか
5. 日本語以外の文字（英単語・キリル文字・ハングル・簡体字）が混じっていないか
   （キリル文字やハングルが紛れ込んだことが複数回あります。1文字ずつ見ます）
6. 署名2行と注記2行が入っているか
7. プレーンテキストとHTMLの両方が入っているか（携帯キャリアのアドレス宛のため）
