# LINE公式アカウント 週1「不動産トピック」配信

LINE公式アカウントで週1回、不動産のお役立ちトピックを配信し、
新ホームページへ誘導して相談・査定の問い合わせにつなげるための運用メモと原稿。

> 社内情報はこのファイルに書かない（CLAUDE.md のルール）。
> URL・電話番号などは次のプレースホルダで書き、配信時に差し替える。
>
> | プレースホルダ | 中身 |
> | --- | --- |
> | `<HOMEPAGE_URL>` | 新ホームページのURL（パラメータなし） |
> | `<CONTACT_URL>` | 新ホームページの問い合わせ・無料相談ページのURL |
> | `<TEL>` | 対外的に案内する電話番号 |

## 運用ルール

| 項目 | 内容 |
| --- | --- |
| 頻度 | 週1回 |
| 配信日時（推奨） | 毎週 木曜 20:00（水曜休業明け。週末の相談・内見予約につなげる） |
| 配信方法 | LINE Official Account Manager → 「メッセージ配信」→「予約配信」 |
| 構成 | 画像1枚（任意）＋テキスト1通。①不動産トピック（300〜400字）→②♨今週の温泉ひとこと（80〜120字）→③🍴恵比寿グルメ便り（80〜120字）→④締め→⑤ハッシュタグ15〜20個 |
| 必ず入れるもの | ホームページURL／電話番号／「このLINEに返信で相談OK」の一文 |
| 承認 | 配信前に代表が文面を確認する。自動投稿はしない |
| 書かないもの | 特定の顧客・物件が分かる情報、社内の数字 |

### 効果測定

URL は `<HOMEPAGE_URL>` をそのまま載せ、計測用パラメータは付けない
（社内ルール：署名・名刺などと同じく、余計なパラメータを付けない表記に統一）。
クリック数は LINE Official Account Manager の「分析」→「メッセージ配信」で配信ごとに確認できる。

### ハッシュタグ

LINE の通常のメッセージ配信ではハッシュタグは検索にかからず、友だち以外には広がらない。
拡散を狙う場合は、同じ文面を **LINE VOOM** と **Instagram** にも投稿する（こちらはタグ検索から見つけてもらえる）。

固定タグ：`#スマートハウス #恵比寿 #恵比寿不動産 #渋谷区 #不動産 #不動産相談 #不動産売却 #相続 #相続不動産`
＋その回の不動産テーマ・温泉地・グルメのタグ。

### 温泉・グルメ欄の注意

- 実在し、現在営業中であることを確認できた温泉地・店だけ書く。閉店・休業中の店は使わない。
- 価格・メニューの細部など変わりやすい情報は書かない。他店との比較や悪口はしない。
- 半年以内に取り上げた温泉地・店と重ならないようにする。

### 税制・金利を書くときの注意

- 税制は毎年改正される。**配信前に最新の国税庁・国交省の情報で確認**する。
- 金利は「今後どうなるか」を断定しない。見通しは「〜と言われています」「〜の可能性」にとどめる。
- 個別の税額判断は税理士の領域。原稿は「一般的な仕組み」の紹介までにし、
  「具体的なケースはご相談ください」で締める。

## 毎週の原稿作成（Claude ルーティン）

毎週火曜の朝、その週の木曜配信分の原稿を Claude が作り、代表あてにメールで届ける。
**LINEへの投稿は自動化しない**。代表が確認し、LINE Official Account Manager で予約配信する。

| 項目 | 値 |
| --- | --- |
| cron（UTC） | `0 23 * * 1` |
| 対応する日本時間 | 毎週 火曜 8:00 |
| 起動モード | 既存セッションを継続（Gmail コネクタを保持しているため） |
| 宛先 | 代表本人のアドレス（`<RECIPIENT>`。本人の3アドレスすべて） |
| 件名 | 【LINE原稿】M/D(木)20:00配信分「テーマ名」／♨温泉地名／🍴店名 |

ルーティンの処理内容（実値は伏せている）：

1. 2026-09-29（火）を第2週として週番号を数え、上の「12週分のテーマ案」から該当テーマを選ぶ。
   第13週以降は、件名「【LINE原稿】」の過去メールで既出テーマを確認し、重複しない新テーマを選ぶ。
2. 税制・制度・金利は国税庁・国交省・法務省・日銀などの最新情報を確認してから書く。
   確認できない数字は書かない。
3. 原稿の末尾は `<HOMEPAGE_URL>`・`<TEL>`・「このLINEに返信で相談OK」で固定。
4. 本文の後に「♨ 今週の温泉ひとこと」「🍴 恵比寿グルメ便り」、締めの後にハッシュタグ15〜20個を付ける。
5. 原稿・確認に使った情報源・配信前の確認ポイントをメールで代表に送る。代表以外には送らない。
