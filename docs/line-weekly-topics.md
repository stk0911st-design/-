# LINE公式アカウント 週1「不動産トピック」配信

LINE公式アカウントで週1回、不動産のお役立ちトピックを配信し、
新ホームページへ誘導して相談・査定の問い合わせにつなげるための運用メモと原稿。

> 社内情報はこのファイルに書かない（CLAUDE.md のルール）。
> URL・電話番号などは次のプレースホルダで書き、配信時に差し替える。
>
> | プレースホルダ | 中身 |
> | --- | --- |
> | `<HOMEPAGE_URL>` | 新ホームページのURL（計測用パラメータ付き。下記参照） |
> | `<CONTACT_URL>` | 新ホームページの問い合わせ・無料相談ページのURL |
> | `<TEL>` | 対外的に案内する電話番号 |

## 運用ルール

| 項目 | 内容 |
| --- | --- |
| 頻度 | 週1回 |
| 配信日時（推奨） | 毎週 木曜 20:00（水曜休業明け。週末の相談・内見予約につなげる） |
| 配信方法 | LINE Official Account Manager → 「メッセージ配信」→「予約配信」 |
| 構成 | 画像1枚（任意）＋テキスト1通。テキストは 300〜450 字を目安 |
| 必ず入れるもの | ホームページURL／「このLINEに返信で相談OK」の一文 |
| 承認 | 配信前に代表が文面を確認する。自動投稿はしない |
| 書かないもの | 特定の顧客・物件が分かる情報、社内の数字 |

### 効果測定用のURL

URL の末尾に次のパラメータを付けると、Googleアナリティクスで LINE からの流入を数えられる。

```
<HOMEPAGE_URL>?utm_source=line&utm_medium=social&utm_campaign=weekly_topic&utm_content=<配信日YYYYMMDD>
```

### 税制・金利を書くときの注意

- 税制は毎年改正される。**配信前に最新の国税庁・国交省の情報で確認**する。
- 金利は「今後どうなるか」を断定しない。見通しは「〜と言われています」「〜の可能性」にとどめる。
- 個別の税額判断は税理士の領域。原稿は「一般的な仕組み」の紹介までにし、
  「具体的なケースはご相談ください」で締める。

## 原稿（第1〜4週）

### 第1週　相続した「いらない土地・空き家」

```
【知らないと損する不動産トピック】
親から相続した「使わない土地・空き家」、どうしていますか？

放っておくと、固定資産税や草木の管理、近所からの苦情…と負担だけが続きます。
選択肢は大きく4つです。

① 売る：現金化して兄弟で分けやすい
② 貸す：賃料収入。ただし修繕費や空室リスクも
③ 活用する：駐車場・建て替えなど
④ 手放す：条件を満たせば国に引き取ってもらう制度も（相続土地国庫帰属制度）

「売れるのか分からない」「遠方で見に行けない」土地でも、まずは状況の整理から。
相続不動産のご相談は、当社の得意分野です。
```

### 第2週　家を売るときの「3,000万円特別控除」

```
【知らないと損する不動産トピック】
マイホームを売って利益が出ると、本来は税金がかかります。
でも「居住用財産の3,000万円特別控除」を使えば、
利益から最大3,000万円を差し引けるため、税金がかからないケースも多いんです。

▼ポイント
・自分が住んでいた家（またはその敷地）の売却が対象
・住まなくなってから3年目の年末までに売る必要あり
・親子や夫婦間の売買は対象外
・利益がなくても、他の特例との関係で申告した方がよい場合も

「いつ売るか」で使える特例が変わります。
売却を考え始めたら、早めのご相談がおトクです。

▼詳しくはホームページへ
<HOMEPAGE_URL>

このLINEに返信いただくだけでもご相談OKです。
```

### 第3週　住宅ローン金利はこの先どうなる？

```
【知らないと損する不動産トピック】
「金利が上がる」というニュース、気になっていませんか？

日銀が金融政策を見直し、長く続いた超低金利の時代は変わりつつあります。
一般に、変動金利は政策金利の影響を、固定金利は長期金利の影響を受けます。

▼考え方のヒント
・変動：今の金利は低めだが、将来の上昇リスクを自分で負う
・固定：金利は高めだが、返済額が最後まで確定する
・大切なのは「金利が〇%上がっても払えるか」を事前に試算しておくこと

先のことは誰にも断定できません。
だからこそ、ご家庭の収支に合わせた借り方を一緒に考えます。
金融機関出身のスタッフが在籍しています。

▼詳しくはホームページへ
<HOMEPAGE_URL>

このLINEに返信いただくだけでもご相談OKです。
株式会社スマートハウス（恵比寿）
```

```
よくいただくご質問です。

相場の天井や底は、後になってからしか分かりません。
判断のものさしは、相場よりも「ご自身の事情」です。

この3つが揃っていれば、「買いどき」はご自身で決められます。
物件探しだけでなく、「買うべきかどうか」のご相談からお受けしています。
```
