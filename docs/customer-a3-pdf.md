# お客さま説明用 A3横PDF「いまの不動産市場」

売却・購入のご相談の場で、市況をそのままお見せできるA4ではなくA3横2ページの資料です。

## 作り方

```sh
/usr/bin/python3.13 tools/build_customer_a3.py
```

`out/いまの不動産市場_お客さま用_YYYY-MM-DD.pdf` ができます。

確認は `pdftoppm -png -r 72 <pdf> a3` で各ページを画像にして目で見ること。
枠の高さは固定なので、文章を足したらはみ出していないか必ず確認します。

## なぜ reportlab なのか

社内資料のA4版は Chromium の `--print-to-pdf` で作っていますが、
日本語が Type3 フォントとして吐かれ、2ページでも700KB近くになります。
この大きさだとメール添付にもドライブ保存にも載せられません
（この実行環境ではファイルの中身を base64 の文字列として運ぶしかなく、
18万文字は確実に通せる量ではないため）。

reportlab に IPAPGothic を subset 埋め込みする方式だと同じ2ページで135KB程度です。

## フォントの2系統

| 方式 | 作り方 | 大きさ | 使いどころ |
| --- | --- | --- | --- |
| 埋め込み（既定） | そのまま実行 | 約135KB | **これが配布用。** どの環境でも同じに見える |
| CID指定 | `BROKER_PDF_CID=1` を付けて実行 | 約18KB | 自動配信に載せたいとき |

CID版（HeiseiKakuGo-W5）は字形を持たないので小さくなりますが、
**文字幅が埋め込み版より最大で約11%広く**、いまのレイアウトでははみ出します。
CID版を配るなら、枠に1割以上の余裕を持たせたレイアウトに直してから使うこと。
幅の比較は次で出せます。

```python
pdfmetrics.stringWidth(s, "TT", size)   # 埋め込み
pdfmetrics.stringWidth(s, "HeiseiKakuGo-W5", size)
```

## 構成（A3横・2ページ）

| ページ | 内容 |
| --- | --- |
| 1 | 中古マンション市況（前年同月比の棒グラフ・成約価格の折れ線）／新築・金利／商圏エリアの相場／月ごとの推移／売るとき買うときの3点 |
| 2 | 大手7社の実績一覧／取扱件数の5年推移／ことばの説明／よくあるご質問／読み取れること／売却をご検討の方へ |

## 中身のルール

- お客さまにお見せする資料なので、社内向けの推測や competitor の内情は書かない。
  2ページ目は「各社が公表している実績」と、その読み取りまでにとどめる。
- 当社の売上・粗利・残高・買付金額・査定額は一切載せない。
- 顧客の個人名・物件名・部屋番号は載せない。
- 確認できていない項目は「—」のままにし、推測で埋めない。
- グラフは指標ごとに分け、1枚に2つの軸を持たせない。
  数値が取れていない月は線をつながず途切れさせる。

数値は `data/brokers.json` と揃えること。
