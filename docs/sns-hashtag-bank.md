# ハッシュタグ集（満タンで付ける）

**すべての投稿に、ハッシュタグを「満タン」で付ける。付けない投稿は、投稿の意味が薄くなる。**

> 他社名・他人の名前・お客様や物件が特定できるタグは付けない。実値（アカウント名・URL・氏名）は書かない。

## 絶対のルール（必須）

1. **Instagram は30個（上限）を使い切る。** 29個以下は不可。
2. **TikTok は20〜30個。** Facebook は15〜20個。
3. **X は、文字数（280字）に収まる範囲で、できるだけ多く**（目安5〜8個）。本文より先にタグの文字数を確保する。
4. **Threads は、1投稿に付けられるタグは1個（Threads の仕様）。** 付けるときは、いちばん近い話題の1個を、必ず付ける。
5. **ホームページ（トピックス）は、タグの代わりに、カテゴリと関連キーワードを入れる。**
6. 毎回、**固定タグ（コア）＋エリア＋内容＋季節**の組み合わせで作る。同じ並びの使い回しは避ける。
7. **投稿の報告（✅とURL）に、各媒体のハッシュタグ数を書く。** 数が足りない投稿は、翌日までに編集で足す。
