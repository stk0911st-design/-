# 送信メールの保存・蓄積

毎日の「送信済みメール」を1日1回まとめて読み取り、Google ドライブへ日付ごとの記録ファイルを
作っていく仕組みです。日次の振り返り・日記や、あとから「いつ・誰に・何を送ったか」を
たどるための一次記録として使います。

※ アドレス・ファイルID などの社内情報はこのリポジトリには置かず、
実行環境側（ルーティン設定）で管理します。

## 保存先

| 項目 | 内容 |
| --- | --- |
| 置き場所 | Google ドライブのフォルダ「送信メールログ」（共有しない） |
| ファイル | Google ドキュメント。既存ファイルは削除も上書きもせず、追加のみ |
| 単位 | 1日1ファイル（`送信メールログ YYYY-MM-DD`） |
| 実行 | 毎日 21:40（JST）。夜の定期メール（21:00）から少しずらす |

## 記録する項目（要点のみ）

1件につき1〜2行。「時刻（JST）／宛先／件名／要点1行」。添付があるときだけ「添付あり」を付けます。

本文の全文は書きません。原本は Gmail に残っているため、記録は要点だけにとどめます。

分類は次の3つ。自動配信と転送は件名と宛先だけの1行で足ります。

- 実務メール
- 自動配信・定期レポート
- 転送

## プライベートは記録しない

- 家族・友人など業務外の相手宛、私的な手続き・買い物・SNS関連は、件名も本文も記録しません。
- 代わりに末尾へ「プライベート ○件（内容は記録せず）」と件数だけ残します。
- 業務か私的か判断がつかないものは、業務として記録します。

## 運用ルール

- **追記のみ。** 過去の記録は削除も上書きもしません。
- 1日ぶん取り逃しても、Gmail に原本が残っているため後から遡って追記できます。
- 記録は社外秘。フォルダは共有せず、本人のドライブ内にのみ置きます。
- 各日の末尾に「申し送り」として、未返信・宿題になっている件をまとめます。

## 取得手順

1. 対象日（JST）を決める。
2. Gmail を `in:sent after:YYYY/MM/DD before:YYYY/MM/DD` で検索する。
3. スレッド一覧では同一スレッドの古いメッセージが出ないことがあるため、
   件数が合わない場合は該当スレッドを個別に開いて補う。
4. プライベートな送信を除き、分類ごとに時刻順で並べる。
5. その日のファイルを新規に作成する。既存のファイルは触らない。
6. 未返信・宿題・期日が近いものを「申し送り」として末尾に3〜5行でまとめる。
7. 送信が0件の日も「送信なし」と記した記録を必ず作成する。

## 注意点

- ドライブのファイルは、これらのツールでは**新規作成しかできず、追記や上書きができません**。
  そのため月次の1ファイルにまとめる形ではなく、1日1ファイルを積み上げる形にしています。
- 2026-09-05 ぶんだけは、この運用を決める前に作った詳細版（`送信メールログ 2026-09`）も
  残っています。消さずにそのままにしています。
- **定期実行の登録は claude.ai のルーティン画面から行う必要があります。**
  セッション側から登録したルーティンは Gmail・ドライブへの接続を引き継げず、
  起動しても何もできません（試験実行で確認済み。当該ルーティンは無効化してあります）。
  プロンプトはアドレス・フォルダIDを含むため、このリポジトリには置かずルーティン側で管理します。
