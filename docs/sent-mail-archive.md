# 送信メールの保存・蓄積

毎日の「送信済みメール」を1日1回まとめて読み取り、Google ドライブの記録ファイルへ
追記していく仕組みです。日次の振り返り・日記や、あとから「いつ・誰に・何を送ったか」を
たどるための一次記録として使います。

※ アドレス・ファイルID などの社内情報はこのリポジトリには置かず、
実行環境側（ルーティン設定）で管理します。

## 保存先

| 項目 | 内容 |
| --- | --- |
| 置き場所 | Google ドライブのフォルダ「送信メールログ」（共有しない） |
| ファイル | 月ごとに1つ（`送信メールログ YYYY-MM`／Google ドキュメント） |
| 追記単位 | 1日1ブロック |

## 記録する項目

送信時刻（JST）／差出アドレス／宛先・Cc／件名／要旨／添付の有無／分類

分類は次の4つ。

- 実務メール（社外・社内）
- 秘書・自動配信（自分宛）
- 転送
- テスト送信

本文の全文は Gmail に原本が残るため、記録ファイルには要旨のみを残します。
全文保存に切り替えることも可能ですが、ファイルが重くなります。

## 運用ルール

- **追記のみ。** 過去の記録は削除も上書きもしません。
- 1日ぶん取り逃しても、Gmail に原本が残っているため後から遡って追記できます。
- 記録は社外秘。フォルダは共有せず、本人のドライブ内にのみ置きます。
- 各日の末尾に「申し送り」として、未返信・宿題になっている件をまとめます。

## 取得手順

1. 対象日（JST）を決める。
2. Gmail を `in:sent after:YYYY/MM/DD before:YYYY/MM/DD` で検索する。
3. スレッド一覧では同一スレッドの古いメッセージが出ないことがあるため、
   件数が合わない場合は該当スレッドを個別に開いて補う。
4. 分類ごとに整理し、時刻順（実務メールは時刻順、その他は種別ごと）に並べる。
5. 月のファイルの末尾に、その日のブロックを追記する。既存の記述は消さない。
6. 未返信・宿題になっている件を「申し送り」として末尾にまとめる。
