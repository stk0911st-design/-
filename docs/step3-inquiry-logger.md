# ステップ③ HP問い合わせを自動で記録する（所要 15分ほど）

ホームページの問い合わせフォームから届く通知メールを Gmail から拾って、
スプレッドシートに1件1行で記録し、月ごとの件数を自動集計します。

これで「今月は何件きたか」「どんな内容だったか」がいつでも見られるようになります。

## 前提：どのアカウントで作るか

フォームの通知メールが**実際に届いている Google アカウント**で作業してください。
現在の通知先は次のとおりです。

| サイト | 通知メール | 受信先 |
| --- | --- | --- |
| 新HP（Netlify） | 件名「【HP問い合わせ】新しいお問い合わせがありました」 | `kaimasu@` |
| 旧HP | 件名「【HPメール問い合わせ】…」 | `info@`（旧ドメイン） |

上記が転送などで1つの Gmail にまとまっているなら、そのアカウントで1つ作れば足ります。
別々に届いている場合は、それぞれのアカウントで同じ手順を繰り返してください。

## 1. スプレッドシートを新規作成

1. Google ドライブで新しいスプレッドシートを作る
2. 名前を付ける（例：HP問い合わせ記録）

## 2. Apps Script を開いてコードを貼る

1. そのスプレッドシートで **拡張機能 → Apps Script**
2. 最初から入っている `function myFunction() {}` を全部消す
3. `gas/InquiryLogger.gs` の中身を全部貼り付ける
4. 保存（Ctrl+S）

## 3. 動作確認（この時点で1回）

1. 上の関数の選択欄で `previewInquiries` を選び、**実行**
2. 初回は権限の確認が出ます
   - 「このアプリは確認されていません」→ **詳細** → **（プロジェクト名）に移動** → **許可**
   - Gmail を読む権限を求められます。読むだけで、削除も既読化もしません
3. 下の**実行ログ**に、拾えたメールの一覧が出ます
   - ここで0件なら、通知メールが別のアカウントに届いています（前提の表を確認）
4. 内容が問題なければ `logInquiries` を選んで **実行**
5. スプレッドシートに `HP問い合わせ` と `HP問い合わせ月次` のタブができていればOK

## 4. 自動実行の設定

1. 左の時計アイコン **トリガー** → **トリガーを追加**
2. 設定
   - 実行する関数：`logInquiries`
   - イベントのソース：**時間主導型**
   - 時間ベースのタイマー：**1時間おき**（1日1回でも可）
3. 保存

これで、問い合わせが来るたびに自動で1行追加されます。

## 5. （任意）月次サマリーメール

月の件数と一覧をメールで受け取りたい場合のみ設定します。
**送信先を設定しない限り、メールは一切送信されません。**

1. 左の歯車 **プロジェクトの設定 → スクリプト プロパティ**
2. `SUMMARY_RECIPIENT` に送信先アドレスを入れる（`SUMMARY_CC` は任意）
3. `previewInquirySummaryMail` を実行して、実行ログで文面を確認する（送信されません）
4. 問題なければトリガーを追加
   - 実行する関数：`sendInquirySummaryMail`
   - 時間主導型 → 月ベースのタイマー → 1日 → 午前8時〜9時

## 設定できる項目（スクリプト プロパティ）

すべて任意です。何も設定しなくても動きます。

| プロパティ | 内容 |
| --- | --- |
| `SPREADSHEET_ID` | 別ファイルに記録する場合のみ。スプレッドシートに紐付けて作ったなら不要 |
| `SEARCH_QUERY` | Gmail の検索条件。フォームを増やしたときにここへ追加する |
| `SEARCH_DAYS` | 何日前まで遡って探すか（既定 30）。過去分を取り込むときは一時的に `365` などにする |
| `LABEL_NAME` | 記録済みメールに付ける Gmail ラベル名。設定した場合のみ付与 |
| `SUMMARY_RECIPIENT` | 月次サマリーの送信先。未設定なら送信しない |
| `SUMMARY_CC` | 月次サマリーのCC（カンマ区切り） |

## 記録される内容

`HP問い合わせ` タブ（1件1行）

`受信日時 / 経路 / 種別 / 会社名 / 担当者名 / 電話番号 / メールアドレス / 物件所在地 / 物件種別 / 希望価格 / 内容 / 件名 / 差出人 / 本文 / メッセージID / 記録日時`

- **経路**：新HP / 旧HP / その他
- **種別**：テスト送信と判断したものは「テスト」。月次集計では件数から除外されます
- **メッセージID**：二重記録を防ぐための目印。この列は消さないでください

`HP問い合わせ月次` タブは `月 / 実件数 / テスト件数 / 合計` を自動で作り直します。
手で編集しても次回実行時に上書きされるので、メモは別タブに書いてください。

## 注意点

- **メールは削除・既読化しません。** 記録済みかどうかはメッセージIDで判定します
- フォームの項目名（「貴社名」「担当者名」など）を変えた場合は、
  `InquiryLogger.gs` 冒頭の `INQUIRY_FIELDS` に新しい項目名を足してください
- 受信先メールボックスの容量が上限に達すると、通知メール自体が届かなくなります。
  受信先の容量には余裕を持たせてください
- 電話でのお問い合わせはこの仕組みでは記録されません
