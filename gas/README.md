# DailyReportMailer（Apps Script 版）

日報カウンターのスプレッドシートから、前営業日に入力された内容を集計して
指定アドレスへメール送信する Apps Script です。

## 導入手順

1. 日報カウンターのスプレッドシートを開き、「拡張機能 → Apps Script」。
   （スプレッドシートの編集権限が必要です）
2. `DailyReportMailer.gs` の内容を新しいスクリプトファイルに貼り付ける。
3. 「プロジェクトの設定 → スクリプト プロパティ」に次を追加する。

   | プロパティ | 値 |
   | --- | --- |
   | `RECIPIENT` | 送信先メールアドレス |
   | `CC` | （任意）CCアドレス。カンマ区切り |

   ※ 別ファイルのスプレッドシートを対象にする場合のみ `SPREADSHEET_ID` も設定します。
   スクリプトを日報カウンターのスプレッドシートに紐付けて作成した場合は不要です。
4. `previewDailyReportMail` を実行して、実行ログで文面を確認する（送信はされません）。
5. 問題なければ「トリガー → トリガーを追加」で次を設定する。
   - 実行する関数: `sendDailyReportMail`
   - イベントのソース: 時間主導型
   - 日付ベースのタイマー: 午前8時〜9時
   - ※ 土日は関数側でスキップします。

## 動作

- 火〜金：前日1日分
- 月：前週の金・土・日の3日分
- 土日：何もしない
- 対象日に入力が0件でも「入力なし」のメールを送信します。

# SubsidyMailer（Apps Script 版・補助金ウォッチ）

`SUBSIDIES` に登録した補助金・助成金から締切までの残日数を計算し、至急のものを先頭に並べて
プロフィール別にメール送信する Apps Script です。**差出人アドレスを指定できる**のが特徴で、
Gmail のエイリアスに登録したアドレスから送信できます。

## プロフィール

| キー | 対象条件 | 配信頻度 | 送信先プロパティ |
| --- | --- | --- | --- |
| `tokyo` | 東京都／従業員6〜20人／不動産業 | 毎週 | `RECIPIENT_TOKYO` |
| `kanagawa` | 神奈川県／従業員5人以下（小規模事業者） | **隔週** | `RECIPIENT_KANAGAWA` |

条件が違うと対象制度が変わるため、1通にまとめず別々のメールとして送ります。
（例：小規模事業者持続化補助金は `kanagawa` のみ対象）

### 隔週配信の仕組み

Apps Script の時間主導型トリガーは「毎週」までしか設定できません。そのため
**トリガーは毎週にしておき、関数側で「今週が配信週か」を判定**しています。

基準日（既定 `BIWEEKLY_ANCHOR` = `2026-09-10`）を含む週から1週おきに送信します。
実行曜日がずれても週単位で判定がぶれないよう、週の始まり（月曜）に正規化して数えています。

| 木曜 | tokyo | kanagawa |
| --- | --- | --- |
| 2026/9/10 | 送信 | 送信 |
| 2026/9/17 | 送信 | — |
| 2026/9/24 | 送信 | 送信 |
| 2026/10/1 | 送信 | — |
| 2026/10/8 | 送信 | 送信 |

基準日を変えたいときは、スクリプトプロパティ `ANCHOR_KANAGAWA` に `YYYY-MM-DD` を設定します
（1週ずらしたい場合はこの値を7日前後させる）。頻度そのものを変える場合は `PROFILES` の
`everyWeeks` を書き換えます（`1`＝毎週、`3`＝3週に1回）。

## 導入手順

1. **先に Gmail のエイリアスを登録する。**
   Gmail の「設定 → アカウントとインポート → 他のメールアドレスを追加」で
   差出人にしたいアドレスを追加し、確認メールで認証を完了させる。
   ※ この登録がないと送信時にエラーになります（スクリプト側で検証しています）。
2. Apps Script プロジェクトを新規作成し、`SubsidyMailer.gs` の内容を貼り付ける。
3. 「プロジェクトの設定 → スクリプト プロパティ」に次を追加する。

   | プロパティ | 値 | 必須 |
   | --- | --- | --- |
   | `SENDER` | 差出人アドレス（エイリアス登録済みのもの） | 任意※ |
   | `SENDER_NAME` | 差出人の表示名 | 任意 |
   | `RECIPIENT_TOKYO` | 東京都プロフィールの送信先（カンマ区切り可） | いずれか |
   | `RECIPIENT_KANAGAWA` | 神奈川プロフィールの送信先（カンマ区切り可） | いずれか |
   | `CC` | CCアドレス（カンマ区切り） | 任意 |
   | `ANCHOR_KANAGAWA` | 隔週配信の基準日 `YYYY-MM-DD` | 任意 |

   ※ `SENDER` 未設定の場合はスクリプト実行アカウントのアドレスから送信されます。
   送信先プロパティが未設定のプロフィールは自動的にスキップされます。

4. `previewSubsidyMail` を実行して、実行ログで両プロフィールの文面を確認する（送信はされません）。
   配信週かどうかもログに出ますが、プレビューでは配信週でなくても文面を表示します。
5. 問題なければ「トリガー → トリガーを追加」で次を設定する。
   - 実行する関数: `sendSubsidyMail`
   - イベントのソース: 時間主導型
   - 週ベースのタイマー: 毎週木曜日／午前9時〜10時

## 関数

| 関数 | 動作 |
| --- | --- |
| `sendSubsidyMail` | 全プロフィールへ送信（定期トリガー用）。配信週でないプロフィールは自動でスキップ |
| `previewSubsidyMail` | 送信せずログに文面を出力 |
| `sendSubsidyMailTokyo` | 東京都プロフィールのみ送信 |
| `sendSubsidyMailKanagawa` | 神奈川プロフィールのみ送信（隔週判定あり） |

## メールの構成

締切までの残日数で自動的に仕分けます。

| セクション | 条件 |
| --- | --- |
| 至急 | 残り30日以内（`URGENT_DAYS` で変更可）。締切が近い順 |
| 受付中・今後の締切 | 残り31日以上。締切が近い順 |
| 通年・随時 | `deadline` が `null` のもの |
| 参考（今年度の受付は終了） | `closed: true` または締切を過ぎたもの |

件名には至急・受付中の件数が入ります（例：`【補助金ウォッチ】2026年9月10日(木)｜至急2件・受付中1件`）。

## 保守について

**このスクリプトは Web 検索をしません。**公募回次や締切が変わったら `SUBSIDIES` の
該当エントリを手で更新してください。制度ごとの調査メモは `docs/subsidy-watch.md` にあります。

新しい制度を追加する場合は、既存エントリと同じ形で以下を埋めます。

```javascript
{
  name: '制度名',
  agency: '実施主体',
  profiles: ['tokyo', 'kanagawa'],   // 対象プロフィール
  deadline: '2026-12-15',            // 通年・未定なら null
  deadlineNote: '17:00締切',          // 補足（任意）
  closed: false,                     // 今年度終了なら true
  amount: '上限50万円',
  rate: '2/3',
  requirements: ['要件1', '要件2'],
  documents: ['必要書類1', '必要書類2'],
  note: '注意点や補足',
  url: 'https://...'
}
```
