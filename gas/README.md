# DailyReportMailer（Apps Script 版）

日報カウンターのスプレッドシートから入力された内容を集計してメール送信する
Apps Script です。3つの機能があります。

| 機能 | 実行関数 | 宛先 | 想定トリガー |
| --- | --- | --- | --- |
| 前営業日ぶんのまとめ | `sendDailyReportMail` | 小林様（`RECIPIENT`） | 平日 毎朝 8:00 |
| 当日ぶんの入力状況 | `sendEveningSummaryMail` | 小林様、CC全担当者 | 毎晩 20:00 |
| 個別の入力リマインド | `sendMorningReminderMail` | 担当者ひとりひとり | 毎朝 9:30 |

## 導入手順（共通）

1. 日報カウンターのスプレッドシートを開き、「拡張機能 → Apps Script」。
   （スプレッドシートの編集権限が必要です）
2. `DailyReportMailer.gs` の内容を新しいスクリプトファイルに貼り付ける。
3. 「プロジェクトの設定 → スクリプト プロパティ」に次を追加する。

   | プロパティ | 値 | 用途 |
   | --- | --- | --- |
   | `RECIPIENT` | 送信先メールアドレス | 上記1・2 |
   | `CC` | （任意）CCアドレス。カンマ区切り | 上記1 |
   | `STAFF_EMAILS` | 担当者名→メールアドレスのJSON<br>例: `{"山田":"yamada@example.com","佐藤":"sato@example.com"}` | 上記2のCC、3の宛先 |
   | `REPORT_APP_URL` | 日報カウンター入力アプリのURL（任意） | 3の本文ボタン |

   ※ 別ファイルのスプレッドシートを対象にする場合のみ `SPREADSHEET_ID` も設定します。
   スクリプトを日報カウンターのスプレッドシートに紐付けて作成した場合は不要です。
   ※ `STAFF_EMAILS` は実在する社員のメールアドレスです。このリポジトリや
   Gitには絶対に含めず、スクリプトプロパティ側でのみ管理してください。

4. 各機能を有効にする前に、対応する `preview〜` 関数（`previewDailyReportMail` /
   `previewEveningSummaryMail` / `previewMorningReminderMail`）を実行し、
   実行ログで文面を確認する（送信はされません）。
5. 問題なければ「トリガー → トリガーを追加」で本番用の関数にトリガーを設定する。
   - `sendDailyReportMail`：時間主導型 / 日付ベース / 午前8時〜9時
   - `sendEveningSummaryMail`：時間主導型 / 日付ベース / 午後8時〜9時
   - `sendMorningReminderMail`：時間主導型 / 日付ベース / 午前9時〜10時
   - ※ 土日の扱いは関数側で制御していません。土日も動かしたくない場合は
     曜日ベースのトリガーに変更するか、関数の先頭で `resolveTargetDates_`
     と同様の曜日チェックを追加してください。

## 動作（`sendDailyReportMail`）

- 火〜金：前日1日分
- 月：前週の金・土・日の3日分
- 対象日に入力が0件でも「入力なし」のメールを送信します。

## `sendEveningSummaryMail` / `sendMorningReminderMail` を有効にする前に

この2つは、既存の「小林様だけに送る」まとめメールと違い、次の点で影響範囲が
広くなります。有効化の前に社内で運用方針を確認してください。

- `sendEveningSummaryMail` は「本日まだ入力がない担当者」の名前を、対象者
  本人を含む全担当者に見える形（CC）で共有します。個人の状況が社内に公開
  される運用になるため、文面のトーン・CCの範囲は事前に合意しておくことを
  推奨します。
- 本文には「日報の入力状況は今後の増員・採用計画の参考にもさせていただき
  ます」という一文を含めています。実際に送る前に、この表現でよいか確認
  してください。
- `STAFF_EMAILS` に実在するメールアドレスを設定するまでは、この2つは
  送信対象が空になり何も送信しません（`sendEveningSummaryMail` はCCなしで
  小林様のみに送信されます）。
