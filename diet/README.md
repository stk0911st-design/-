# カロリーノート（食事・カロリー記録アプリ）

`meal-log.html` は、1日の食事とカロリーを記録するための Artifact 用ページです。

## できること

| 機能 | 内容 |
| --- | --- |
| 写真から記録 | 「撮る」でカメラを起動、「写真を選ぶ」で保存済みの写真から。料理とカロリーを読み取り、確認・修正してから記録 |
| 食事の記録 | 朝食 / 昼食 / 夕食 / 間食 ごとに「食べたもの」と kcal を追加 |
| かんたん入力 | 日本の食品カロリー目安（約50品）から候補をタップして1回で記録 |
| よく食べるもの | 直近30日で2回以上記録した食品・種目を候補の先頭に自動表示 |
| 運動の記録 | 種目と時間（分）を記録。消費カロリーは METs × 体重 × 時間 × 1.05 で自動計算（手入力で上書き可） |
| 体重・体脂肪率 | 1日1件記録。前回比・目標までの差を表示 |
| 歩数 | 1日1件記録。手入力、またはスマホの歩数計の画面を写真から読み取り。目標歩数までの残りと概算消費カロリーを表示 |
| 1日の合計 | 食べた合計 kcal・運動で消費した分・目標との差（残り／超過）・食事ごとの内訳 |
| 目標設定 | 1日の目標カロリー（500〜6000 kcal）・目標体重（20〜300 kg）・目標歩数（1000〜50000 歩）|
| 推移 | 「カロリー 7日」「体重 30日」「歩数 7日」を切り替え表示 |
| 日付移動 | 前後の日へ移動して過去の記録を確認・追記（未来の日付には進めない） |
| 週まとめ | 画面上部の「週まとめ」に切り替えると、その週（月〜日）のふりかえりを表示 |

「残り」は `目標カロリー + 運動で消費した分 − 食べた合計` です。運動した分だけその日に食べられる量が増えます。

## 週まとめ（ふりかえり）

月曜はじまりの1週間について、次を表示します。

- **4つの数字** … 1日平均の摂取カロリー（目標との差）／体重の変化（週初→週末）／運動の消費と日数・時間／記録できた日数と目標内の日数
- **日ごとの記録** … 日付・摂取・運動・差引（`摂取 − 運動 − 目標`）・体重の一覧。目標を超えた日は棒と数値の色が変わる
- **よく食べたもの** … 回数の多い順に5件（合計カロリー付き）
- **ふりかえり** … 平均と目標の差、目標内におさまった日数、いちばん多かった日、間食の合計、運動、体重の変化、
  目標体重までの見込み週数、先週平均との比較を文章で表示

前後の「‹ ›」で週を移動できます。

## 歩数について

**自動連携はできません。** このページはブラウザ上で動くため、iOS のヘルスケア（HealthKit）や
Google Fit のデータに直接アクセスする手段がありません。代わりに次の2つで記録します。

1. **歩数計の画面を写真から読み取る** … 「歩数」欄の「📷 読み取る」から、ヘルスケアアプリや
   歩数ウィジェットの画面を撮る／選ぶと、歩数を読み取って確認画面に出します。
   画面に日付が写っていて表示中の日と違う場合は、どちらの日に記録するか選べます。
2. **手入力** … 「歩数」欄に直接入力。

歩数からの概算消費カロリーは `2.5(METs) × 体重kg × (歩数 ÷ 100 ÷ 60)h × 1.05` です。
安静時ぶん（1 MET）を引いた「余分に消費した分」として計算しています（歩行 3.5 METs、約100歩/分と仮定）。

確認画面の「歩いた分を運動としても記録する」をオンにすると、その日の運動として
「ウォーキング（歩数から）」を追加し、「残り」に反映します。ウォーキングを別に記録している日は
二重計上になるため、既定ではオフです。

## 写真からの読み取り

Artifact の `sample` 機能（ページから Claude に質問する機能）を使い、選んだ写真を Claude に見せて
料理名と推定カロリーを JSON で受け取ります。

- 「撮る」は `<input type="file" capture="environment">` でスマホの標準カメラを起動します
  （PC など対応していない環境では通常のファイル選択になります）。
- 送信前に長辺 1600px / JPEG 品質 0.85 に縮小します。
- 結果は**必ず確認画面**を通します。品目名・カロリーの修正、行の削除、記録先（朝/昼/夕/間食）の変更ができます。
- 読み取りの自信が低い品はオレンジ色で表示します。
- 写真から記録した品には一覧で 📷 が付きます。
- カロリーは写真からの推定値であり、正確な値ではありません。
- 写真のボタンは、Artifact のビューアで開いていれば常に表示します。`sample` の利用可否は
  ボタンを押したあとに判定し、使えない場合は理由を確認画面に出します
  （判定を先に行ってボタンを隠すと、使えるはずの環境でもボタンが出ないことがあったため）。
- ビューア外（HTMLファイルを直接開いた場合など）では写真ボタンを表示しません。

運動の METs は一般的な値（ウォーキング 3.5／ジョギング 7.0／筋トレ(自重) 3.5 など、全18種目）を使い、
一覧にない種目は 4.0 で概算します。計算に使う体重は、その日以前でいちばん近い体重の記録
（1件も無ければ 60 kg）です。

## データの保存

- Artifact として公開した状態では、記録はページの `db` 機能に保存されます。
  - `days/<YYYY-MM-DD>` … `{ date, items: [{ id, slot, name, kcal, at }], exercise: [{ id, name, min, kcal, at }], weight, fat }`
  - `settings/main` … `{ targetKcal, targetWeight }`
- `db` が使えない環境（ローカルでファイルを直接開いた場合など）では、
  その端末のブラウザ（localStorage）に保存されます。
- ブラウザに残っていた記録は、`db` に同じ日付の記録が無い場合にかぎり
  自動でクラウド側へ引き上げます。**既存の記録を上書き・削除することはありません。**

## 公開方法

このファイルを Artifact として公開すると、リンクを開くだけでスマホからも利用できます。
`db` を宣言しているため、ページは組織内メンバーのみアクセス可能で、一般公開はできません。

再公開するときは同じファイルパスで publish すれば、同じ URL・同じデータのまま更新されます。
